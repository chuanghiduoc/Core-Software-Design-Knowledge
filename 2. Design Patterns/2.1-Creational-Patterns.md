## 1. Singleton

### Vấn đề

Cần đảm bảo một class chỉ có **DUY NHẤT MỘT instance** trong toàn bộ ứng dụng, và cung cấp global access point đến instance đó.

**Ví dụ thực tế:** Database connection pool, Logger, Configuration, Cache client.

### Khi nào cần

- Resource đắt đỏ mà chỉ cần 1 instance (DB pool, HTTP client)
- Shared state cần consistent (app config, feature flags)
- Coordination point (event bus, service registry)

### ❌ Sai: Global variable / Naive singleton

```typescript
// ❌ Global mutable — không kiểm soát, không testable
let dbConnection: DatabaseConnection | null = null;

function getDb(): DatabaseConnection {
  if (!dbConnection) {
    dbConnection = new DatabaseConnection(process.env.DB_URL!);
  }
  return dbConnection;
}
// Vấn đề: không thể mock trong test, hidden dependency, race condition possible
```

### ✅ TypeScript Singleton — Module Scope (cách tốt nhất)

```typescript
// database.ts
// TypeScript module = singleton by design (cached after first import)
// Đây là cách idiomatic nhất trong TS — KHÔNG cần class singleton pattern

import { Pool } from 'pg';

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
  max: 20,
  idleTimeoutMillis: 30_000,
});

// Chỉ export functions, không export pool trực tiếp
export async function query<T>(sql: string, params?: unknown[]): Promise<T[]> {
  const result = await pool.query(sql, params);
  return result.rows;
}

export async function transaction<T>(
  fn: (client: PoolClient) => Promise<T>,
): Promise<T> {
  const client = await pool.connect();
  try {
    await client.query('BEGIN');
    const result = await fn(client);
    await client.query('COMMIT');
    return result;
  } catch (error) {
    await client.query('ROLLBACK');
    throw error;
  } finally {
    client.release();
  }
}

export async function disconnect(): Promise<void> {
  await pool.end();
}

// Usage — mọi file import đều dùng cùng 1 pool
// import { query } from './database';
// const users = await query<User>('SELECT * FROM users');
```

### ✅ Class-based Singleton (khi cần lazily initialized)

```typescript
class AppConfig {
  private static instance: AppConfig | null = null;

  private constructor(
    readonly port: number,
    readonly dbUrl: string,
    readonly jwtSecret: string,
    readonly environment: 'development' | 'staging' | 'production',
  ) {}

  static getInstance(): AppConfig {
    if (!AppConfig.instance) {
      AppConfig.instance = AppConfig.loadFromEnv();
    }
    return AppConfig.instance;
  }

  // Cho phép reset trong tests
  static resetForTesting(): void {
    if (process.env.NODE_ENV !== 'test') {
      throw new Error('resetForTesting() is only available in test environment');
    }
    AppConfig.instance = null;
  }

  private static loadFromEnv(): AppConfig {
    const port = parseInt(process.env.PORT ?? '3000', 10);
    const dbUrl = process.env.DATABASE_URL;
    const jwtSecret = process.env.JWT_SECRET;

    if (!dbUrl) throw new Error('DATABASE_URL is required');
    if (!jwtSecret) throw new Error('JWT_SECRET is required');

    return new AppConfig(
      port,
      dbUrl,
      jwtSecret,
      (process.env.NODE_ENV as any) ?? 'development',
    );
  }

  get isDevelopment(): boolean { return this.environment === 'development'; }
  get isProduction(): boolean { return this.environment === 'production'; }
}
```

### ⚠️ Khi nào KHÔNG dùng Singleton

| Tình huống | Thay thế |
|-----------|----------|
| "Mọi thứ cần global access" | Dependency Injection — pass dependencies explicitly |
| Để tránh truyền parameters | Constructor injection — rõ ràng hơn |
| Test cần state khác nhau | DI + interface → mock dễ dàng |

> **Lời khuyên:** Trong TypeScript hiện đại, ưu tiên **module-level singleton** (export instance từ module) hoặc **DI container** hơn class-based singleton. Class singleton thường là dấu hiệu của hidden dependency.

## 2. Factory Method

### Vấn đề

Code cần tạo objects nhưng **không biết trước** concrete class nào sẽ được dùng. Hoặc muốn delegate việc tạo object cho subclass/module.

**Ví dụ thực tế:** Tạo notification channels, payment processors, database connections cho different environments.

### Bản chất

```
Thay vì:  const thing = new ConcreteThing()
Gọi:      const thing = createThing(type)     // Factory function
Hoặc:     const thing = factory.create(type)   // Factory class
```

### ✅ Factory Function (cách phổ biến nhất trong TypeScript)

```typescript
// Vấn đề: Tạo logger khác nhau tùy environment

interface Logger {
  info(message: string, context?: Record<string, unknown>): void;
  error(message: string, error?: Error, context?: Record<string, unknown>): void;
  warn(message: string, context?: Record<string, unknown>): void;
}

// Concrete implementations
class ConsoleLogger implements Logger {
  info(message: string, context?: Record<string, unknown>): void {
    console.log(`[INFO] ${message}`, context ?? '');
  }

  error(message: string, error?: Error, context?: Record<string, unknown>): void {
    console.error(`[ERROR] ${message}`, error?.stack ?? '', context ?? '');
  }

  warn(message: string, context?: Record<string, unknown>): void {
    console.warn(`[WARN] ${message}`, context ?? '');
  }
}

class StructuredLogger implements Logger {
  constructor(private readonly serviceName: string) {}

  info(message: string, context?: Record<string, unknown>): void {
    this.writeLog('info', message, undefined, context);
  }

  error(message: string, error?: Error, context?: Record<string, unknown>): void {
    this.writeLog('error', message, error, context);
  }

  warn(message: string, context?: Record<string, unknown>): void {
    this.writeLog('warn', message, undefined, context);
  }

  private writeLog(
    level: string,
    message: string,
    error?: Error,
    context?: Record<string, unknown>,
  ): void {
    const entry = {
      timestamp: new Date().toISOString(),
      level,
      service: this.serviceName,
      message,
      ...(error && { error: { name: error.name, message: error.message, stack: error.stack } }),
      ...context,
    };
    process.stdout.write(JSON.stringify(entry) + '\n');
  }
}

class SilentLogger implements Logger {
  info(): void { /* noop */ }
  error(): void { /* noop */ }
  warn(): void { /* noop */ }
}

// Factory Function — tạo đúng logger cho environment
function createLogger(config: { environment: string; serviceName: string }): Logger {
  switch (config.environment) {
    case 'production':
    case 'staging':
      return new StructuredLogger(config.serviceName);
    case 'test':
      return new SilentLogger();
    case 'development':
    default:
      return new ConsoleLogger();
  }
}

// Usage
const logger = createLogger({
  environment: process.env.NODE_ENV ?? 'development',
  serviceName: 'user-api',
});

logger.info('Server started', { port: 3000 });
// Dev: "[INFO] Server started { port: 3000 }"
// Prod: {"timestamp":"...","level":"info","service":"user-api","message":"Server started","port":3000}
```

### ✅ Factory Method Pattern — Polymorphic creation

```typescript
// Vấn đề: Mỗi loại document cần parser riêng, nhưng pipeline xử lý giống nhau

interface Document {
  readonly content: string;
  readonly metadata: DocumentMetadata;
  extractText(): string;
  extractLinks(): ReadonlyArray<string>;
}

// Abstract creator — define factory method
abstract class DocumentImporter {
  // Template method: pipeline chung
  async import(source: DataSource): Promise<ImportResult> {
    const raw = await source.read();
    const document = this.createDocument(raw);  // Factory method — subclass quyết định
    const text = document.extractText();
    const links = document.extractLinks();

    return {
      document,
      textLength: text.length,
      linkCount: links.length,
    };
  }

  // Factory method — subclass override để tạo concrete document
  protected abstract createDocument(raw: Buffer): Document;
}

// Concrete creators
class PdfImporter extends DocumentImporter {
  protected createDocument(raw: Buffer): Document {
    return new PdfDocument(raw);  // Tạo PDF-specific document
  }
}

class HtmlImporter extends DocumentImporter {
  protected createDocument(raw: Buffer): Document {
    return new HtmlDocument(raw); // Tạo HTML-specific document
  }
}

class MarkdownImporter extends DocumentImporter {
  protected createDocument(raw: Buffer): Document {
    return new MarkdownDocument(raw);
  }
}

// Registry cho dynamic selection
const importers: Record<string, DocumentImporter> = {
  'application/pdf': new PdfImporter(),
  'text/html': new HtmlImporter(),
  'text/markdown': new MarkdownImporter(),
};

function getImporter(mimeType: string): DocumentImporter {
  const importer = importers[mimeType];
  if (!importer) throw new UnsupportedFormatError(mimeType);
  return importer;
}
```

### ✅ Real-world: API Response Factory

```typescript
// Factory cho consistent API responses

interface ApiResponse<T> {
  success: boolean;
  data?: T;
  error?: ApiError;
  meta?: ResponseMeta;
}

interface ApiError {
  code: string;
  message: string;
  details?: unknown;
}

interface ResponseMeta {
  requestId: string;
  timestamp: string;
  pagination?: PaginationMeta;
}

// Factory functions — enforce consistent shape
const ApiResponse = {
  success<T>(data: T, meta?: Partial<ResponseMeta>): ApiResponse<T> {
    return {
      success: true,
      data,
      meta: {
        requestId: meta?.requestId ?? crypto.randomUUID(),
        timestamp: new Date().toISOString(),
        ...meta,
      },
    };
  },

  paginated<T>(
    data: ReadonlyArray<T>,
    pagination: PaginationMeta,
    meta?: Partial<ResponseMeta>,
  ): ApiResponse<ReadonlyArray<T>> {
    return {
      success: true,
      data: [...data],
      meta: {
        requestId: meta?.requestId ?? crypto.randomUUID(),
        timestamp: new Date().toISOString(),
        pagination,
        ...meta,
      },
    };
  },

  error(code: string, message: string, details?: unknown): ApiResponse<never> {
    return {
      success: false,
      error: { code, message, details },
      meta: {
        requestId: crypto.randomUUID(),
        timestamp: new Date().toISOString(),
      },
    };
  },

  fromError(err: unknown): ApiResponse<never> {
    if (err instanceof AppError) {
      return ApiResponse.error(err.code, err.message);
    }
    return ApiResponse.error('INTERNAL_ERROR', 'An unexpected error occurred');
  },
} as const;

// Usage
app.get('/users', async (req, res) => {
  const { users, total } = await userService.list(req.query);
  res.json(ApiResponse.paginated(users, { total, page: 1, pageSize: 20 }));
});

app.get('/users/:id', async (req, res) => {
  const user = await userService.findById(req.params.id);
  if (!user) {
    res.status(404).json(ApiResponse.error('NOT_FOUND', 'User not found'));
    return;
  }
  res.json(ApiResponse.success(user));
});
```

### Khi nào dùng Factory Method

| ✅ Dùng khi | ❌ Không cần khi |
|------------|-----------------|
| Không biết trước concrete type | Chỉ có 1 concrete type |
| Type phụ thuộc vào runtime config | Type cố định, không thay đổi |
| Cần consistent creation logic | Constructor đủ đơn giản |
| Muốn tách creation logic ra khỏi business logic | Prototype app / script |

## 3. Abstract Factory

### Vấn đề

Cần tạo **một họ (family) objects liên quan** mà đảm bảo chúng tương thích với nhau, mà KHÔNG specify concrete classes.

**Ví dụ thực tế:** UI theme system (tất cả components phải cùng theme), cross-platform UI, multi-database support.

### ❌ Vấn đề: Mixing incompatible objects

```typescript
// Không có factory → có thể mix MaterialButton với iOSDialog → inconsistent UI
const button = new MaterialButton();    // Material Design
const dialog = new CupertinoDialog();   // iOS style
const input = new MaterialTextField();  // Material Design
// → UI nhìn inconsistent, hard to maintain
```

### ✅ Abstract Factory — Đảm bảo family consistency

```typescript
// Vấn đề thực tế: Database abstraction hỗ trợ PostgreSQL và SQLite

// === Abstract Products ===
interface QueryBuilder {
  select(table: string, columns: string[]): QueryBuilder;
  where(condition: string, params: unknown[]): QueryBuilder;
  orderBy(column: string, direction: 'ASC' | 'DESC'): QueryBuilder;
  limit(n: number): QueryBuilder;
  build(): { sql: string; params: unknown[] };
}

interface ConnectionPool {
  acquire(): Promise<Connection>;
  release(conn: Connection): void;
  destroy(): Promise<void>;
  get size(): number;
}

interface SchemaBuilder {
  createTable(name: string, definition: TableDefinition): string;
  addColumn(table: string, column: ColumnDefinition): string;
  addIndex(table: string, columns: string[], unique?: boolean): string;
}

// === Abstract Factory ===
interface DatabaseFactory {
  createQueryBuilder(): QueryBuilder;
  createConnectionPool(config: PoolConfig): ConnectionPool;
  createSchemaBuilder(): SchemaBuilder;
}

// === PostgreSQL Family ===
class PostgresQueryBuilder implements QueryBuilder {
  private parts: QueryParts = { table: '', columns: [], conditions: [], params: [], orderBy: null, limit: null };

  select(table: string, columns: string[]): QueryBuilder {
    this.parts.table = table;
    this.parts.columns = columns;
    return this;
  }

  where(condition: string, params: unknown[]): QueryBuilder {
    this.parts.conditions.push(condition);
    this.parts.params.push(...params);
    return this;
  }

  orderBy(column: string, direction: 'ASC' | 'DESC'): QueryBuilder {
    this.parts.orderBy = `${column} ${direction}`;
    return this;
  }

  limit(n: number): QueryBuilder {
    this.parts.limit = n;
    return this;
  }

  build(): { sql: string; params: unknown[] } {
    const cols = this.parts.columns.length > 0 ? this.parts.columns.join(', ') : '*';
    let sql = `SELECT ${cols} FROM ${this.parts.table}`;

    if (this.parts.conditions.length > 0) {
      // PostgreSQL dùng $1, $2 cho parameterized queries
      sql += ` WHERE ${this.parts.conditions.join(' AND ')}`;
    }
    if (this.parts.orderBy) sql += ` ORDER BY ${this.parts.orderBy}`;
    if (this.parts.limit) sql += ` LIMIT ${this.parts.limit}`;

    return { sql, params: this.parts.params };
  }
}

class PostgresSchemaBuilder implements SchemaBuilder {
  createTable(name: string, def: TableDefinition): string {
    const columns = def.columns.map(c => {
      let col = `"${c.name}" ${this.mapType(c.type)}`;
      if (c.primaryKey) col += ' PRIMARY KEY';
      if (c.nullable === false) col += ' NOT NULL';
      if (c.default !== undefined) col += ` DEFAULT ${c.default}`;
      return col;
    });
    return `CREATE TABLE IF NOT EXISTS "${name}" (\n  ${columns.join(',\n  ')}\n);`;
  }

  addColumn(table: string, col: ColumnDefinition): string {
    return `ALTER TABLE "${table}" ADD COLUMN "${col.name}" ${this.mapType(col.type)};`;
  }

  addIndex(table: string, columns: string[], unique = false): string {
    const indexName = `idx_${table}_${columns.join('_')}`;
    const uniqueStr = unique ? 'UNIQUE ' : '';
    return `CREATE ${uniqueStr}INDEX IF NOT EXISTS "${indexName}" ON "${table}" (${columns.map(c => `"${c}"`).join(', ')});`;
  }

  private mapType(type: ColumnType): string {
    const map: Record<ColumnType, string> = {
      string: 'TEXT',
      integer: 'INTEGER',
      bigint: 'BIGINT',
      float: 'DOUBLE PRECISION',
      boolean: 'BOOLEAN',
      timestamp: 'TIMESTAMP WITH TIME ZONE',
      uuid: 'UUID',
      json: 'JSONB', // PostgreSQL-specific: JSONB cho queries
    };
    return map[type];
  }
}

class PostgresFactory implements DatabaseFactory {
  createQueryBuilder(): QueryBuilder { return new PostgresQueryBuilder(); }
  createConnectionPool(config: PoolConfig): ConnectionPool { return new PostgresPool(config); }
  createSchemaBuilder(): SchemaBuilder { return new PostgresSchemaBuilder(); }
}

// === SQLite Family ===
class SQLiteSchemaBuilder implements SchemaBuilder {
  createTable(name: string, def: TableDefinition): string {
    const columns = def.columns.map(c => {
      let col = `"${c.name}" ${this.mapType(c.type)}`;
      if (c.primaryKey) col += ' PRIMARY KEY';
      if (c.nullable === false) col += ' NOT NULL';
      return col;
    });
    return `CREATE TABLE IF NOT EXISTS "${name}" (\n  ${columns.join(',\n  ')}\n);`;
  }

  private mapType(type: ColumnType): string {
    const map: Record<ColumnType, string> = {
      string: 'TEXT',
      integer: 'INTEGER',
      bigint: 'INTEGER',     // SQLite không có BIGINT
      float: 'REAL',
      boolean: 'INTEGER',    // SQLite dùng 0/1 cho boolean
      timestamp: 'TEXT',     // SQLite lưu datetime dạng text
      uuid: 'TEXT',          // SQLite không có UUID type
      json: 'TEXT',          // SQLite không có JSONB
    };
    return map[type];
  }

  addColumn(table: string, col: ColumnDefinition): string {
    return `ALTER TABLE "${table}" ADD COLUMN "${col.name}" ${this.mapType(col.type)};`;
  }

  addIndex(table: string, columns: string[], unique = false): string {
    const indexName = `idx_${table}_${columns.join('_')}`;
    const uniqueStr = unique ? 'UNIQUE ' : '';
    return `CREATE ${uniqueStr}INDEX IF NOT EXISTS "${indexName}" ON "${table}" (${columns.join(', ')});`;
  }
}

class SQLiteFactory implements DatabaseFactory {
  createQueryBuilder(): QueryBuilder { return new SQLiteQueryBuilder(); }
  createConnectionPool(config: PoolConfig): ConnectionPool { return new SQLitePool(config); }
  createSchemaBuilder(): SchemaBuilder { return new SQLiteSchemaBuilder(); }
}

// === Client Code — works with ANY database ===
class MigrationRunner {
  constructor(private readonly dbFactory: DatabaseFactory) {}

  async run(migrations: ReadonlyArray<Migration>): Promise<void> {
    const schema = this.dbFactory.createSchemaBuilder();
    const pool = this.dbFactory.createConnectionPool({ max: 1 });
    const conn = await pool.acquire();

    try {
      for (const migration of migrations) {
        const sql = migration.up(schema); // Schema builder generates correct SQL
        await conn.execute(sql);
      }
    } finally {
      pool.release(conn);
    }
  }
}

// Usage — swap database bằng cách đổi factory, KHÔNG sửa MigrationRunner
const factory = process.env.NODE_ENV === 'test'
  ? new SQLiteFactory()
  : new PostgresFactory();

const migrationRunner = new MigrationRunner(factory);
```

### Khi nào dùng Abstract Factory

| ✅ Dùng khi | ❌ Không cần khi |
|------------|-----------------|
| Tạo family objects phải tương thích | Chỉ tạo 1 loại object (dùng Factory Method) |
| Hỗ trợ multiple platforms/databases | Chỉ hỗ trợ 1 platform |
| Products có coupling nội bộ | Objects independent với nhau |

> **Note:** Trong TypeScript thực tế, Abstract Factory ít gặp hơn Factory Method. Thường thấy trong database abstraction, UI theming, hoặc cross-platform code.

## 4. Builder

### Vấn đề

Cần tạo complex objects với **nhiều optional parameters**, nhiều combinations, hoặc cần **step-by-step construction**.

**Ví dụ thực tế:** HTTP request builders, query builders, config objects, email builders, test data generators.

### ❌ Vấn đề: Telescoping Constructor

```typescript
// Constructor với quá nhiều parameters — không ai nhớ thứ tự
const email = new Email(
  'alice@example.com',     // to
  'bob@example.com',       // from
  'Hello',                 // subject
  '<p>Content</p>',        // htmlBody
  'Content',               // plainTextBody — wait, is this the right order?
  undefined,               // cc
  ['charlie@example.com'], // bcc — or is this cc?
  'high',                  // priority
  true,                    // trackOpens
  ['file.pdf'],            // attachments
  { 'X-Custom': 'value' }, // headers
);
// → Impossible to read, easy to swap parameters
```

### ✅ Builder Pattern

```typescript
// Email Builder — fluent API, type-safe, self-documenting

interface EmailMessage {
  readonly to: ReadonlyArray<string>;
  readonly from: string;
  readonly subject: string;
  readonly htmlBody?: string;
  readonly textBody?: string;
  readonly cc?: ReadonlyArray<string>;
  readonly bcc?: ReadonlyArray<string>;
  readonly replyTo?: string;
  readonly priority?: 'low' | 'normal' | 'high';
  readonly attachments?: ReadonlyArray<Attachment>;
  readonly headers?: Readonly<Record<string, string>>;
  readonly trackOpens?: boolean;
  readonly trackClicks?: boolean;
}

class EmailBuilder {
  private message: Partial<EmailMessage> = {};

  // Required fields — bắt buộc gọi
  to(...addresses: string[]): this {
    this.message.to = addresses;
    return this;
  }

  from(address: string): this {
    this.message.from = address;
    return this;
  }

  subject(text: string): this {
    this.message.subject = text;
    return this;
  }

  // Content — ít nhất 1 trong 2
  html(body: string): this {
    this.message.htmlBody = body;
    return this;
  }

  text(body: string): this {
    this.message.textBody = body;
    return this;
  }

  // Optional fields — chain as needed
  cc(...addresses: string[]): this {
    this.message.cc = addresses;
    return this;
  }

  bcc(...addresses: string[]): this {
    this.message.bcc = addresses;
    return this;
  }

  replyTo(address: string): this {
    this.message.replyTo = address;
    return this;
  }

  priority(level: 'low' | 'normal' | 'high'): this {
    this.message.priority = level;
    return this;
  }

  attach(attachment: Attachment): this {
    this.message.attachments = [...(this.message.attachments ?? []), attachment];
    return this;
  }

  header(key: string, value: string): this {
    this.message.headers = { ...this.message.headers, [key]: value };
    return this;
  }

  trackOpens(enabled = true): this {
    this.message.trackOpens = enabled;
    return this;
  }

  trackClicks(enabled = true): this {
    this.message.trackClicks = enabled;
    return this;
  }

  // Build with validation
  build(): EmailMessage {
    if (!this.message.to?.length) throw new Error('Email must have at least one recipient');
    if (!this.message.from) throw new Error('Email must have a sender');
    if (!this.message.subject) throw new Error('Email must have a subject');
    if (!this.message.htmlBody && !this.message.textBody) {
      throw new Error('Email must have either HTML or text body');
    }

    return { ...this.message } as EmailMessage;
  }
}

// Usage — self-documenting, impossible to mix up params
const email = new EmailBuilder()
  .to('alice@example.com', 'bob@example.com')
  .from('noreply@myapp.com')
  .subject('Your order has been shipped')
  .html(renderTemplate('order-shipped', orderData))
  .text(renderPlainText('order-shipped', orderData))
  .bcc('admin@myapp.com')
  .priority('high')
  .attach({ filename: 'invoice.pdf', content: invoiceBuffer })
  .trackOpens()
  .build();
```

### ✅ Real-world: Query Builder

```typescript
// Type-safe SQL query builder

class SelectQueryBuilder<T extends Record<string, unknown>> {
  private _table = '';
  private _columns: string[] = [];
  private _conditions: Array<{ sql: string; params: unknown[] }> = [];
  private _orderBy: Array<{ column: string; direction: 'ASC' | 'DESC' }> = [];
  private _limit?: number;
  private _offset?: number;
  private _joins: string[] = [];

  from(table: string): this {
    this._table = table;
    return this;
  }

  select(...columns: Array<keyof T & string>): this {
    this._columns = columns;
    return this;
  }

  where(column: keyof T & string, operator: '=' | '!=' | '>' | '<' | 'LIKE' | 'IN', value: unknown): this {
    const paramIndex = this._conditions.reduce((sum, c) => sum + c.params.length, 0) + 1;

    if (operator === 'IN' && Array.isArray(value)) {
      const placeholders = value.map((_, i) => `$${paramIndex + i}`).join(', ');
      this._conditions.push({ sql: `"${column}" IN (${placeholders})`, params: value });
    } else {
      this._conditions.push({ sql: `"${column}" ${operator} $${paramIndex}`, params: [value] });
    }
    return this;
  }

  andWhere(column: keyof T & string, operator: '=' | '!=' | '>' | '<', value: unknown): this {
    return this.where(column, operator, value);
  }

  join(table: string, on: string): this {
    this._joins.push(`JOIN "${table}" ON ${on}`);
    return this;
  }

  leftJoin(table: string, on: string): this {
    this._joins.push(`LEFT JOIN "${table}" ON ${on}`);
    return this;
  }

  orderBy(column: keyof T & string, direction: 'ASC' | 'DESC' = 'ASC'): this {
    this._orderBy.push({ column, direction });
    return this;
  }

  limit(n: number): this {
    this._limit = n;
    return this;
  }

  offset(n: number): this {
    this._offset = n;
    return this;
  }

  build(): { sql: string; params: unknown[] } {
    if (!this._table) throw new Error('Table is required');

    const cols = this._columns.length > 0
      ? this._columns.map(c => `"${c}"`).join(', ')
      : '*';

    let sql = `SELECT ${cols} FROM "${this._table}"`;

    if (this._joins.length > 0) {
      sql += ' ' + this._joins.join(' ');
    }

    const allParams: unknown[] = [];
    if (this._conditions.length > 0) {
      sql += ' WHERE ' + this._conditions.map(c => c.sql).join(' AND ');
      this._conditions.forEach(c => allParams.push(...c.params));
    }

    if (this._orderBy.length > 0) {
      sql += ' ORDER BY ' + this._orderBy.map(o => `"${o.column}" ${o.direction}`).join(', ');
    }

    if (this._limit !== undefined) sql += ` LIMIT ${this._limit}`;
    if (this._offset !== undefined) sql += ` OFFSET ${this._offset}`;

    return { sql, params: allParams };
  }
}

// Usage
interface UserTable {
  id: string;
  name: string;
  email: string;
  status: string;
  created_at: string;
}

const query = new SelectQueryBuilder<UserTable>()
  .from('users')
  .select('id', 'name', 'email')
  .where('status', '=', 'active')
  .where('created_at', '>', '2024-01-01')
  .orderBy('created_at', 'DESC')
  .limit(20)
  .offset(40)
  .build();

// { sql: 'SELECT "id", "name", "email" FROM "users"
//         WHERE "status" = $1 AND "created_at" > $2
//         ORDER BY "created_at" DESC LIMIT 20 OFFSET 40',
//   params: ['active', '2024-01-01'] }
```

## 5. Prototype

### Vấn đề

Cần tạo objects bằng cách **clone** objects hiện có, thay vì tạo mới từ đầu. Đặc biệt hữu ích khi creation đắt đỏ hoặc khi cần copy objects phức tạp.

**Ví dụ thực tế:** Cloning configuration, duplicating complex documents, undo/redo snapshots, template-based creation.

### Bản chất trong TypeScript

TypeScript/JavaScript có spread operator và `structuredClone()` nên Prototype pattern đơn giản hơn trong Java/C++:

```typescript
// JavaScript đã có prototype cloning built-in
const original = { name: 'Alice', scores: [95, 87, 92] };

// Shallow clone
const shallow = { ...original };
shallow.scores.push(100); // ⚠️ Mutates original.scores!

// Deep clone (modern JS)
const deep = structuredClone(original);
deep.scores.push(100); // ✅ original.scores unchanged
```

### ✅ Prototype Pattern — Template-based configuration

```typescript
// Vấn đề: Tạo nhiều server configs dựa trên templates

interface ServerConfig {
  readonly host: string;
  readonly port: number;
  readonly database: DatabaseConfig;
  readonly cache: CacheConfig;
  readonly logging: LoggingConfig;
  readonly features: ReadonlyArray<string>;
}

interface DatabaseConfig {
  readonly url: string;
  readonly pool: { readonly min: number; readonly max: number };
  readonly ssl: boolean;
}

// Prototype class với clone method
class ServerConfigPrototype {
  constructor(private config: ServerConfig) {}

  clone(overrides: DeepPartial<ServerConfig> = {}): ServerConfig {
    return this.deepMerge(structuredClone(this.config), overrides);
  }

  private deepMerge(target: any, source: any): any {
    for (const key of Object.keys(source)) {
      if (source[key] && typeof source[key] === 'object' && !Array.isArray(source[key])) {
        target[key] = this.deepMerge(target[key] ?? {}, source[key]);
      } else {
        target[key] = source[key];
      }
    }
    return target;
  }
}

// Template configs
const productionTemplate = new ServerConfigPrototype({
  host: '0.0.0.0',
  port: 8080,
  database: { url: 'postgres://prod-host/app', pool: { min: 10, max: 50 }, ssl: true },
  cache: { host: 'redis-prod', port: 6379, ttlMs: 300_000 },
  logging: { level: 'warn', format: 'json', destination: 'stdout' },
  features: ['rate-limiting', 'compression', 'cors'],
});

const stagingTemplate = new ServerConfigPrototype({
  host: '0.0.0.0',
  port: 8080,
  database: { url: 'postgres://staging-host/app', pool: { min: 2, max: 10 }, ssl: true },
  cache: { host: 'redis-staging', port: 6379, ttlMs: 60_000 },
  logging: { level: 'info', format: 'json', destination: 'stdout' },
  features: ['rate-limiting', 'compression', 'cors', 'debug-headers'],
});

// Clone and customize
const regionEuConfig = productionTemplate.clone({
  database: { url: 'postgres://eu-prod-host/app' },
  cache: { host: 'redis-eu-prod' },
});

const regionUsConfig = productionTemplate.clone({
  database: { url: 'postgres://us-prod-host/app' },
  cache: { host: 'redis-us-prod' },
});
```

### ✅ Real-world: Cloneable Domain Objects

```typescript
// Document editor: clone documents for "Save As" / "Duplicate"

class Document {
  constructor(
    readonly id: string,
    private _title: string,
    private _content: DocumentContent,
    private _metadata: DocumentMetadata,
    private _permissions: ReadonlyArray<Permission>,
  ) {}

  // Clone with new ID — for "Duplicate" feature
  duplicate(newOwner: UserId): Document {
    return new Document(
      crypto.randomUUID(), // New ID
      `${this._title} (Copy)`,
      this._content.clone(), // Deep clone content
      {
        ...this._metadata,
        createdAt: new Date(),
        createdBy: newOwner,
        version: 1, // Reset version
      },
      [{ userId: newOwner, level: 'owner' }], // Reset permissions
    );
  }

  // Snapshot for undo/redo
  snapshot(): DocumentSnapshot {
    return {
      title: this._title,
      content: this._content.clone(),
      metadata: { ...this._metadata },
      timestamp: new Date(),
    };
  }

  restoreFrom(snapshot: DocumentSnapshot): void {
    this._title = snapshot.title;
    this._content = snapshot.content.clone();
    this._metadata = { ...snapshot.metadata, updatedAt: new Date() };
  }
}
```

### Khi nào dùng Prototype

| ✅ Dùng khi | ❌ Không cần khi |
|------------|-----------------|
| Clone đắt hơn create | Object đơn giản, tạo mới nhanh |
| Object có nhiều variations dựa trên template | Mỗi object hoàn toàn khác nhau |
| Cần snapshot/undo | Không cần history |
| Runtime configuration cloning | Compile-time fixed configs |

> **Note TypeScript:** `structuredClone()` + spread operator đã cover 90% use cases. Chỉ cần explicit Prototype pattern khi cần custom clone logic (selective deep copy, resetting certain fields).

## So sánh Creational Patterns

| Pattern | Mục đích | Khi nào dùng | Complexity |
|---------|----------|-------------|------------|
| **Singleton** | 1 instance duy nhất | Shared resource, config | Low |
| **Factory Method** | Delegate creation cho subclass/function | Chưa biết concrete type | Low-Medium |
| **Abstract Factory** | Tạo family objects tương thích | Multi-platform, multi-DB | Medium-High |
| **Builder** | Step-by-step complex construction | Nhiều optional params | Medium |
| **Prototype** | Clone existing objects | Template-based, snapshots | Low-Medium |

### Decision Flow

```
Cần tạo object?
├── Chỉ 1 instance? → Singleton (hoặc module-level)
├── Object phức tạp, nhiều optional params? → Builder
├── Cần clone từ template? → Prototype
├── Cần tạo family objects tương thích? → Abstract Factory
└── Cần delegate concrete type? → Factory Method
```
