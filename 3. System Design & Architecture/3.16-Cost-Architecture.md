## Cost-Aware Architecture Decisions

### Architecture Cost Impact

```
Decision                          Monthly Cost Impact
──────────────────────────────    ──────────────────
Microservices vs Monolith         $500 (mono) vs $3,000+ (micro)
  - N databases, N load balancers, N CI pipelines, N monitoring

Multi-region vs Single-region     $1,000 vs $3,000+
  - Data replication, cross-region traffic, duplicate infrastructure

Real-time vs Batch processing     $200 (batch) vs $2,000+ (real-time)
  - Kafka cluster, stream processors, always-on consumers

Serverless vs Containers          Depends on traffic pattern
  - Low/variable traffic: serverless wins
  - Steady high traffic: containers win
  - Crossover: ~5-10M requests/month

SQL vs NoSQL                      PostgreSQL RDS: $50-200/mo
                                  DynamoDB: $0-1,000+/mo (pay per operation)
                                  → DynamoDB cheap at low scale, expensive at high scale
```

### Right-Sizing Checklist

```typescript
// Questions to ask before EVERY infrastructure decision:

// 1. Do we NEED this?
// ❌ "Let's add Redis for caching"
// ✅ "Database queries average 200ms. Is that a problem? For whom?"

// 2. What's the cheapest thing that works?
// ❌ RDS db.r5.2xlarge ($1,400/mo) "for performance"
// ✅ RDS db.t3.medium ($50/mo) + monitor → upgrade when data shows need

// 3. Can we defer this decision?
// ❌ Set up Kafka on day 1 "for event-driven architecture"
// ✅ Start with PostgreSQL LISTEN/NOTIFY → Kafka when throughput requires it

// 4. What's the cost of being wrong?
// Over-provisioned: waste money (reversible)
// Under-provisioned: users have bad experience (fixable quickly with auto-scaling)
// Wrong architecture: expensive to change (think carefully)
```

## Cloud Cost Optimization

### Compute

```
1. Right-size instances:
   - Monitor CPU/memory utilization
   - If avg CPU < 30% → downsize
   - If avg CPU > 70% → upsize (or add auto-scaling)

2. Reserved Instances / Savings Plans:
   - Steady-state workloads → 1-year RI = 30-40% savings
   - 3-year RI = 50-60% savings
   - Only for PREDICTABLE baseline workload

3. Spot Instances (70-90% discount):
   - Batch processing, CI/CD runners, dev environments
   - NOT for production API servers (can be terminated anytime)

4. Auto-scaling:
   - Scale to 0 during off-hours (dev/staging environments)
   - Schedule-based: scale up before business hours, down after
   - Metric-based: scale on CPU, request count, queue depth
```

### Database

```
1. Use appropriate instance size:
   - Start small (db.t3.medium: ~$50/mo)
   - Monitor and upgrade when needed

2. Storage optimization:
   - VACUUM regularly (PostgreSQL)
   - Archive old data to cold storage
   - Partition tables by time, drop old partitions

3. Read replicas:
   - Cheaper than upgrading primary
   - Route read queries to replicas

4. Connection pooling (PgBouncer):
   - Reduce connection count → smaller instance possible
   - Serverless → PgBouncer ESSENTIAL (Lambda creates many connections)
```

### Bandwidth & Storage

```
1. CDN for static assets:
   - CloudFront/Cloudflare: cache at edge
   - Avoid serving static files from application server

2. S3 storage classes:
   - S3 Standard: frequently accessed ($0.023/GB)
   - S3 Infrequent Access: older data ($0.0125/GB)
   - S3 Glacier: archive ($0.004/GB)
   - Lifecycle policies: auto-transition based on age

3. Compress responses:
   - gzip/brotli: reduce bandwidth 60-80%
   - Especially important for API responses and static assets

4. Image optimization:
   - WebP/AVIF instead of PNG/JPEG (50-70% smaller)
   - Responsive images (don't serve 4K to mobile)
   - Lazy loading (don't load below-fold images)
```

### Cost Anomaly Detection

```typescript
// Track daily costs, alert on spikes

class CostMonitor {
  async checkDailyCost(): Promise<void> {
    const today = await this.getCloudCost('today');
    const last7DaysAvg = await this.getAverageDailyCost(7);

    // Alert if today's cost > 150% of 7-day average
    if (today > last7DaysAvg * 1.5) {
      await this.alert({
        severity: 'warning',
        title: 'Cost anomaly detected',
        message: `Today's cost ($${today}) is ${Math.round(today / last7DaysAvg * 100)}% of 7-day average ($${last7DaysAvg})`,
        suggestedActions: [
          'Check for runaway instances (forgotten dev environments)',
          'Check for DDoS or unusual traffic patterns',
          'Check for data transfer spikes',
          'Check for expensive queries (full table scans)',
        ],
      });
    }
  }
}

// Common cost surprises:
// - NAT Gateway data transfer ($0.045/GB — adds up FAST)
// - CloudWatch Logs ingestion ($0.50/GB)
// - EBS snapshots accumulating
// - Forgotten dev/test environments running 24/7
// - Cross-AZ data transfer between services
```
