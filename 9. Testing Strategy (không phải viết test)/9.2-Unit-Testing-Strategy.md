# 9.2 Unit Testing Strategy

> Unit test không phải "test từng function" — mà là **test từng BEHAVIOR ở mức nhỏ nhất có ý nghĩa**.
> Một unit test tốt cho bạn biết CÁI GÌ hỏng trong 2 giây. Một unit test tệ cho bạn biết "có gì đó sai" rồi bạn phải debug 2 tiếng.

## Định nghĩa "Unit"

```
Classic (Detroit School): "Unit" = một BEHAVIOR, có thể span nhiều classes
  → Chỉ mock external dependencies (DB, network, file system)
  → Recommendation: dùng cho hầu hết trường hợp

Mockist (London School): "Unit" = một CLASS riêng lẻ
  → Mock TẤT CẢ dependencies, verify interactions
  → Dùng khi cần verify interaction cụ thể
```

## Sociable vs Solitary Unit Tests

### Sociable (Classic) — collaborators chạy thật

```typescript
// ShippingCostCalculator dùng real WeightCalculator, ZoneMapper, RateCard
const calculator = new ShippingCostCalculator(
  new WeightCalculator(),        // Real
  new ZoneMapper(zoneData),      // Real, with test data
  new RateCard(rateData),        // Real, with test data
);

it('calculates international shipping for heavy package', () => {
  const order = OrderBuilder.create().withItem({ weight: Kg.of(15) }).build();
  const destination = Address.international('US', 'New York');
  expect(calculator.calculate(order, destination)).toEqual(Money.of(45.00));
});
// Ưu: phản ánh reality, refactor internal không break test
// Nhược: khi fail, phải check nhiều classes
```

### Solitary (London) — mock tất cả

```typescript
it('uses weight, zone, and rate card to calculate shipping', () => {
  const mockWeightCalc = { totalWeight: jest.fn().mockReturnValue(Kg.of(2)) };
  const mockZoneMapper = { getZone: jest.fn().mockReturnValue(Zone.DOMESTIC) };
  const mockRateCard = { getRate: jest.fn().mockReturnValue(Money.of(9.99)) };
  const calculator = new ShippingCostCalculator(mockWeightCalc, mockZoneMapper, mockRateCard);

  const result = calculator.calculate(someOrder, someAddress);
  expect(mockRateCard.getRate).toHaveBeenCalledWith(Kg.of(2), Zone.DOMESTIC);
  expect(result).toEqual(Money.of(9.99));
});
// Ưu: fail = biết CHÍNH XÁC class nào hỏng
// Nhược: gắn chặt vào implementation, refactor = rewrite tests
```

### Chọn khi nào

```
Sociable (mặc định): Domain logic, business rules, collaborators đơn giản/nhanh
Solitary (khi cần):  Dependency phức tạp/chậm/non-deterministic, verify interaction
```

## Khi nào Mock, khi nào KHÔNG Mock

### Nguyên tắc vàng

```
MOCK: External service, non-deterministic (time, random), slow (DB, network),
      shared resource, cần verify interaction (gửi email? publish event?)

KHÔNG MOCK: Value Objects (Money, Email), pure logic (Calculator, Validator),
            cùng module/bounded context, khi mock phức tạp hơn real
```

### Các loại Test Doubles

```typescript
// STUB — trả về giá trị cố định
const stubPriceService: PriceService = {
  getPrice: async () => Money.of(29.99),
};

// FAKE — implementation đơn giản nhưng hoạt động (Fake > Mock cho complex interfaces)
class FakeUserRepository implements UserRepository {
  private users = new Map<string, User>();
  async save(user: User): Promise<void> { this.users.set(user.id, user); }
  async findById(id: string): Promise<User | null> { return this.users.get(id) ?? null; }
  async findByEmail(email: string): Promise<User | null> {
    return [...this.users.values()].find(u => u.email === email) ?? null;
  }
}

// MOCK — verify method được gọi đúng
const mockEmailService = { send: jest.fn() };
// SPY — wrap real implementation, track calls
const spy = jest.spyOn(realService, 'notify');
// DUMMY — placeholder, never used
const dummyLogger: Logger = { info: () => {}, error: () => {}, warn: () => {} };
```

### Anti-pattern: Over-mocking

```typescript
// ❌ Test CHỈ verify wiring, không test behavior
it('creates user', async () => {
  const mockValidator = { validate: jest.fn().mockReturnValue(true) };
  const mockHasher = { hash: jest.fn().mockResolvedValue('hash') };
  const mockRepo = { save: jest.fn() };
  const service = new UserService(mockValidator, mockHasher, mockRepo);
  await service.create({ email: 'a@b.com', password: '123' });
  expect(mockValidator.validate).toHaveBeenCalled(); // So what?
  expect(mockHasher.hash).toHaveBeenCalledWith('123'); // Proves nothing
});

// ✅ Mix real + fake, test actual behavior
it('creates user with hashed password', async () => {
  const fakeRepo = new FakeUserRepository();
  const service = new UserService(
    new PasswordValidator(),  // Real validation
    new BcryptHasher(),       // Real hashing
    fakeRepo,                 // Fake DB
  );
  const user = await service.create({ email: 'a@b.com', password: 'Str0ng!Pass' });
  const stored = await fakeRepo.findById(user.id);
  expect(stored?.passwordHash).not.toBe('Str0ng!Pass'); // Actually hashed!
});
```

## Testing Pure Functions

```typescript
// Pure function: same input → same output, no side effects
// → KHÔNG cần mock, setup, cleanup. FAST, DETERMINISTIC.

function calculateTax(subtotal: Money, taxRate: TaxRate, exemptions: TaxExemption[]): Money {
  const exemptAmount = exemptions.reduce((sum, e) => sum.add(e.amount), Money.zero());
  const taxableAmount = subtotal.subtract(exemptAmount);
  if (taxableAmount.isNegativeOrZero()) return Money.zero();
  return taxableAmount.multiply(taxRate.value);
}

describe('calculateTax', () => {
  const rate = TaxRate.of(0.1);
  it('calculates tax on full amount with no exemptions', () => {
    expect(calculateTax(Money.of(100), rate, [])).toEqual(Money.of(10));
  });
  it('subtracts exemptions before calculating', () => {
    expect(calculateTax(Money.of(100), rate, [TaxExemption.of(Money.of(20))])).toEqual(Money.of(8));
  });
  it('returns zero when exemptions exceed subtotal', () => {
    expect(calculateTax(Money.of(100), rate, [TaxExemption.of(Money.of(150))])).toEqual(Money.zero());
  });
});
// 3 tests, < 1ms → đây là sweet spot của unit testing
```

### Chiến lược: Push logic vào pure functions

```typescript
// ❌ Logic trộn với side effects → khó test
class OrderService {
  async processOrder(orderId: string): Promise<void> {
    const order = await this.repo.findById(orderId);     // side effect
    const discount = order.items.length > 5 ? 0.1 : 0;   // logic
    const total = subtotal * (1 - discount) * 1.08;       // logic
    order.total = total;                                   // mutation
    await this.repo.save(order);                           // side effect
  }
}

// ✅ Extract pure logic
function calculateOrderTotal(items: OrderItem[]): OrderCalculation {
  const subtotal = items.reduce((sum, i) => sum.add(i.price.multiply(i.quantity)), Money.zero());
  const discount = items.length > 5 ? Percentage.of(10) : Percentage.zero();
  const discountedTotal = subtotal.applyDiscount(discount);
  const tax = discountedTotal.multiply(0.08);
  return { subtotal, discount, discountedTotal, tax, grandTotal: discountedTotal.add(tax) };
}
// → 20 unit tests cho pure function, 2-3 integration tests cho orchestrator
```

## Testing Domain Logic

### Value Objects

```typescript
describe('Money', () => {
  it('rounds to 2 decimal places', () => {
    expect(Money.of(10.555).getAmount()).toBe(10.56);
  });
  it('adds same currency', () => {
    expect(Money.of(10).add(Money.of(20))).toEqual(Money.of(30));
  });
  it('refuses different currencies', () => {
    expect(() => Money.of(10, 'USD').add(Money.of(20, 'EUR'))).toThrow(CurrencyMismatchError);
  });
  it('refuses subtraction exceeding balance', () => {
    expect(() => Money.of(10).subtract(Money.of(20))).toThrow(InsufficientFundsError);
  });
  it('rejects negative amounts', () => {
    expect(() => Money.of(-5)).toThrow(InvalidMoneyError);
  });
});
```

### Aggregates — test state transitions và business invariants

```typescript
describe('BankAccount', () => {
  let account: BankAccount;
  beforeEach(() => { account = new BankAccount('acc-1', 'user-1', Money.of(1000)); });

  it('increases balance on deposit', () => {
    account.deposit(Money.of(500));
    expect(account.getBalance()).toEqual(Money.of(1500));
  });
  it('rejects withdrawal exceeding balance', () => {
    expect(() => account.withdraw(Money.of(1500))).toThrow(InsufficientFundsError);
    expect(account.getBalance()).toEqual(Money.of(1000)); // unchanged
  });
  it('blocks operations on frozen account', () => {
    account.freeze();
    expect(() => account.deposit(Money.of(100))).toThrow(AccountFrozenError);
    expect(() => account.withdraw(Money.of(100))).toThrow(AccountFrozenError);
  });
  it('maintains transaction history integrity', () => {
    account.deposit(Money.of(500));
    account.withdraw(Money.of(200));
    const computed = account.getTransactions().reduce(
      (bal, tx) => tx.type === 'deposit' ? bal.add(tx.amount) : bal.subtract(tx.amount),
      Money.of(1000),
    );
    expect(computed).toEqual(account.getBalance());
  });
});
```

## Testing Services with Dependencies

```typescript
describe('OrderService', () => {
  let orderRepo: FakeOrderRepository;
  let paymentGateway: jest.Mocked<PaymentGateway>;
  let eventPublisher: FakeEventPublisher;
  let service: OrderService;

  beforeEach(() => {
    orderRepo = new FakeOrderRepository();
    paymentGateway = { charge: jest.fn(), refund: jest.fn() };
    eventPublisher = new FakeEventPublisher();
    service = new OrderService(orderRepo, paymentGateway, eventPublisher);
  });

  it('places order when payment succeeds', async () => {
    paymentGateway.charge.mockResolvedValue({ success: true, paymentId: 'pay-123' });
    const order = await service.placeOrder({
      customerId: 'cust-1',
      items: [{ productId: 'prod-1', quantity: 2, unitPrice: Money.of(25) }],
    });
    expect(order.status).toBe('confirmed');
    expect(order.total).toEqual(Money.of(50));
    expect(await orderRepo.findById(order.id)).toEqual(order);
    expect(eventPublisher.publishedEvents).toContainEqual(
      expect.objectContaining({ type: 'OrderPlaced', orderId: order.id }),
    );
  });

  it('rejects order when payment fails — nothing persisted', async () => {
    paymentGateway.charge.mockResolvedValue({ success: false, reason: 'Declined' });
    await expect(service.placeOrder({
      customerId: 'cust-1',
      items: [{ productId: 'prod-1', quantity: 1, unitPrice: Money.of(100) }],
    })).rejects.toThrow(PaymentFailedError);
    expect(await orderRepo.count()).toBe(0);
    expect(eventPublisher.publishedEvents).toHaveLength(0);
  });
});
```

## Test Data Builders và Factories

```typescript
// Builder Pattern — highlight CHỈ những gì quan trọng cho test
class CustomerBuilder {
  private props: CustomerProps = {
    id: `cust-${randomUUID()}`, name: 'Test Customer', email: 'test@example.com',
    tier: 'standard', totalOrders: 0, totalSpent: Money.zero(),
  };
  static create() { return new CustomerBuilder(); }
  withTier(tier: CustomerTier): this { this.props.tier = tier; return this; }
  withTotalSpent(amount: Money): this { this.props.totalSpent = amount; return this; }
  asPremium(): this { return this.withTier('premium').withTotalSpent(Money.of(5000)); }
  asNewCustomer(): this { return this.withTier('standard'); }
  build(): Customer { return new Customer(this.props); }
}

// Usage — clean, focused
it('applies premium discount', () => {
  const customer = CustomerBuilder.create().asPremium().build();
  const order = OrderBuilder.create().withTotal(Money.of(200)).build();
  expect(discountEngine.calculate(customer, order)).toEqual(Money.of(30));
});

// Factory Function — alternative nhẹ hơn khi builder quá nặng
function createCustomer(overrides: Partial<CustomerProps> = {}): Customer {
  return new Customer({
    id: `cust-${randomUUID()}`, name: 'Test', email: 'test@example.com',
    tier: 'standard', totalOrders: 0, totalSpent: Money.zero(),
    ...overrides,
  });
}
```

## Property-Based Testing

```typescript
import fc from 'fast-check';

// Test PROPERTIES phải đúng cho MỌI input, không chỉ vài examples

// Commutativity: a + b = b + a
it('addition is commutative', () => {
  fc.assert(fc.property(
    fc.float({ min: 0, max: 1_000_000, noNaN: true }),
    fc.float({ min: 0, max: 1_000_000, noNaN: true }),
    (a, b) => {
      expect(Money.of(a).add(Money.of(b))).toEqual(Money.of(b).add(Money.of(a)));
    },
  ));
});

// Roundtrip: serialize → deserialize = identity
it('serialization roundtrip preserves data', () => {
  fc.assert(fc.property(
    fc.record({ name: fc.string({ minLength: 1 }), email: fc.emailAddress() }),
    (data) => { expect(JSON.parse(JSON.stringify(data))).toEqual(data); },
  ));
});

// Business invariant: discount never makes price negative
it('discount never results in negative price', () => {
  fc.assert(fc.property(
    fc.float({ min: 0.01, max: 10000, noNaN: true }),
    fc.float({ min: 0, max: 1, noNaN: true }),
    (price, rate) => {
      expect(applyDiscount(Money.of(price), Percentage.of(rate * 100)).isNegative()).toBe(false);
    },
  ));
});

// Khi đặc biệt hữu ích:
// Parsers/serializers, mathematical ops, data transformations,
// sorting/filtering, wide input ranges, finding edge cases bạn không nghĩ tới
```

## Mutation Testing

### Đo CHẤT LƯỢNG tests, không chỉ coverage

```
Coverage: "Code này ĐƯỢC CHẠY bởi test"
Mutation:  "Code này ĐƯỢC KIỂM TRA ĐÚNG bởi test"

Tool tạo "mutants" (đổi > thành >=, + thành -, xóa dòng)
→ Test FAIL = mutant bị "killed" = test tốt
→ Test PASS = mutant "survived" = test THIẾU assertion!
```

```typescript
// Source
function isEligible(customer: Customer): boolean {
  return customer.totalOrders >= 10 && customer.tier !== 'blocked';
}

// Tests trông ổn, coverage 100%
it('eligible with many orders', () => {
  expect(isEligible(createCustomer({ totalOrders: 15, tier: 'premium' }))).toBe(true);
});
it('ineligible with few orders', () => {
  expect(isEligible(createCustomer({ totalOrders: 3 }))).toBe(false);
});

// Mutation: >= 10 → > 10 → tests vẫn pass! (15 > 10 = true)
// → Missing: boundary test for totalOrders = 10 exactly
// → Missing: test for blocked tier with many orders

// Fix: thêm boundary tests
it('eligible with exactly 10 orders', () => {
  expect(isEligible(createCustomer({ totalOrders: 10 }))).toBe(true);
});
it('ineligible when blocked despite many orders', () => {
  expect(isEligible(createCustomer({ totalOrders: 100, tier: 'blocked' }))).toBe(false);
});
```

**Thực tế:** Mutation testing CHẬM. Chỉ dùng cho critical domain logic, chạy nightly.

## Complete Example

```typescript
// Restaurant reservation system — full domain model testing

class TimeSlot {
  constructor(readonly date: Date, readonly startHour: number, readonly endHour: number) {
    if (startHour >= endHour) throw new InvalidTimeSlotError('Start must be before end');
    if (startHour < 0 || endHour > 24) throw new InvalidTimeSlotError('Hours 0-24');
  }
  overlaps(other: TimeSlot): boolean {
    if (this.date.getTime() !== other.date.getTime()) return false;
    return this.startHour < other.endHour && other.startHour < this.endHour;
  }
}

class Reservation {
  private status: 'pending' | 'confirmed' | 'cancelled' = 'pending';
  constructor(
    readonly id: string, readonly tableId: string,
    readonly partySize: number, readonly timeSlot: TimeSlot,
  ) {
    if (partySize < 1 || partySize > 20) throw new InvalidPartySizeError(partySize);
  }
  confirm(): void {
    if (this.status !== 'pending') throw new InvalidStateTransitionError(this.status, 'confirmed');
    this.status = 'confirmed';
  }
  cancel(): void {
    if (this.status === 'cancelled') throw new InvalidStateTransitionError(this.status, 'cancelled');
    this.status = 'cancelled';
  }
  canCancelFree(now: Date): boolean {
    return (this.timeSlot.date.getTime() - now.getTime()) / 3_600_000 >= 24;
  }
}

describe('TimeSlot', () => {
  const today = new Date('2024-06-15');
  it('detects overlapping slots', () => {
    const a = new TimeSlot(today, 18, 20);
    expect(a.overlaps(new TimeSlot(today, 19, 21))).toBe(true);
    expect(a.overlaps(new TimeSlot(today, 17, 19))).toBe(true);
  });
  it('adjacent slots do not overlap', () => {
    const a = new TimeSlot(today, 18, 20);
    expect(a.overlaps(new TimeSlot(today, 16, 18))).toBe(false);
    expect(a.overlaps(new TimeSlot(today, 20, 22))).toBe(false);
  });
  it('different dates never overlap', () => {
    const a = new TimeSlot(today, 18, 20);
    expect(a.overlaps(new TimeSlot(new Date('2024-06-16'), 18, 20))).toBe(false);
  });
  it('rejects invalid hours', () => {
    expect(() => new TimeSlot(today, 20, 18)).toThrow();
    expect(() => new TimeSlot(today, -1, 20)).toThrow();
  });
});

describe('Reservation', () => {
  const slot = new TimeSlot(new Date('2024-06-15'), 19, 21);
  const makeRes = (size = 4) => new Reservation('r1', 'table-5', size, slot);

  it('starts in pending status', () => { expect(makeRes().getStatus()).toBe('pending'); });
  it('rejects invalid party size', () => {
    expect(() => makeRes(0)).toThrow(InvalidPartySizeError);
    expect(() => makeRes(21)).toThrow(InvalidPartySizeError);
  });
  it('accepts boundary party sizes', () => {
    expect(makeRes(1).partySize).toBe(1);
    expect(makeRes(20).partySize).toBe(20);
  });
  it('confirms pending → confirmed', () => {
    const r = makeRes(); r.confirm(); expect(r.getStatus()).toBe('confirmed');
  });
  it('cannot confirm twice', () => {
    const r = makeRes(); r.confirm();
    expect(() => r.confirm()).toThrow(InvalidStateTransitionError);
  });
  it('free cancellation 24h+ before', () => {
    const r = makeRes();
    expect(r.canCancelFree(new Date('2024-06-14T10:00:00'))).toBe(true);  // 33h before
    expect(r.canCancelFree(new Date('2024-06-15T10:00:00'))).toBe(false); // 9h before
  });
});
```

## Tổng kết

```
1. "UNIT" = behavior, không phải function/class. Mặc định dùng sociable tests.
2. Mock external dependencies. KHÔNG mock internal collaborators trừ khi cần.
3. Fake > Mock cho complex interfaces.
4. Push logic vào pure functions → easiest to test.
5. Builders cho complex test data, factories cho simple data.
6. Property-based testing cho invariants và edge cases bạn không nghĩ tới.
7. Mutation testing cho critical logic — đo test quality, không chỉ coverage.
```
