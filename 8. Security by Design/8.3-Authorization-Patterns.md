# 8.3 Authorization Patterns

## Tổng quan

Authorization (AuthZ) trả lời: **"Bạn được phép làm gì?"** — sau khi authentication đã xác minh identity. Section này cover từ RBAC đơn giản đến Zanzibar-style ReBAC.

## RBAC — Role-Based Access Control

RBAC gán permissions cho roles, rồi gán roles cho users. Đơn giản, phổ biến, nhưng có giới hạn.

```typescript
// Permissions as resource:action pairs
type Permission = 'project:create' | 'project:read' | 'project:update' |
  'project:delete' | 'user:manage' | 'billing:manage' | 'settings:manage';

interface Role {
  name: string;
  permissions: Permission[];
  inherits?: string[];  // Role hierarchy
}

const ROLES: Record<string, Role> = {
  viewer: { name: 'viewer', permissions: ['project:read'] },
  editor: { name: 'editor', permissions: ['project:create', 'project:update'], inherits: ['viewer'] },
  admin:  { name: 'admin',  permissions: ['project:delete', 'user:manage', 'settings:manage'], inherits: ['editor'] },
  owner:  { name: 'owner',  permissions: ['billing:manage'], inherits: ['admin'] },
};

// Resolve permissions including inherited roles
function resolvePermissions(roleName: string, roles: Record<string, Role>): Set<Permission> {
  const role = roles[roleName];
  if (!role) return new Set();
  const perms = new Set<Permission>(role.permissions);
  for (const parent of role.inherits ?? []) {
    resolvePermissions(parent, roles).forEach(p => perms.add(p));
  }
  return perms;
}

class RBACService {
  private cache = new Map<string, Set<Permission>>();

  constructor(roles: Record<string, Role>) {
    for (const name of Object.keys(roles)) {
      this.cache.set(name, resolvePermissions(name, roles));
    }
  }

  hasPermission(userRoles: string[], permission: Permission): boolean {
    return userRoles.some(r => this.cache.get(r)?.has(permission) ?? false);
  }

  requirePermission(...permissions: Permission[]) {
    return (req: Request, res: Response, next: NextFunction) => {
      const hasAll = permissions.every(p => this.hasPermission(req.user?.roles ?? [], p));
      if (!hasAll) { res.status(403).json({ error: 'Forbidden' }); return; }
      next();
    };
  }
}

// Usage
const rbac = new RBACService(ROLES);
app.delete('/api/projects/:id', authenticate, rbac.requirePermission('project:delete'), handler);
```

### RBAC Limitations

RBAC **cannot** express:
- "User can edit ONLY projects they created" (ownership)
- "User can read docs in their department" (attribute-based)
- "User can edit IF document status is 'draft'" (contextual)
- "User A can view User B's profile because they're on the same team" (relationship)

Khi gặp các requirements trên, cần ABAC hoặc ReBAC.

## ABAC — Attribute-Based Access Control

ABAC đánh giá quyền dựa trên **attributes** của subject, resource, action, và environment.

```typescript
interface ABACContext {
  subject: { id: string; roles: string[]; department: string; clearanceLevel: number };
  resource: { type: string; id: string; ownerId: string; classification: string; department: string; status: string };
  action: string;
  environment: { ipAddress: string; time: Date; isMfaVerified: boolean };
}

interface ABACPolicy {
  id: string;
  description: string;
  effect: 'allow' | 'deny';
  priority: number;
  condition: (ctx: ABACContext) => boolean;
}

const policies: ABACPolicy[] = [
  { id: 'require-mfa-sensitive', description: 'MFA required for confidential+ resources',
    effect: 'deny', priority: 99,
    condition: (ctx) => ['confidential', 'secret'].includes(ctx.resource.classification) && !ctx.environment.isMfaVerified },
  { id: 'clearance-check', description: 'Clearance must meet classification level',
    effect: 'deny', priority: 95,
    condition: (ctx) => {
      const levels: Record<string, number> = { public: 0, internal: 1, confidential: 2, secret: 3 };
      return ctx.subject.clearanceLevel < (levels[ctx.resource.classification] ?? 0);
    }},
  { id: 'deny-outside-hours', description: 'No sensitive data outside business hours',
    effect: 'deny', priority: 90,
    condition: (ctx) => {
      const h = ctx.environment.time.getHours();
      return ctx.resource.classification === 'confidential' && (h < 8 || h > 18);
    }},
  { id: 'owner-full-access', description: 'Resource owner has full access',
    effect: 'allow', priority: 80,
    condition: (ctx) => ctx.subject.id === ctx.resource.ownerId },
  { id: 'department-read', description: 'Read within same department',
    effect: 'allow', priority: 70,
    condition: (ctx) => ctx.action === 'read' && ctx.subject.department === ctx.resource.department },
  { id: 'edit-draft-only', description: 'Editors can only edit drafts',
    effect: 'allow', priority: 60,
    condition: (ctx) => ctx.action === 'update' && ctx.subject.roles.includes('editor') && ctx.resource.status === 'draft' },
];

class ABACEngine {
  private policies: ABACPolicy[];

  constructor(policies: ABACPolicy[]) {
    this.policies = [...policies].sort((a, b) => b.priority - a.priority);
  }

  evaluate(ctx: ABACContext): { allowed: boolean; matchedPolicy?: string } {
    // Deny-first: any matching deny → deny
    for (const p of this.policies) {
      if (p.condition(ctx) && p.effect === 'deny') return { allowed: false, matchedPolicy: p.id };
    }
    // Then check allows
    for (const p of this.policies) {
      if (p.effect === 'allow' && p.condition(ctx)) return { allowed: true, matchedPolicy: p.id };
    }
    return { allowed: false, matchedPolicy: 'default-deny' }; // Default deny
  }
}

// Middleware factory
function abacGuard(engine: ABACEngine, action: string, getResource: (req: Request) => Promise<ABACContext['resource']>) {
  return async (req: Request, res: Response, next: NextFunction) => {
    const result = engine.evaluate({
      subject: { id: req.user.id, roles: req.user.roles, department: req.user.department, clearanceLevel: req.user.clearanceLevel },
      resource: await getResource(req),
      action,
      environment: { ipAddress: req.ip ?? '', time: new Date(), isMfaVerified: req.user.mfaVerified ?? false },
    });
    if (!result.allowed) {
      logger.warn('ABAC denied', { userId: req.user.id, action, policy: result.matchedPolicy });
      res.status(403).json({ error: 'Forbidden' }); return;
    }
    next();
  };
}
```

## ReBAC — Relationship-Based Access Control (Google Zanzibar)

ReBAC mô hình quyền dựa trên **relationships** giữa objects. Google Zanzibar (Google Drive, YouTube) là reference implementation. OpenFGA là open-source.

```typescript
// Core concept: Tuple (object, relation, user)
// Ví dụ: (document:readme, viewer, user:alice) = "Alice is a viewer of readme"

// OpenFGA client — Zanzibar-style
import { OpenFgaClient } from '@openfga/sdk';

class ReBAcService {
  private fga: OpenFgaClient;

  constructor() {
    this.fga = new OpenFgaClient({
      apiUrl: process.env.OPENFGA_URL!,
      storeId: process.env.OPENFGA_STORE_ID!,
    });
  }

  async addRelation(object: string, relation: string, user: string): Promise<void> {
    await this.fga.write({ writes: [{ user, relation, object }] });
  }

  async removeRelation(object: string, relation: string, user: string): Promise<void> {
    await this.fga.write({ deletes: [{ user, relation, object }] });
  }

  async check(user: string, relation: string, object: string): Promise<boolean> {
    const resp = await this.fga.check({ user, relation, object });
    return resp.allowed ?? false;
  }

  async listObjects(user: string, relation: string, type: string): Promise<string[]> {
    const resp = await this.fga.listObjects({ user, relation, type });
    return resp.objects;
  }
}

// Usage: Google Drive-like permissions
const rebac = new ReBAcService();
await rebac.addRelation('document:doc1', 'owner', 'user:alice');
await rebac.addRelation('document:doc1', 'parent_folder', 'folder:engineering');
await rebac.addRelation('folder:engineering', 'viewer', 'user:bob');

// Bob can view doc1 via folder inheritance
const canView = await rebac.check('user:bob', 'viewer', 'document:doc1'); // true

// Middleware
function requireRelation(relation: string, objectResolver: (req: Request) => string) {
  return async (req: Request, res: Response, next: NextFunction) => {
    const allowed = await rebac.check(`user:${req.user.id}`, relation, objectResolver(req));
    if (!allowed) { res.status(403).json({ error: 'Forbidden' }); return; }
    next();
  };
}

app.get('/api/documents/:id', authenticate,
  requireRelation('viewer', (req) => `document:${req.params.id}`), handler);
```

## Permission Systems Design: CASL

CASL cho phép define permissions chạy được cả **frontend và backend** (isomorphic).

```typescript
import { AbilityBuilder, createMongoAbility, type MongoAbility } from '@casl/ability';

type Actions = 'create' | 'read' | 'update' | 'delete' | 'manage';
type Subjects = 'Project' | 'Task' | 'Comment' | 'User' | 'all';
type AppAbility = MongoAbility<[Actions, Subjects]>;

function buildAbility(user: { id: string; role: string; orgId: string; teamIds: string[] }): AppAbility {
  const { can, cannot, build } = new AbilityBuilder<AppAbility>(createMongoAbility);

  switch (user.role) {
    case 'admin':
      can('manage', 'all');
      cannot('delete', 'User', { id: user.id }); // Cannot delete self
      break;
    case 'manager':
      can('read', 'Project', { organizationId: user.orgId });
      can('create', 'Project');
      can('update', 'Project', { teamId: { $in: user.teamIds } });
      can('delete', 'Project', { ownerId: user.id });
      can('manage', 'Task', { projectTeamId: { $in: user.teamIds } });
      break;
    case 'member':
      can('read', 'Project', { organizationId: user.orgId });
      can('create', 'Task');
      can('update', 'Task', { assigneeId: user.id });
      can('manage', 'Comment', { authorId: user.id });
      can('read', 'Comment');
      break;
    case 'guest':
      can('read', 'Project', { isPublic: true });
      break;
  }
  return build();
}

// Share rules with frontend
app.get('/api/auth/permissions', authenticate, (req, res) => {
  res.json({ rules: buildAbility(req.user).rules });
});
```

### PostgreSQL RLS

```sql
ALTER TABLE projects ENABLE ROW LEVEL SECURITY;

-- Users see only their org's projects
CREATE POLICY tenant_isolation ON projects
  USING (organization_id = current_setting('app.current_org_id')::uuid);

-- Users update only their own projects

  FOR UPDATE USING (owner_id = current_setting('app.current_user_id')::uuid);
```

```typescript
// TypeScript: set RLS context per request
import { Pool, type PoolClient } from 'pg';

class TenantAwareDB {
  constructor(private pool: Pool) {}

  async query<T>(tenantId: string, userId: string, sql: string, params: unknown[]): Promise<T[]> {
    const client = await this.pool.connect();
    try {
      await client.query("SELECT set_config('app.current_org_id', $1, true)", [tenantId]);
      await client.query("SELECT set_config('app.current_user_id', $1, true)", [userId]);
      const result = await client.query(sql, params);
      return result.rows as T[];
    } finally { client.release(); }
  }
}

// Middleware — developer KHÔNG CẦN think about tenant filtering
app.get('/api/projects', authenticate, async (req, res) => {
  const projects = await req.db.query('SELECT * FROM projects', []);
  res.json(projects); // RLS tự động filter
});
```

## Multi-Tenancy Authorization

```typescript
// Tenant-scoped operations — ALWAYS inject tenantId
class TenantScopedService<T extends { tenantId: string }> {
  constructor(private repo: Repository<T>, private tenantId: string) {}

  async findAll(filter: Partial<T> = {}): Promise<T[]> {
    return this.repo.find({ where: { ...filter, tenantId: this.tenantId } as any });
  }

  async update(id: string, data: Partial<T>): Promise<T> {
    const existing = await this.repo.findOne({ where: { id, tenantId: this.tenantId } as any });
    if (!existing) throw new AppError(404, 'Not found', 'Wrong tenant', 'NOT_FOUND');
    delete (data as any).tenantId; // Prevent tenant change
    return this.repo.save({ ...existing, ...data });
  }

  async delete(id: string): Promise<void> {
    const result = await this.repo.delete({ id, tenantId: this.tenantId } as any);
    if (result.affected === 0) throw new AppError(404, 'Not found', 'Wrong tenant', 'NOT_FOUND');
  }
}

// Cross-tenant access (platform admins only) — with audit trail
class PlatformAdminService {
  async accessTenant(adminId: string, targetTenantId: string, reason: string): Promise<TenantContext> {
    const admin = await db.users.findById(adminId);
    if (!admin.isPlatformAdmin) throw new AppError(403, 'Forbidden', 'Not admin', 'FORBIDDEN');

    await auditLogger.log({
      userId: adminId, action: 'CROSS_TENANT_ACCESS',
      resource: 'tenant', resourceId: targetTenantId,
      details: { reason }, ipAddress: '', userAgent: '',
    });
    return { tenantId: targetTenantId, userId: adminId, role: 'platform_admin' };
  }
}
```

## API Authorization: Three Layers

```typescript
// Layer 1: OAuth Scope — "Does token have right scopes?"
function requireScopes(...required: string[]) {
  return (req: Request, res: Response, next: NextFunction) => {
    const scopes = req.auth?.scope?.split(' ') ?? [];
    if (!required.every(s => scopes.includes(s))) {
      res.status(403).json({ error: 'insufficient_scope', required }); return;
    }
    next();
  };
}

// Layer 2: Permission — "Does user have right permissions?"
function requirePermissions(...perms: Permission[]) {
  return (req: Request, res: Response, next: NextFunction) => {
    if (!perms.every(p => resolveUserPermissions(req.user).has(p))) {
      res.status(403).json({ error: 'Forbidden' }); return;
    }
    next();
  };
}

// Layer 3: Resource — "Does user own/have access to THIS resource?"
function requireResourceAccess<T>(
  fetch: (req: Request) => Promise<T | null>,
  check: (user: AuthUser, resource: T) => boolean
) {
  return async (req: Request, res: Response, next: NextFunction) => {
    const resource = await fetch(req);
    if (!resource || !check(req.user, resource)) {
      res.status(404).json({ error: 'Not found' }); return; // 404, not 403
    }
    req.resource = resource;
    next();
  };
}

// Combined: all three layers
app.put('/api/projects/:id',
  authenticate,
  requireScopes('projects:write'),
  requirePermissions('project:update'),
  requireResourceAccess(
    (req) => projectService.findById(req.params.id),
    (user, project) => project.orgId === user.orgId && (project.ownerId === user.id || user.roles.includes('admin'))
  ),
  async (req, res) => { res.json(await projectService.update(req.params.id, req.body)); }
);
```

## Building a Flexible Authorization Engine

```typescript
// Unified engine: RBAC + ABAC + ReBAC combined
type PolicyEvaluator = (req: AuthorizationRequest) => Promise<'allow' | 'deny' | 'abstain'>;

interface AuthorizationRequest {
  subject: { id: string; type: string; attributes: Record<string, unknown> };
  action: string;
  resource: { type: string; id: string; attributes: Record<string, unknown> };
  context: Record<string, unknown>;
}

class AuthorizationEngine {
  private policies: Array<{ id: string; priority: number; evaluator: PolicyEvaluator }> = [];

  addPolicy(id: string, priority: number, evaluator: PolicyEvaluator): void {
    this.policies.push({ id, priority, evaluator });
    this.policies.sort((a, b) => b.priority - a.priority);
  }

  async evaluate(req: AuthorizationRequest): Promise<{ allowed: boolean; reason: string }> {
    for (const policy of this.policies) {
      const result = await policy.evaluator(req);
      if (result === 'deny') return { allowed: false, reason: `Denied by ${policy.id}` };
      if (result === 'allow') return { allowed: true, reason: `Allowed by ${policy.id}` };
    }
    return { allowed: false, reason: 'default-deny' };
  }
}

// Register policies
const engine = new AuthorizationEngine();

engine.addPolicy('tenant-isolation', 100, async (req) => {
  const uTenant = req.subject.attributes['tenantId'];
  const rTenant = req.resource.attributes['tenantId'];
  return uTenant && rTenant && uTenant !== rTenant ? 'deny' : 'abstain';
});

engine.addPolicy('ownership', 60, async (req) => {
  return req.resource.attributes['ownerId'] === req.subject.id ? 'allow' : 'abstain';
});

engine.addPolicy('rbac', 50, async (req) => {
  const roles = req.subject.attributes['roles'] as string[];
  const perm = `${req.resource.type}:${req.action}` as Permission;
  return rbac.hasPermission(roles, perm) ? 'allow' : 'abstain';
});

engine.addPolicy('rebac', 40, async (req) => {
  const relation = req.action === 'read' ? 'viewer' : 'editor';
  const allowed = await rebacService.check(
    `${req.subject.type}:${req.subject.id}`, relation,
    `${req.resource.type}:${req.resource.id}`);
  return allowed ? 'allow' : 'abstain';
});
```

## Chọn Authorization Model nào?

| Model | Use Case | Complexity | Example |
|-------|----------|------------|---------|
| **RBAC** | Clear role hierarchy | Low | Admin/Editor/Viewer |
| **ABAC** | Context-dependent policies | Medium | "Managers approve expenses < $10k" |
| **ReBAC** | Sharing, nested permissions | High | Google Drive, Notion |
| **Hybrid** | Most production SaaS | Medium-High | RBAC base + ABAC + ReBAC sharing |

### Decision Checklist

```
Need role hierarchy?                    → Start with RBAC
Need context-dependent decisions?       → Add ABAC
Need object-level sharing/inheritance?  → Add ReBAC
Need multi-tenancy?                     → Tenant isolation is non-negotiable
Need audit trail?                       → Log every authorization decision
Need frontend permission checks?        → CASL or similar isomorphic library
```
