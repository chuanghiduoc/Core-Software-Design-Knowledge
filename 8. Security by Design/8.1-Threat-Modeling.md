# 8.1 Threat Modeling

## Threat Modeling là gì và tại sao mọi engineer cần biết

Threat modeling là quá trình **có hệ thống** để xác định, đánh giá, và ưu tiên các mối đe dọa bảo mật. Thay vì đợi pentester tìm lỗi, bạn chủ động phân tích: "Hệ thống bị tấn công ở đâu? Bằng cách nào? Hậu quả ra sao?"

### Tại sao engineer — không chỉ security team — cần làm threat modeling?

1. **Bạn hiểu hệ thống rõ nhất** — Security team không biết business logic bằng developer
2. **Phát hiện sớm = fix rẻ** — Lỗ hổng ở design phase rẻ hơn 100x so với production
3. **Security mindset** — Threat modeling xây dựng tư duy "attacker perspective"
4. **Compliance** — SOC2, ISO 27001, PCI-DSS đều yêu cầu threat modeling

### Bốn câu hỏi cốt lõi

```
1. What are we building?        → System model (DFD, architecture)
2. What can go wrong?           → Threat identification (STRIDE)
3. What are we going to do?     → Mitigation strategies
4. Did we do a good enough job? → Validation & review
```

## STRIDE Framework

STRIDE là framework phân loại threats từ Microsoft. Mỗi chữ cái đại diện cho một loại threat:

### S — Spoofing (Giả mạo danh tính)

```typescript
// VULNERABLE: Không verify JWT signature
function vulnerableDecode(token: string) {
  return jwt.decode(token); // Bất kỳ ai cũng craft được token
}

// MITIGATED: Verify signature + issuer + audience
function verifyToken(token: string): TokenPayload {
  return jwt.verify(token, getPublicKeyFromJWKS(), {
    algorithms: ['RS256'],            // Chỉ chấp nhận RS256
    issuer: 'https://auth.myapp.com', // Verify issuer
    audience: 'my-api',               // Verify audience
    clockTolerance: 30,
  }) as TokenPayload;
}
```

### T — Tampering (Giả mạo dữ liệu)

```typescript
// VULNERABLE: Trust client-sent price
app.post('/api/orders', (req, res) => {
  db.orders.create({ price: req.body.price }); // Attacker sửa price = 0
});

// MITIGATED: Server-side lookup + HMAC integrity
async function createOrder(req: OrderRequest, userId: string) {
  const product = await db.products.findById(req.productId);
  if (!product) throw new Error('Product not found');
  return db.orders.create({
    userId, productId: req.productId, quantity: req.quantity,
    unitPrice: product.price, totalPrice: product.price * req.quantity,
  });
}

// HMAC data integrity verification
function verifyDataIntegrity(data: string, signature: string, secret: string): boolean {
  const expected = crypto.createHmac('sha256', secret).update(data).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(signature, 'hex'), Buffer.from(expected, 'hex'));
}
```

### R — Repudiation (Chối bỏ hành vi)

```typescript
// MITIGATED: Append-only audit log với hash chain
interface AuditEntry {
  id: string;
  timestamp: Date;
  userId: string;
  action: string;
  resource: string;
  resourceId: string;
  details: Record<string, unknown>;
  ipAddress: string;
  previousHash: string;
  hash: string;
}

class AuditLogger {
  private lastHash = 'GENESIS';

  async log(entry: Omit<AuditEntry, 'id' | 'hash' | 'previousHash' | 'timestamp'>): Promise<void> {
    const timestamp = new Date();
    const dataToHash = JSON.stringify({ ...entry, timestamp, previousHash: this.lastHash });
    const hash = crypto.createHash('sha256').update(dataToHash).digest('hex');
    this.lastHash = hash;

    await this.appendOnlyStore.insert({
      id: crypto.randomUUID(), ...entry, timestamp, previousHash: this.lastHash, hash,
    });
    await this.siem.send({ ...entry, timestamp, hash }); // External copy
  }

  async verifyChain(): Promise<boolean> {
    const entries = await this.appendOnlyStore.findAll({ order: 'timestamp ASC' });
    let expectedPrev = 'GENESIS';
    for (const entry of entries) {
      if (entry.previousHash !== expectedPrev) return false;
      const { hash, ...data } = entry;
      const computed = crypto.createHash('sha256')
        .update(JSON.stringify({ ...data, previousHash: expectedPrev })).digest('hex');
      if (computed !== hash) return false;
      expectedPrev = hash;
    }
    return true;
  }
}
```

### I — Information Disclosure (Lộ thông tin)

```typescript
// VULNERABLE: Stack trace trong response
app.use((err: Error, req: Request, res: Response, next: NextFunction) => {
  res.status(500).json({ error: err.message, stack: err.stack }); // Lộ internal info
});

// MITIGATED: Sanitized errors + response filtering
class AppError extends Error {
  constructor(
    public statusCode: number,
    public userMessage: string,     // Message cho client
    public internalMessage: string, // Message cho logging
    public errorCode: string,
  ) { super(internalMessage); }
}

app.use((err: Error, req: Request, res: Response, next: NextFunction) => {
  if (err instanceof AppError) {
    logger.error({ errorCode: err.errorCode, message: err.internalMessage, stack: err.stack });
    res.status(err.statusCode).json({ error: err.userMessage, code: err.errorCode, requestId: req.id });
  } else {
    logger.error({ message: err.message, stack: err.stack });
    res.status(500).json({ error: 'An unexpected error occurred', requestId: req.id });
  }
});

// Response filtering — explicit allowlist
function toUserResponse(user: UserDB): UserResponse {
  return { id: user.id, email: user.email }; // Không trả passwordHash, ssn, etc.
}
```

```typescript
// MITIGATED: Multi-layer DoS protection
app.use(express.json({ limit: '1mb' }));

const apiLimiter = rateLimit({
  windowMs: 15 * 60 * 1000, max: 100,
  standardHeaders: true, legacyHeaders: false,
  keyGenerator: (req) => req.ip ?? 'unknown',

app.use('/api/', apiLimiter);

// GraphQL complexity limiting
const validationRules = [depthLimit(5), createComplexityLimitRule(1000)];

function getPaginatedResults<T>(query: QueryBuilder<T>, page: number, limit: number) {
  const safeLimit = Math.min(Math.max(limit, 1), 100);
  return query.offset((Math.max(page, 1) - 1) * safeLimit).limit(safeLimit);
}
```

## Data Flow Diagrams cho Threat Identification

DFD visualize cách data di chuyển qua hệ thống — mỗi điểm data cross trust boundary cần kiểm tra threat.

```typescript
type TrustBoundary = 'internet' | 'dmz' | 'internal_network' | 'database_tier';

interface DFDElement {
  id: string;
  name: string;
  type: 'external_entity' | 'process' | 'data_store';
  trustBoundary: TrustBoundary;
}

interface DataFlow {
  id: string;
  from: string;
  to: string;
  data: string;
  protocol: string;
  encrypted: boolean;
  authenticated: boolean;
}

// E-commerce DFD example
const elements: DFDElement[] = [
  { id: 'user',    name: 'Browser',    type: 'external_entity', trustBoundary: 'internet' },
  { id: 'cdn',     name: 'CDN',        type: 'process',         trustBoundary: 'dmz' },
  { id: 'api',     name: 'API Server', type: 'process',         trustBoundary: 'internal_network' },
  { id: 'db',      name: 'PostgreSQL', type: 'data_store',      trustBoundary: 'database_tier' },
  { id: 'payment', name: 'Stripe',     type: 'external_entity', trustBoundary: 'internet' },
];

const flows: DataFlow[] = [
  { id: 'f1', from: 'user', to: 'cdn',     data: 'HTTP requests',    protocol: 'HTTPS', encrypted: true,  authenticated: false },
  { id: 'f2', from: 'cdn',  to: 'api',     data: 'Proxied requests', protocol: 'HTTPS', encrypted: true,  authenticated: false },
  { id: 'f3', from: 'api',  to: 'db',      data: 'SQL queries',      protocol: 'TLS',   encrypted: true,  authenticated: true },
  { id: 'f4', from: 'api',  to: 'payment', data: 'Payment intents',  protocol: 'HTTPS', encrypted: true,  authenticated: true },
];

// Auto-identify threats at trust boundary crossings
function identifyBoundaryCrossingThreats(elements: DFDElement[], flows: DataFlow[]) {
  const elementMap = new Map(elements.map(e => [e.id, e]));
  return flows
    .map(flow => {
      const from = elementMap.get(flow.from)!, to = elementMap.get(flow.to)!;
      const threats: string[] = [];
      if (from.trustBoundary !== to.trustBoundary) {
        threats.push('BOUNDARY_CROSSING');
        if (!flow.encrypted) threats.push('TAMPERING: Unencrypted');
        if (!flow.authenticated) threats.push('SPOOFING: Unauthenticated');
      }
      if (/payment|credential/i.test(flow.data)) threats.push('INFO_DISCLOSURE: Sensitive data');
      return { flow, threats };
    })
    .filter(r => r.threats.length > 0);
}
```

## Attack Trees

Attack tree mô hình hóa các cách attacker đạt mục tiêu. Root = goal, children = methods.

```typescript
interface AttackNode {
  id: string;
  description: string;
  type: 'AND' | 'OR';  // AND = cần tất cả children, OR = cần 1
  likelihood: number;   // 0-1
  impact: number;       // 0-1
  mitigations: string[];
  children: AttackNode[];
}

const stealDataTree: AttackNode = {
  id: 'root',
  description: 'Steal user PII from database',
  type: 'OR', likelihood: 0.3, impact: 1.0, mitigations: [],
  children: [
    {
      id: 'sqli', description: 'SQL Injection',
      type: 'AND', likelihood: 0.2, impact: 1.0,
      mitigations: ['Parameterized queries', 'WAF', 'Input validation'],
      children: [
        { id: 'find-sqli', description: 'Find injectable param', type: 'OR',
          likelihood: 0.3, impact: 0.5, mitigations: ['SAST', 'Code review'], children: [] },
        { id: 'exfiltrate', description: 'Extract via UNION/blind SQLi', type: 'OR',
          likelihood: 0.5, impact: 1.0, mitigations: ['Least-privilege DB user'], children: [] },
      ],
    },
    {
      id: 'creds', description: 'Compromise admin credentials',
      type: 'OR', likelihood: 0.4, impact: 1.0,
      mitigations: ['MFA', 'Credential rotation', 'Access logging'],
      children: [
        { id: 'phishing', description: 'Phishing attack', type: 'OR',
          likelihood: 0.5, impact: 0.8, mitigations: ['Security training', 'WebAuthn'], children: [] },
        { id: 'leaked', description: 'Secrets in git/logs', type: 'OR',
          likelihood: 0.3, impact: 1.0, mitigations: ['GitLeaks', 'Secrets manager'], children: [] },
      ],
    },
  ],
};

// Calculate risk score per path
function calculateRisk(node: AttackNode): number {
  if (node.children.length === 0) return node.likelihood * node.impact;
  const childRisks = node.children.map(c => calculateRisk(c));
  if (node.type === 'OR') {
    return (1 - childRisks.reduce((acc, r) => acc * (1 - r), 1)) * node.impact;
  }
  return childRisks.reduce((acc, r) => acc * r, 1) * node.impact;
}
```

## Risk Assessment: Likelihood x Impact

```typescript
type Severity = 'critical' | 'high' | 'medium' | 'low' | 'info';

interface ThreatAssessment {
  threatId: string;
  title: string;
  strideCategory: 'S' | 'T' | 'R' | 'I' | 'D' | 'E';
  likelihood: 1 | 2 | 3 | 4 | 5;  // 1=rare, 5=almost certain
  impact: 1 | 2 | 3 | 4 | 5;      // 1=negligible, 5=catastrophic
  severity: Severity;
  mitigations: string[];
  status: 'identified' | 'mitigated' | 'accepted' | 'transferred';
}

function assessRisk(likelihood: number, impact: number): { score: number; severity: Severity } {
  const score = likelihood * impact;
  const severity: Severity =
    score >= 20 ? 'critical' :
    score >= 12 ? 'high' :
    score >= 6  ? 'medium' :
    score >= 2  ? 'low' : 'info';
  return { score, severity };
}
```

## Common Threat Patterns cho SaaS Applications

```typescript
// Pattern 1: Multi-tenant data leakage → Tenant-scoped repository
class TenantScopedRepository<T> {
  constructor(private repo: Repository<T>, private tenantId: string) {}

  async findById(id: string): Promise<T | null> {
    const entity = await this.repo.findOne({ where: { id } as any });
    if (entity && (entity as any).tenantId !== this.tenantId) {
      logger.warn('Cross-tenant access attempt', { tenantId: this.tenantId, resourceId: id });
      return null;
    }
    return entity;
  }
}

// Pattern 2: Webhook verification (chống fake events + replay)
function verifyWebhookSignature(payload: string, signature: string, secret: string): boolean {
  const [timestamp, sig] = signature.split(',');
  const ts = parseInt(timestamp.replace('t=', ''), 10);
  if (Math.abs(Date.now() / 1000 - ts) > 300) return false; // 5min tolerance
  const expected = crypto.createHmac('sha256', secret).update(`${ts}.${payload}`).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(sig.replace('v1=', '')), Buffer.from(expected));
}

// Pattern 3: File upload validation (magic bytes, not Content-Type)
async function validateUpload(file: UploadedFile, config: FileUploadConfig) {
  if (file.size > config.maxSizeBytes) return { valid: false, reason: 'Too large' };
  const ext = path.extname(file.originalname).toLowerCase();
  if (!config.allowedExtensions.includes(ext)) return { valid: false, reason: 'Type not allowed' };
  const { fileTypeFromBuffer } = await import('file-type');
  const detected = await fileTypeFromBuffer(file.buffer);
  if (!detected || !config.allowedMimeTypes.includes(detected.mime))
    return { valid: false, reason: 'Content mismatch' };
  return { valid: true };
}
```
