## Bản chất

Separation of Concerns (SoC) là nguyên lý nền tảng nhất: **mỗi phần của hệ thống chỉ nên giải quyết MỘT concern (mối quan tâm) riêng biệt**. Thay đổi concern A không nên ảnh hưởng concern B.

SoC là meta-principle — SRP, ISP, và nhiều pattern khác đều là biểu hiện cụ thể của SoC.

### Concern là gì?

Concern = một khía cạnh riêng biệt của hệ thống mà có thể thay đổi độc lập.

```
Ví dụ concerns trong web app:
├── Business logic (rules nghiệp vụ)
├── Data access (CRUD, queries)
├── Presentation (UI rendering)
├── Routing (URL → handler mapping)
├── Authentication (ai đang dùng?)
├── Authorization (được phép làm gì?)
├── Validation (input có hợp lệ?)
├── Error handling (xử lý khi sai)
├── Logging (ghi nhận hoạt động)
├── Caching (tối ưu performance)
└── Configuration (environment-specific settings)
```

## SoC ở mọi cấp độ

### Level 1: Function level

```typescript
// ❌ Một function làm quá nhiều concerns
async function handleCreateUser(req: Request, res: Response): Promise<void> {
  // Concern 1: Validation
  if (!req.body.email || !req.body.email.includes('@')) {
    res.status(400).json({ error: 'Invalid email' });
    return;
  }
  if (!req.body.name || req.body.name.length < 2) {
    res.status(400).json({ error: 'Name too short' });
    return;
  }

  // Concern 2: Authorization
  if (req.user.role !== 'admin') {
    res.status(403).json({ error: 'Not authorized' });
    return;
  }

  // Concern 3: Business logic
  const existingUser = await db.query('SELECT id FROM users WHERE email=$1', [req.body.email]);
  if (existingUser.rows.length > 0) {
    res.status(409).json({ error: 'Email already exists' });
    return;
  }

  // Concern 4: Data access
  const hashedPassword = await bcrypt.hash(req.body.password, 12);
  const result = await db.query(
    'INSERT INTO users (name, email, password_hash) VALUES ($1, $2, $3) RETURNING id',
    [req.body.name, req.body.email, hashedPassword]
  );

  // Concern 5: Side effects
  await sendWelcomeEmail(req.body.email, req.body.name);

  // Concern 6: Logging
  console.log(`User created: ${result.rows[0].id}`);

  // Concern 7: Response formatting
  res.status(201).json({ id: result.rows[0].id, name: req.body.name, email: req.body.email });
}
```

```typescript
// validation/user.validation.ts
const CreateUserSchema = z.object({
  name: z.string().min(2).max(100),
  email: z.string().email(),
  password: z.string().min(8).max(128),
});

type CreateUserInput = z.infer<typeof CreateUserSchema>;

// domain/user.service.ts — Business logic ONLY
class UserService {
  constructor(
    private readonly users: UserRepository,
    private readonly hasher: PasswordHasher,
    private readonly events: EventBus,
  ) {}

  async createUser(input: CreateUserInput): Promise<User> {
    const existing = await this.users.findByEmail(input.email);
    if (existing) throw new DuplicateEmailError(input.email);

    const passwordHash = await this.hasher.hash(input.password);
    const user = User.create(input.name, input.email, passwordHash);

    await this.users.save(user);
    await this.events.publish(new UserCreatedEvent(user));

    return user;
  }
}

// http/controllers/user.controller.ts — HTTP concern ONLY
class UserController {
  constructor(private readonly userService: UserService) {}

  async create(req: Request, res: Response): Promise<void> {
    const input = CreateUserSchema.parse(req.body); // Validation concern
    const user = await this.userService.createUser(input); // Delegates to service
    res.status(201).json(UserDto.from(user)); // Response formatting concern
  }
}

// event-handlers/user-created.handler.ts — Side effects ONLY
class UserCreatedHandler {
  constructor(private readonly mailer: Mailer) {}

  async handle(event: UserCreatedEvent): Promise<void> {
    await this.mailer.send({
      to: event.user.email,
      template: 'welcome',
      data: { name: event.user.name },
    });
  }
}

// middleware/auth.middleware.ts — Auth concern ONLY
function requireRole(...roles: Role[]): Middleware {
  return (req, res, next) => {
    if (!req.user || !roles.includes(req.user.role)) {
      throw new UnauthorizedError('Insufficient permissions');
    }
    next();
  };
}

// routes/user.routes.ts — Routing concern ONLY
router.post('/users',
  requireRole('admin'),           // Auth
  validate(CreateUserSchema),     // Validation
  controller.create.bind(controller), // Handler
```

## Layered Architecture

### Clean Architecture Layers trong TypeScript

```typescript
// Layer 1: Domain (innermost — zero dependencies)
// domain/entities/order.ts
class Order {
  private constructor(
    readonly id: OrderId,
    readonly customerId: CustomerId,
    private _items: ReadonlyArray<OrderItem>,
    private _status: OrderStatus,
    readonly createdAt: Date,
  ) {}

  static create(customerId: CustomerId, items: ReadonlyArray<OrderItem>): Order {
    if (items.length === 0) throw new EmptyOrderError();
    return new Order(OrderId.generate(), customerId, items, 'pending', new Date());
  }

  get total(): Money {
    return this._items.reduce(
      (sum, item) => sum.add(item.subtotal),
      Money.zero('USD'),
    );
  }

  get status(): OrderStatus { return this._status; }

  confirm(): void {
    if (this._status !== 'pending') {
      throw new InvalidOrderTransitionError(this._status, 'confirmed');
    }
    this._status = 'confirmed';
  }

  cancel(reason: string): void {
    if (this._status === 'shipped' || this._status === 'delivered') {
      throw new InvalidOrderTransitionError(this._status, 'cancelled');
    }
    this._status = 'cancelled';
  }
}

// Layer 2: Application (use cases — depends only on domain)
// application/place-order.usecase.ts
class PlaceOrderUseCase {
  constructor(
    private readonly orders: OrderRepository,       // Port (interface)
    private readonly inventory: InventoryService,   // Port
    private readonly payment: PaymentGateway,       // Port
  ) {}

  async execute(command: PlaceOrderCommand): Promise<PlaceOrderResult> {
    // Orchestrate domain objects
    const items = command.items.map(i => OrderItem.create(i.productId, i.quantity, i.unitPrice));
    const order = Order.create(command.customerId, items);

    // Check inventory
    const available = await this.inventory.checkAvailability(items);
    if (!available.allInStock) {
      return PlaceOrderResult.outOfStock(available.unavailableItems);
    }

    // Process payment
    const paymentResult = await this.payment.charge(order.total, command.paymentMethod);
    if (!paymentResult.success) {
      return PlaceOrderResult.paymentFailed(paymentResult.error);
    }

    // Confirm and save
    order.confirm();
    await this.orders.save(order);
    await this.inventory.reserve(items);

    return PlaceOrderResult.success(order);
  }
}

// Layer 3: Infrastructure (outermost — implements ports)
// infrastructure/repositories/postgres-order.repository.ts
class PostgresOrderRepository implements OrderRepository {
  constructor(private readonly db: Knex) {}

  async save(order: Order): Promise<void> {
    await this.db.transaction(async trx => {
      await trx('orders').insert({
        id: order.id,
        customer_id: order.customerId,
        status: order.status,
        total_cents: order.total.cents,
        created_at: order.createdAt,
      });

      const itemRows = order.items.map((item, idx) => ({
        order_id: order.id,
        product_id: item.productId,
        quantity: item.quantity,
        unit_price_cents: item.unitPrice.cents,
        position: idx,
      }));

      await trx('order_items').insert(itemRows);
    });
  }
}

// Layer 4: Transport/Presentation (HTTP, GraphQL, CLI)
// http/controllers/order.controller.ts
class OrderController {
  constructor(private readonly placeOrder: PlaceOrderUseCase) {}

  async create(req: Request, res: Response): Promise<void> {
    const command = PlaceOrderCommand.fromHttp(req.body, req.user.id);
    const result = await this.placeOrder.execute(command);

    if (result.isSuccess) {
      res.status(201).json(OrderDto.from(result.order));
    } else if (result.isOutOfStock) {
      res.status(409).json({ error: 'Items out of stock', items: result.unavailableItems });
    } else {
      res.status(402).json({ error: 'Payment failed', details: result.paymentError });
    }
  }
}
```

### Dependency Rule

```
┌─────────────────────────────────────────────────────────────┐
│  Transport Layer (HTTP, GraphQL, CLI, WebSocket)            │
│  → Depends on Application Layer                             │
├─────────────────────────────────────────────────────────────┤
│  Infrastructure Layer (DB, Cache, External APIs, Queue)     │
│  → Depends on Domain Layer (implements interfaces)          │
├─────────────────────────────────────────────────────────────┤
│  Application Layer (Use Cases, DTOs, Commands/Queries)      │
│  → Depends on Domain Layer                                  │
├─────────────────────────────────────────────────────────────┤
│  Domain Layer (Entities, Value Objects, Domain Services)    │
│  → Depends on NOTHING                                       │
└─────────────────────────────────────────────────────────────┘

Dependencies point INWARD. Inner layers NEVER import from outer layers.
```

```typescript
function useSortedFilteredList<T>(
  items: ReadonlyArray<T>,
  config: {
    filterFn: (item: T, query: string) => boolean;
    sortFn: (a: T, b: T) => number;
    filterQuery: string;
  },
): ReadonlyArray<T> {
  return useMemo(() => {
    const filtered = items.filter(item => config.filterFn(item, config.filterQuery));
    return [...filtered].sort(config.sortFn);
  }, [items, config.filterQuery, config.filterFn, config.sortFn]);
}
```

### Request Pipeline — Mỗi middleware = 1 concern

```typescript
// Express/Fastify pipeline: mỗi middleware xử lý đúng 1 concern

// Concern: Request ID tracking
const requestId: Middleware = (req, _res, next) => {
  req.id = req.headers['x-request-id'] as string ?? crypto.randomUUID();
  next();
};

// Concern: Request logging
const requestLogger: Middleware = (req, res, next) => {
  const start = Date.now();
  res.on('finish', () => {
    logger.info({
      requestId: req.id,
      method: req.method,
      url: req.url,
      status: res.statusCode,
      durationMs: Date.now() - start,
    });
  });
  next();
};

// Concern: Rate limiting
const rateLimiter = rateLimit({
  windowMs: 60_000,
  max: 100,
  keyGenerator: (req) => req.ip ?? 'unknown',
});

// Concern: Body parsing + size limit
const bodyParser = express.json({ limit: '1mb' });

// Concern: CORS
const cors = corsMiddleware({ origin: config.allowedOrigins });

// Concern: Authentication
const authenticate: Middleware = async (req, _res, next) => {
  const token = req.headers.authorization?.replace('Bearer ', '');
  if (token) {
    req.user = await tokenService.verify(token);
  }
  next();
};

// Compose pipeline — each concern is isolated and reorderable
app.use(requestId);
app.use(requestLogger);
app.use(cors);
app.use(rateLimiter);
app.use(bodyParser);
app.use(authenticate);
```

### CQRS — Tách Read và Write concerns

```typescript
// Command (Write) — focus on business rules, validation, consistency
interface Command<TResult = void> {
  readonly type: string;
}

interface CommandHandler<TCommand extends Command<TResult>, TResult = void> {
  execute(command: TCommand): Promise<TResult>;
}

class CreateProjectCommand implements Command<ProjectId> {
  readonly type = 'CreateProject';
  constructor(
    readonly name: string,
    readonly ownerId: UserId,
    readonly visibility: 'public' | 'private',
  ) {}
}

class CreateProjectHandler implements CommandHandler<CreateProjectCommand, ProjectId> {
  constructor(
    private readonly projects: ProjectRepository,
    private readonly permissions: PermissionService,
  ) {}

  async execute(command: CreateProjectCommand): Promise<ProjectId> {
    await this.permissions.assertCanCreateProject(command.ownerId);

    const project = Project.create(command.name, command.ownerId, command.visibility);
    await this.projects.save(project);

    return project.id;
  }
}

// Query (Read) — focus on performance, denormalized views, caching
interface Query<TResult> {
  readonly type: string;
}

interface QueryHandler<TQuery extends Query<TResult>, TResult> {
  execute(query: TQuery): Promise<TResult>;
}

class GetProjectDashboardQuery implements Query<ProjectDashboard> {
  readonly type = 'GetProjectDashboard';
  constructor(readonly projectId: ProjectId, readonly userId: UserId) {}
}

class GetProjectDashboardHandler
  implements QueryHandler<GetProjectDashboardQuery, ProjectDashboard> {
  constructor(private readonly db: Knex) {}

  async execute(query: GetProjectDashboardQuery): Promise<ProjectDashboard> {
    // Optimized read query — can use denormalized views, joins, caching
    // No business rules here, pure data retrieval
    const [project, recentActivity, memberCount, openIssues] = await Promise.all([
      this.db('projects').where('id', query.projectId).first(),
      this.db('activity_log')
        .where('project_id', query.projectId)
        .orderBy('created_at', 'desc')
        .limit(10),
      this.db('project_members').where('project_id', query.projectId).count().first(),
      this.db('issues')
        .where({ project_id: query.projectId, status: 'open' })
        .count()
        .first(),
    ]);

    return {
      project,
      recentActivity,
      stats: {
        memberCount: Number(memberCount?.count ?? 0),
        openIssues: Number(openIssues?.count ?? 0),
      },
    };
  }
}
```

## Cross-cutting Concerns

Một số concerns "cắt ngang" nhiều layers: logging, error handling, caching, auth. Giải pháp:

### Approach 1: Middleware / Decorator

```typescript
// Logging decorator — apply to any use case without modifying it

function withLogging<TInput, TOutput>(
  useCase: { execute(input: TInput): Promise<TOutput> },
  logger: Logger,
  useCaseName: string,
): { execute(input: TInput): Promise<TOutput> } {
  return {
    async execute(input: TInput): Promise<TOutput> {
      const start = performance.now();
      logger.info(`${useCaseName} started`, { input });

      try {
        const result = await useCase.execute(input);
        const duration = performance.now() - start;
        logger.info(`${useCaseName} completed`, { durationMs: Math.round(duration) });
        return result;
      } catch (error) {
        const duration = performance.now() - start;
        logger.error(`${useCaseName} failed`, {
          error: String(error),
          durationMs: Math.round(duration),
        });
        throw error;
      }
    },
  };
}

// Apply cross-cutting concerns without polluting business logic
const placeOrder = withLogging(
  new PlaceOrderUseCase(orderRepo, inventory, payment),
  logger,
  'PlaceOrder',
);
```

### Approach 2: Event-driven side effects

```typescript
// Business logic emits events → separate handlers for cross-cutting concerns

class OrderService {
  async placeOrder(command: PlaceOrderCommand): Promise<Order> {
    const order = Order.create(command);
    await this.orders.save(order);

    // Emit event — doesn't care WHO handles it or HOW
    await this.events.publish(new OrderPlacedEvent(order));

    return order;
  }
}
```

### SoC Red Flags

| Signal | Vấn đề |
|--------|--------|
| File > 400 dòng | Có thể đang mix concerns |
| Function > 30 dòng | Có thể đang làm nhiều việc |
| Nhiều `import` statements từ domains khác nhau | Coupling between concerns |
| `try/catch` wrap toàn bộ function | Error handling không tách biệt |
| SQL queries trong controller | Data access + transport mixed |
| Business rules trong event handler | Domain logic leaking |
| `if (user.role === 'admin')` rải khắp nơi | Auth concern không centralized |
