## OAuth 2.0 Flows

OAuth 2.0 là **authorization framework** cho phép ứng dụng truy cập resource thay mặt user mà không cần biết password.

### Authorization Code Flow + PKCE

Flow an toàn nhất cho **public clients** (SPA, mobile). PKCE chống authorization code interception.

```typescript
import crypto from 'crypto';

// PKCE helpers
const generateCodeVerifier = () => crypto.randomBytes(32).toString('base64url');
const generateCodeChallenge = (verifier: string) =>
  crypto.createHash('sha256').update(verifier).digest('base64url');

interface OAuth2Config {
  clientId: string;
  redirectUri: string;
  authorizationEndpoint: string;
  tokenEndpoint: string;
  scopes: string[];
}

class OAuth2PKCEClient {
  private codeVerifier = '';
  private state = '';

  constructor(private config: OAuth2Config) {}

  // Step 1: Generate authorization URL
  getAuthorizationUrl(): string {
    this.codeVerifier = generateCodeVerifier();
    this.state = crypto.randomBytes(16).toString('hex');

    const params = new URLSearchParams({
      response_type: 'code',
      client_id: this.config.clientId,
      redirect_uri: this.config.redirectUri,
      scope: this.config.scopes.join(' '),
      state: this.state,
      code_challenge: generateCodeChallenge(this.codeVerifier),
      code_challenge_method: 'S256',
    });
    return `${this.config.authorizationEndpoint}?${params}`;
  }

  // Step 2: Exchange code for tokens
  async exchangeCode(code: string, returnedState: string): Promise<TokenResponse> {
    if (returnedState !== this.state) throw new Error('State mismatch — possible CSRF');

    const response = await fetch(this.config.tokenEndpoint, {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams({
        grant_type: 'authorization_code',
        client_id: this.config.clientId,
        code,
        redirect_uri: this.config.redirectUri,
        code_verifier: this.codeVerifier,
      }),
    });
    if (!response.ok) throw new Error(`Token exchange failed: ${response.status}`);
    return response.json() as Promise<TokenResponse>;
  }
}

interface TokenResponse {
  access_token: string;
  token_type: 'Bearer';
  expires_in: number;
  refresh_token?: string;
  id_token?: string;
  scope: string;
}
```

### Client Credentials Flow

Machine-to-machine — không có user involvement.

```typescript
class ClientCredentialsClient {
  private cachedToken: { token: string; expiresAt: number } | null = null;

  constructor(
    private clientId: string,
    private clientSecret: string,
    private tokenEndpoint: string,
    private scopes: string[]
  ) {}

  async getAccessToken(): Promise<string> {
    if (this.cachedToken && this.cachedToken.expiresAt > Date.now() + 60_000) {
      return this.cachedToken.token;
    }

    const response = await fetch(this.tokenEndpoint, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/x-www-form-urlencoded',
        Authorization: `Basic ${Buffer.from(`${this.clientId}:${this.clientSecret}`).toString('base64')}`,
      },
      body: new URLSearchParams({
        grant_type: 'client_credentials',
        scope: this.scopes.join(' '),
      }),
    });
    if (!response.ok) throw new Error(`Auth failed: ${response.status}`);

    const data: TokenResponse = await response.json();
    this.cachedToken = { token: data.access_token, expiresAt: Date.now() + data.expires_in * 1000 };
    return data.access_token;
  }
}
```

### Device Code Flow

Cho devices không có browser (Smart TV, CLI tools, IoT).

```typescript
interface DeviceCodeResponse {
  device_code: string;
  user_code: string;            // User nhập code này trên browser
  verification_uri: string;      // URL user truy cập
  expires_in: number;
  interval: number;              // Polling interval (seconds)
}

class DeviceCodeClient {
  constructor(private clientId: string, private deviceAuthEndpoint: string,
              private tokenEndpoint: string, private scopes: string[]) {}

  async requestDeviceCode(): Promise<DeviceCodeResponse> {
    const response = await fetch(this.deviceAuthEndpoint, {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams({ client_id: this.clientId, scope: this.scopes.join(' ') }),
    });
    return response.json() as Promise<DeviceCodeResponse>;
  }

  async pollForToken(deviceCode: string, interval: number): Promise<TokenResponse> {
    while (true) {
      await new Promise(resolve => setTimeout(resolve, interval * 1000));
      const response = await fetch(this.tokenEndpoint, {
        method: 'POST',
        headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
        body: new URLSearchParams({
          grant_type: 'urn:ietf:params:oauth:grant-type:device_code',
          client_id: this.clientId,
          device_code: deviceCode,
        }),
      });
      const data = await response.json();
      if (response.ok) return data as TokenResponse;
      if (data.error === 'authorization_pending') continue;
      if (data.error === 'slow_down') { interval += 5; continue; }
      throw new Error(`Device auth failed: ${data.error}`);
    }
  }
}
```

## OpenID Connect (OIDC)

OIDC là **identity layer on top of OAuth 2.0**. OAuth 2.0 cho authorization (access token), OIDC thêm authentication (ID token).

```typescript
import jwt from 'jsonwebtoken';
import jwksClient from 'jwks-rsa';

interface IDTokenPayload {
  iss: string;   sub: string;   aud: string;   exp: number;   iat: number;
  nonce?: string;
  email?: string;  email_verified?: boolean;  name?: string;  picture?: string;
}

class OIDCClient {
  private jwks: jwksClient.JwksClient;

  constructor(private issuer: string, private clientId: string) {
    this.jwks = jwksClient({
      jwksUri: `${issuer}/.well-known/jwks.json`,
      cache: true, rateLimit: true, jwksRequestsPerMinute: 5,
    });
  }

  async verifyIdToken(idToken: string, nonce?: string): Promise<IDTokenPayload> {
    const decoded = jwt.decode(idToken, { complete: true });
    if (!decoded || typeof decoded === 'string') throw new Error('Invalid ID token');

    const key = await this.jwks.getSigningKey(decoded.header.kid);
    const payload = jwt.verify(idToken, key.getPublicKey(), {
      algorithms: ['RS256'],
      issuer: this.issuer,
      audience: this.clientId,
    }) as IDTokenPayload;

    if (nonce && payload.nonce !== nonce) throw new Error('Nonce mismatch — replay attack');
    return payload;
  }

  async getUserInfo(accessToken: string): Promise<Record<string, unknown>> {
    const disc = await fetch(`${this.issuer}/.well-known/openid-configuration`);
    const { userinfo_endpoint } = await disc.json() as { userinfo_endpoint: string };
    const response = await fetch(userinfo_endpoint, {
      headers: { Authorization: `Bearer ${accessToken}` },
    });
    return response.json() as Promise<Record<string, unknown>>;
  }
}
```

### RSA vs HMAC — Khi nào dùng gì

```typescript
// HMAC (HS256): Symmetric — cùng secret sign & verify
// Dùng khi: monolith (1 service tạo và verify)
// Ưu: Nhanh, đơn giản. Nhược: Secret phải share giữa services

class HMACTokenService {
  constructor(private secret: string) {
    if (secret.length < 32) throw new Error('Secret must be >= 256 bits');
  }
  sign(payload: object): string {
    return jwt.sign(payload, this.secret, { algorithm: 'HS256', expiresIn: '15m' });
  }
  verify(token: string): JWTPayload {
    return jwt.verify(token, this.secret, { algorithms: ['HS256'] }) as JWTPayload;
  }
}

// RSA (RS256): Asymmetric — private key sign, public key verify
// Dùng khi: microservices (auth service sign, others verify with public key)
// Ưu: Services chỉ cần public key. Nhược: Chậm hơn, key management phức tạp hơn

class RSATokenService {
  constructor(private privateKey: string, private publicKey: string) {}
  sign(payload: object): string {
    return jwt.sign(payload, this.privateKey, { algorithm: 'RS256', expiresIn: '15m', keyid: 'key-2024-01' });
  }
  verify(token: string): JWTPayload {
    return jwt.verify(token, this.publicKey, { algorithms: ['RS256'] }) as JWTPayload;
  }
}
```

### Token Rotation Strategy

```typescript
// Access Token: short-lived (15 min). Refresh Token: longer-lived (7 days), rotated on use.

class TokenRotationService {
  constructor(private jwtService: RSATokenService, private store: RefreshTokenStore) {}

  async issueTokens(userId: string, meta: { ip: string; userAgent: string }): Promise<TokenPair> {
    const accessToken = this.jwtService.sign({ sub: userId, iss: 'my-app', aud: 'my-api' });
    const refreshToken = crypto.randomBytes(48).toString('base64url'); // Opaque, NOT JWT

    await this.store.save({
      token: this.hash(refreshToken), userId,
      ip: meta.ip, userAgent: meta.userAgent,
      expiresAt: new Date(Date.now() + 7 * 24 * 60 * 60 * 1000), used: false,
    });
    return { accessToken, refreshToken, expiresIn: 900 };
  }

  async refresh(refreshToken: string, meta: { ip: string; userAgent: string }): Promise<TokenPair> {
    const stored = await this.store.findByHash(this.hash(refreshToken));
    if (!stored) throw new Error('Invalid refresh token');
    if (stored.expiresAt < new Date()) throw new Error('Expired');

    // Reuse detection: if token already used, someone stole it
    if (stored.used) {
      await this.store.revokeAllForUser(stored.userId); // Force re-login
      throw new Error('Token reuse detected — all sessions revoked');
    }

    await this.store.markUsed(this.hash(refreshToken));
    return this.issueTokens(stored.userId, meta);
  }

  private hash(token: string): string {
    return crypto.createHash('sha256').update(token).digest('hex');
  }
}
```

### Token Storage: Cookie vs localStorage vs Memory

```
╔═══════════════════╦══════════════╦════════════╦══════════════╗
║ Storage           ║ XSS Risk     ║ CSRF Risk  ║ Persistence  ║
╠═══════════════════╬══════════════╬════════════╬══════════════╣
║ localStorage      ║ HIGH (JS)    ║ None       ║ Persistent   ║
║ HttpOnly Cookie   ║ None         ║ HIGH       ║ Configurable ║
║ Memory (variable) ║ LOW          ║ None       ║ Lost on refresh║
╚═══════════════════╩══════════════╩════════════╩══════════════╝
```

**Recommended: HttpOnly Cookie + CSRF token**

```typescript
function setAuthCookies(res: Response, tokens: TokenPair): void {
  res.cookie('access_token', tokens.accessToken, {
    httpOnly: true, secure: true, sameSite: 'strict',
    maxAge: tokens.expiresIn * 1000, path: '/api',
  });
  res.cookie('refresh_token', tokens.refreshToken, {
    httpOnly: true, secure: true, sameSite: 'strict',
    maxAge: 7 * 24 * 60 * 60 * 1000, path: '/api/auth/refresh',
  });
}

// CSRF protection middleware
function csrfProtection(req: Request, res: Response, next: NextFunction): void {
  if (['GET', 'HEAD', 'OPTIONS'].includes(req.method)) return next();
  const csrfCookie = req.cookies['csrf_token'];
  const csrfHeader = req.headers['x-csrf-token'];
  if (!csrfCookie || !csrfHeader || csrfCookie !== csrfHeader) {
    res.status(403).json({ error: 'CSRF token mismatch' }); return;
  }
  next();
}
```

## Session-based vs Token-based Auth

```typescript
// Session-based: stateful, stored server-side (Redis), easy revocation
// Token-based: stateless, stored client-side, hard to revoke but easy to scale

// Session setup
import session from 'express-session';
import RedisStore from 'connect-redis';

app.use(session({
  store: new RedisStore({ client: redis }),
  secret: process.env.SESSION_SECRET!,
  name: '__session',  // Custom name (default 'connect.sid' is fingerprintable)
  resave: false, saveUninitialized: false,
  cookie: { httpOnly: true, secure: true, sameSite: 'strict', maxAge: 86400000 },
}));

// Hybrid: JWT for identity, Redis for revocation check
async function hybridAuth(req: Request, res: Response, next: NextFunction): Promise<void> {
  const token = req.cookies['access_token'];
  if (!token) { res.status(401).json({ error: 'No token' }); return; }
  try {
    const payload = jwtService.verify(token);
    const isRevoked = await redis.get(`revoked:${payload.jti}`);
    if (isRevoked) { res.status(401).json({ error: 'Token revoked' }); return; }
    req.user = payload;
    next();
  } catch { res.status(401).json({ error: 'Invalid token' }); }
}
```

## Multi-Factor Authentication

### TOTP (Time-based One-Time Password)

```typescript
import { authenticator } from 'otplib';
import QRCode from 'qrcode';

class TOTPService {
  async enableTOTP(userId: string): Promise<{ secret: string; qrCodeUrl: string }> {
    const secret = authenticator.generateSecret();
    await db.users.update(userId, { totpSecret: encrypt(secret), totpEnabled: false });
    const otpauth = authenticator.keyuri(userId, 'MyApp', secret);
    return { secret, qrCodeUrl: await QRCode.toDataURL(otpauth) };
  }

  async verifyAndEnable(userId: string, code: string): Promise<{ backupCodes: string[] }> {
    const user = await db.users.findById(userId);
    if (!authenticator.verify({ token: code, secret: decrypt(user.totpSecret) }))
      throw new Error('Invalid TOTP code');

    const backupCodes = Array.from({ length: 10 }, () => crypto.randomBytes(4).toString('hex'));
    await db.users.update(userId, {
      totpEnabled: true,
      backupCodes: backupCodes.map(c => crypto.createHash('sha256').update(c).digest('hex')),
    });
    return { backupCodes }; // Show once, user must save
  }

  async verifyCode(userId: string, code: string): Promise<boolean> {
    const user = await db.users.findById(userId);
    if (authenticator.verify({ token: code, secret: decrypt(user.totpSecret) })) return true;
    // Check backup codes
    for (let i = 0; i < user.backupCodes.length; i++) {
      const hash = crypto.createHash('sha256').update(code).digest('hex');
      if (crypto.timingSafeEqual(Buffer.from(hash), Buffer.from(user.backupCodes[i]))) {
        user.backupCodes.splice(i, 1);
        await db.users.update(userId, { backupCodes: user.backupCodes });
        return true;
      }
    }
    return false;
  }
}
```

### WebAuthn / Passkeys

```typescript
import {
  generateRegistrationOptions, verifyRegistrationResponse,
  generateAuthenticationOptions, verifyAuthenticationResponse,
} from '@simplewebauthn/server';

const rpName = 'MyApp', rpID = 'myapp.com', origin = 'https://myapp.com';

class WebAuthnService {
  async startRegistration(userId: string, username: string) {
    const existing = await db.credentials.findByUserId(userId);
    const options = await generateRegistrationOptions({
      rpName, rpID, userName: username, attestationType: 'none',
      excludeCredentials: existing.map(c => ({ id: c.credentialId, transports: c.transports })),
      authenticatorSelection: { residentKey: 'preferred', userVerification: 'preferred' },
    });
    await db.challenges.save(userId, options.challenge);
    return options;
  }

  async finishRegistration(userId: string, response: any): Promise<void> {
    const verification = await verifyRegistrationResponse({
      response, expectedChallenge: await db.challenges.get(userId),
      expectedOrigin: origin, expectedRPID: rpID,
    });
    if (!verification.verified || !verification.registrationInfo) throw new Error('Failed');
    const { credential } = verification.registrationInfo;
    await db.credentials.save({
      userId, credentialId: credential.id,
      publicKey: Buffer.from(credential.publicKey), counter: credential.counter,
    });
  }

  async startAuthentication(userId: string) {
    const creds = await db.credentials.findByUserId(userId);
    const options = await generateAuthenticationOptions({
      rpID, allowCredentials: creds.map(c => ({ id: c.credentialId, transports: c.transports })),
    });
    await db.challenges.save(userId, options.challenge);
    return options;
  }

  async finishAuthentication(userId: string, response: any): Promise<boolean> {
    const cred = await db.credentials.findById(response.id);
    if (!cred || cred.userId !== userId) throw new Error('Not found');
    const verification = await verifyAuthenticationResponse({
      response, expectedChallenge: await db.challenges.get(userId),
      expectedOrigin: origin, expectedRPID: rpID,
      credential: { id: cred.credentialId, publicKey: cred.publicKey, counter: cred.counter },
    });
    if (verification.verified) {
      await db.credentials.updateCounter(cred.credentialId, verification.authenticationInfo.newCounter);
    }
    return verification.verified;
  }
}
```

## Machine-to-Machine Authentication

### API Keys

```typescript
class APIKeyService {
  async createKey(meta: { name: string; ownerId: string; permissions: string[] }) {
    const keyId = crypto.randomUUID();
    const rawKey = `myapp_${crypto.randomBytes(32).toString('base64url')}`;
    const keyHash = crypto.createHash('sha256').update(rawKey).digest('hex');

    await db.apiKeys.create({
      id: keyId, keyHash, keyPrefix: rawKey.slice(0, 12), ...meta, createdAt: new Date(),
    });
    return { key: rawKey, keyId }; // rawKey returned ONCE — cannot be recovered
  }

  async verify(key: string): Promise<APIKeyRecord | null> {
    const keyHash = crypto.createHash('sha256').update(key).digest('hex');
    const record = await db.apiKeys.findByHash(keyHash);
    if (!record || (record.expiresAt && record.expiresAt < new Date()) || record.revokedAt) return null;
    await db.apiKeys.updateLastUsed(record.id);
    return record;
  }
}
```

### mTLS (Mutual TLS)

```typescript
import https from 'https';
import fs from 'fs';
import tls from 'tls';

// Server: verify client certificate
const server = https.createServer({
  key: fs.readFileSync('/certs/server-key.pem'),
  cert: fs.readFileSync('/certs/server-cert.pem'),
  ca: fs.readFileSync('/certs/ca-cert.pem'),
  requestCert: true, rejectUnauthorized: true,

// Extract client identity from cert
function mtlsIdentity(req: Request, res: Response, next: NextFunction): void {
  const cert = (req.socket as tls.TLSSocket).getPeerCertificate();
  if (!cert?.subject) { res.status(403).json({ error: 'Client cert required' }); return; }
  req.serviceIdentity = {
    commonName: cert.subject.CN, organization: cert.subject.O, fingerprint: cert.fingerprint256,
  };
  next();
}
```

## Social Login Implementation Pattern

```typescript
interface SocialProfile {
  provider: 'google' | 'github' | 'microsoft';
  providerId: string;
  email: string;
  emailVerified: boolean;
  name: string;
}

class SocialAuthService {
  constructor(private providers: Map<string, SocialAuthProvider>, private userService: UserService) {}

  async handleCallback(provider: string, code: string): Promise<{ user: User; isNewUser: boolean }> {
    const authProvider = this.providers.get(provider);
    if (!authProvider) throw new Error(`Unknown provider: ${provider}`);

    const tokens = await authProvider.exchangeCode(code);
    const profile = await authProvider.getProfile(tokens.accessToken, tokens.idToken);

    // 1. Try existing linked account
    const link = await db.socialAccounts.findOne({ provider: profile.provider, providerId: profile.providerId });
    if (link) return { user: await this.userService.findById(link.userId), isNewUser: false };

    // 2. Auto-link by verified email
    if (profile.emailVerified) {
      const existing = await this.userService.findByEmail(profile.email);
      if (existing) {
        await db.socialAccounts.create({ userId: existing.id, provider: profile.provider, providerId: profile.providerId });
        return { user: existing, isNewUser: false };
      }
    }

    // 3. Create new user
    const newUser = await this.userService.create({ email: profile.email, name: profile.name, emailVerified: profile.emailVerified });
    await db.socialAccounts.create({ userId: newUser.id, provider: profile.provider, providerId: profile.providerId });
    return { user: newUser, isNewUser: true };
  }
}
```

## Authentication Decision Tree

```
User-facing web app?  ──YES──→  OAuth 2.0 + PKCE + OIDC + HttpOnly cookies
        │ NO
Mobile/SPA?  ──YES──→  OAuth 2.0 + PKCE + secure storage + token rotation
        │ NO
CLI/Device?  ──YES──→  Device Code Flow
        │ NO
Service-to-service?  ──YES──→  mTLS (internal) / Client Credentials (external)
```

### Security Checklist

- [ ] Passwords hashed với bcrypt/argon2 (cost >= 12)
- [ ] JWT signed RS256 cho microservices, HS256 chỉ cho monolith
- [ ] Access tokens short-lived (15 min max)
- [ ] Refresh tokens rotated + reuse detection
- [ ] MFA enforced cho admin accounts
- [ ] Tokens in HttpOnly + Secure + SameSite cookies
- [ ] CSRF protection cho cookie-based auth
- [ ] Brute force protection (rate limiting + lockout)
- [ ] Logout invalidates session/token server-side
