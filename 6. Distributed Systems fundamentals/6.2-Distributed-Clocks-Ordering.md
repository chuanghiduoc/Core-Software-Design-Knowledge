## Wall Clocks vs Logical Clocks

### Tại sao wall clocks không đáng tin?

Mỗi máy tính có một **oscillator** (thạch anh) để đếm thời gian. Nhưng:

```
Vấn đề 1: Clock drift
  - Oscillator thạch anh sai ~10-50 ppm (parts per million)
  - 50 ppm = 4.3 giây/ngày drift
  - Sau 1 tuần: ~30 giây lệch giữa 2 server

Vấn đề 2: NTP adjustment
  - NTP đồng bộ clock qua network (có latency)
  - NTP có thể NHẢY LÙI clock (step correction)
  - Hoặc SLEW: chạy chậm/nhanh hơn để bắt kịp

Vấn đề 3: Leap seconds
  - 2016-12-31: thêm 1 giây vào 23:59:59 → 23:59:60
  - Nhiều hệ thống crash vì không handle

Vấn đề 4: VM/Container time
  - VM migration → clock jump
  - Container có thể share host clock hoặc không
```

### Hậu quả thực tế

```typescript
// BUG THỰC TẾ: Dùng wall clock để ordering events

class BrokenEventStore {
  async append(event: DomainEvent): Promise<void> {
    // WRONG: Dùng Date.now() làm ordering key
    const timestamp = Date.now();
    await this.db.insert('events', {
      ...event,
      timestamp,
      // Khi NTP nhảy lùi: event mới có timestamp CŨ hơn event trước
      // → Mất ordering → data corruption
    });
  }

  async getEventsAfter(since: number): Promise<DomainEvent[]> {
    // Event với timestamp bị NTP đẩy lùi sẽ BỊ BỎ QUA
    return this.db.query(
      'SELECT * FROM events WHERE timestamp > $1 ORDER BY timestamp',
      [since]
    );
  }
}

// ĐÚNG: Dùng monotonic sequence number + wall clock chỉ để tham khảo
class CorrectEventStore {
  private sequence = 0n; // BigInt, monotonically increasing

  async append(event: DomainEvent): Promise<void> {
    const seq = ++this.sequence;
    await this.db.insert('events', {
      ...event,
      sequenceNumber: seq,          // Ordering key — monotonic
      wallClockHint: Date.now(),     // Chỉ để tham khảo, KHÔNG dùng để order
    });
  }
}
```

## Lamport Timestamps

> "The happened-before relation captures potential causality."
> — Leslie Lamport, "Time, Clocks, and the Ordering of Events in a Distributed System", 1978

### Ý tưởng cốt lõi

Lamport timestamp là **logical clock** đơn giản nhất. Mỗi process giữ một counter:

```
Rule 1: Trước mỗi event nội bộ, tăng counter lên 1
Rule 2: Khi gửi message, đính kèm counter hiện tại
Rule 3: Khi nhận message, counter = max(local, received) + 1
```

### Happened-before relation (→)

```
a → b  nghĩa là "a happened before b" (a có thể ảnh hưởng đến b)

Nếu a và b cùng process, và a trước b     → a → b
Nếu a là send message, b là receive cùng message → a → b
Nếu a → b và b → c                        → a → c (transitive)

Nếu KHÔNG a → b VÀ KHÔNG b → a            → a ∥ b (concurrent)
```

### TypeScript Implementation

```typescript
class LamportClock {
  private counter: number = 0;

  constructor(private readonly nodeId: string) {}

  // Rule 1: Internal event — tăng counter
  tick(): LamportTimestamp {
    this.counter++;
    return this.timestamp();
  }

  // Rule 2: Gửi message — đính kèm timestamp
  send(): { timestamp: LamportTimestamp; payload_clock: number } {
    this.counter++;
    return {
      timestamp: this.timestamp(),
      payload_clock: this.counter,
    };
  }

  // Rule 3: Nhận message — max(local, received) + 1
  receive(receivedClock: number): LamportTimestamp {
    this.counter = Math.max(this.counter, receivedClock) + 1;
    return this.timestamp();
  }

  private timestamp(): LamportTimestamp {
    return {
      counter: this.counter,
      nodeId: this.nodeId,
    };
  }
}

interface LamportTimestamp {
  counter: number;
  nodeId: string;
}

// So sánh Lamport timestamps
function compareLamport(a: LamportTimestamp, b: LamportTimestamp): number {
  if (a.counter !== b.counter) {
    return a.counter - b.counter;
  }
  // Tie-break bằng nodeId để total order
  return a.nodeId.localeCompare(b.nodeId);
}

// === Ví dụ: Distributed Event Log ===

class DistributedEventLog {
  private clock: LamportClock;
  private events: Array<{ event: string; ts: LamportTimestamp }> = [];

  constructor(nodeId: string) {
    this.clock = new LamportClock(nodeId);
  }

  // Local event
  recordEvent(event: string): LamportTimestamp {
    const ts = this.clock.tick();
    this.events.push({ event, ts });
    return ts;
  }

  // Gửi event tới node khác
  createMessage(event: string): {
    event: string;
    clock: number;
    ts: LamportTimestamp;
  } {
    const { timestamp, payload_clock } = this.clock.send();
    this.events.push({ event, ts: timestamp });
    return { event, clock: payload_clock, ts: timestamp };
  }

  // Nhận event từ node khác
  receiveMessage(msg: { event: string; clock: number }): void {
    const ts = this.clock.receive(msg.clock);
    this.events.push({ event: msg.event, ts });
  }

  // Lấy events đã sắp xếp
  getOrderedEvents(): Array<{ event: string; ts: LamportTimestamp }> {
    return [...this.events].sort((a, b) => compareLamport(a.ts, b.ts));
  }
}

// Demo
const nodeA = new DistributedEventLog('node-A');
const nodeB = new DistributedEventLog('node-B');

nodeA.recordEvent('user_login');         // A: counter=1
const msg = nodeA.createMessage('order_created'); // A: counter=2
nodeB.receiveMessage(msg);               // B: counter=max(0,2)+1=3
nodeB.recordEvent('inventory_reserved'); // B: counter=4
```

### Giới hạn của Lamport Timestamps

```
Lamport guarantee:  nếu a → b thì L(a) < L(b)
NHƯNG ngược lại KHÔNG đúng: L(a) < L(b) KHÔNG có nghĩa a → b

→ Lamport timestamps KHÔNG detect được concurrent events
→ Cần Vector Clocks cho việc đó
```

## Vector Clocks

> Vector Clock giải quyết giới hạn của Lamport: nó CÓ THỂ detect concurrent events.
> Mỗi process giữ một vector chứa counter của TẤT CẢ processes.

### Thuật toán

```
Mỗi process Pi giữ vector V[0..n-1] (n = số processes)

Rule 1: Trước mỗi event, Pi tăng V[i] lên 1
Rule 2: Khi gửi message, Pi gửi kèm toàn bộ vector V
Rule 3: Khi nhận message với vector W,
         Pi cập nhật: V[j] = max(V[j], W[j]) cho mọi j
         Rồi tăng V[i] lên 1
```

### So sánh Vector Clocks

```
V ≤ W   khi mọi V[i] ≤ W[i]           → V happened-before W
V ∥ W   khi tồn tại i: V[i] > W[i]    → Concurrent (conflict!)
         VÀ tồn tại j: V[j] < W[j]
```

### TypeScript Implementation

```typescript
class VectorClock {
  private clock: Map<string, number>;

  constructor(nodeId?: string) {
    this.clock = new Map();
    if (nodeId) {
      this.clock.set(nodeId, 0);
    }
  }

  // Tạo VectorClock từ plain object (deserialization)
  static fromRecord(record: Record<string, number>): VectorClock {
    const vc = new VectorClock();
    for (const [nodeId, counter] of Object.entries(record)) {
      vc.clock.set(nodeId, counter);
    }
    return vc;
  }

  // Rule 1: Internal event
  increment(nodeId: string): VectorClock {
    const newClock = this.copy();
    newClock.clock.set(nodeId, (newClock.clock.get(nodeId) ?? 0) + 1);
    return newClock;
  }

  // Rule 3: Merge khi nhận message
  merge(other: VectorClock): VectorClock {
    const merged = this.copy();
    for (const [nodeId, counter] of other.clock) {
      merged.clock.set(
        nodeId,
        Math.max(merged.clock.get(nodeId) ?? 0, counter)
      );
    }
    return merged;
  }

  // So sánh: happened-before, after, concurrent
  compare(other: VectorClock): 'before' | 'after' | 'concurrent' | 'equal' {
    let hasLess = false;
    let hasGreater = false;

    // Lấy tất cả nodeIds từ cả hai clocks
    const allNodeIds = new Set([...this.clock.keys(), ...other.clock.keys()]);

    for (const nodeId of allNodeIds) {
      const a = this.clock.get(nodeId) ?? 0;
      const b = other.clock.get(nodeId) ?? 0;

      if (a < b) hasLess = true;
      if (a > b) hasGreater = true;

      // Early exit: đã xác định concurrent
      if (hasLess && hasGreater) return 'concurrent';
    }

    if (!hasLess && !hasGreater) return 'equal';
    if (hasLess && !hasGreater) return 'before';
    return 'after'; // hasGreater && !hasLess
  }

  // Kiểm tra event a có happened-before event b không
  happenedBefore(other: VectorClock): boolean {
    return this.compare(other) === 'before';
  }

  // Kiểm tra concurrent (conflict detection!)
  isConcurrentWith(other: VectorClock): boolean {
    return this.compare(other) === 'concurrent';
  }

  // Serialize
  toRecord(): Record<string, number> {
    return Object.fromEntries(this.clock);
  }

  private copy(): VectorClock {
    const vc = new VectorClock();
    vc.clock = new Map(this.clock);
    return vc;
  }

  toString(): string {
    const entries = Array.from(this.clock.entries())
      .sort(([a], [b]) => a.localeCompare(b))
      .map(([k, v]) => `${k}:${v}`)
      .join(', ');
    return `{${entries}}`;
  }
}

// === Ứng dụng: Conflict Detection trong Distributed KV Store ===

interface VersionedValue<T> {
  value: T;
  clock: VectorClock;
}

class DistributedKVStore<T> {
  private readonly nodeId: string;
  private data = new Map<string, VersionedValue<T>[]>();

  constructor(nodeId: string) {
    this.nodeId = nodeId;
  }

  put(key: string, value: T, clientClock?: VectorClock): PutResult {
    const existing = this.data.get(key) ?? [];
    const newClock = (clientClock ?? new VectorClock())
      .increment(this.nodeId);

    // Tìm siblings mà newClock supersedes
    const survivors: VersionedValue<T>[] = [];
    let hasConflict = false;

    for (const version of existing) {
      const rel = newClock.compare(version.clock);
      if (rel === 'after' || rel === 'equal') {
        // newClock supersedes → loại bỏ version cũ
        continue;
      }
      if (rel === 'concurrent') {
        // CONFLICT! Giữ cả hai versions (siblings)
        hasConflict = true;
        survivors.push(version);
      }
      if (rel === 'before') {
        // Viết cũ hơn version hiện tại → bỏ qua write
        return { status: 'stale_write', conflicts: existing };
      }
    }

    survivors.push({ value, clock: newClock });
    this.data.set(key, survivors);

    if (hasConflict) {
      return { status: 'conflict', conflicts: survivors };
    }
    return { status: 'ok', conflicts: [] };
  }

  get(key: string): VersionedValue<T>[] {
    return this.data.get(key) ?? [];
  }

  // Client giải quyết conflict bằng cách merge rồi write lại
  resolveConflict(
    key: string,
    resolvedValue: T,
    conflictingVersions: VersionedValue<T>[]
  ): void {
    // Merge tất cả vector clocks
    let mergedClock = new VectorClock();
    for (const version of conflictingVersions) {
      mergedClock = mergedClock.merge(version.clock);
    }
    // Increment cho node hiện tại
    mergedClock = mergedClock.increment(this.nodeId);

    this.data.set(key, [{ value: resolvedValue, clock: mergedClock }]);
  }
}

type PutResult =
  | { status: 'ok'; conflicts: VersionedValue<unknown>[] }
  | { status: 'conflict'; conflicts: VersionedValue<unknown>[] }
  | { status: 'stale_write'; conflicts: VersionedValue<unknown>[] };

// Demo: Conflict detection
const storeA = new DistributedKVStore<string>('node-A');
const storeB = new DistributedKVStore<string>('node-B');

// Concurrent writes → conflict!
storeA.put('user:1:name', 'Alice');
storeB.put('user:1:name', 'Bob');
// Khi replicate, vector clocks detect: {A:1} vs {B:1} → concurrent!
```

## Hybrid Logical Clocks (HLC)

> HLC kết hợp tốt nhất của wall clock (physical time) và logical clock.
> Được dùng trong CockroachDB, MongoDB, YugabyteDB.
> — Sandeep Kulkarni et al., 2014

### Tại sao cần HLC?

```
Lamport Clock:  Không liên hệ với physical time → khó debug, khó hiểu
Wall Clock:     Không monotonic, có thể nhảy lùi → sai ordering
Vector Clock:   Không scale (vector size = số nodes)

HLC = Physical time + Logical counter
    = Gần physical time nhưng LUÔN monotonic
    = Scale tốt hơn vector clocks (fixed-size)
```

### Cấu trúc HLC

```
HLC timestamp = (physical_time, logical_counter, node_id)

- physical_time: wall clock, lấy từ NTP
- logical_counter: dùng khi physical_time giống nhau hoặc bị đẩy lùi
- node_id: tie-breaker để total order
```

### TypeScript Implementation

```typescript
interface HLCTimestamp {
  /** Wall clock time (milliseconds since epoch) */
  wallTime: number;
  /** Logical counter — tăng khi wallTime giống nhau */
  logical: number;
  /** Node identifier */
  nodeId: string;
}

class HybridLogicalClock {
  private wallTime: number = 0;
  private logical: number = 0;

  constructor(
    private readonly nodeId: string,
    private readonly physicalClock: () => number = Date.now,
    private readonly maxDrift: number = 60_000, // max 60s drift cho phép
  ) {}

  /**
   * Tạo timestamp mới cho local event
   */
  now(): HLCTimestamp {
    const pt = this.physicalClock();

    if (pt > this.wallTime) {
      // Physical clock tiến lên bình thường
      this.wallTime = pt;
      this.logical = 0;
    } else {
      // Physical clock đứng yên hoặc nhảy lùi (NTP adjustment)
      // → Chỉ tăng logical counter
      this.logical++;
    }

    return {
      wallTime: this.wallTime,
      logical: this.logical,
      nodeId: this.nodeId,
    };
  }

  /**
   * Cập nhật clock khi nhận message từ node khác
   */
  receive(remote: HLCTimestamp): HLCTimestamp {
    const pt = this.physicalClock();

    // Kiểm tra drift quá lớn (có thể do clock skew hoặc malicious node)
    if (Math.abs(remote.wallTime - pt) > this.maxDrift) {
      throw new ClockDriftError(
        `Remote clock drift ${Math.abs(remote.wallTime - pt)}ms exceeds max ${this.maxDrift}ms`
      );
    }

    if (pt > this.wallTime && pt > remote.wallTime) {
      // Local physical clock ahead — dùng nó
      this.wallTime = pt;
      this.logical = 0;
    } else if (remote.wallTime > this.wallTime) {
      // Remote clock ahead — adopt remote time
      this.wallTime = remote.wallTime;
      this.logical = remote.logical + 1;
    } else if (this.wallTime > remote.wallTime) {
      // Local HLC ahead — keep local time, bump logical
      this.logical++;
    } else {
      // Same wall time — take max logical + 1
      this.logical = Math.max(this.logical, remote.logical) + 1;
    }

    return {
      wallTime: this.wallTime,
      logical: this.logical,
      nodeId: this.nodeId,
    };
  }

  /**
   * So sánh hai HLC timestamps
   */
  static compare(a: HLCTimestamp, b: HLCTimestamp): number {
    if (a.wallTime !== b.wallTime) return a.wallTime - b.wallTime;
    if (a.logical !== b.logical) return a.logical - b.logical;
    return a.nodeId.localeCompare(b.nodeId);
  }

  /**
   * Encode HLC thành single 64-bit-like value để storage
   * Format: [wall_time_ms: 48 bits][logical: 16 bits]
   * → hỗ trợ ~8900 năm wall time, 65535 logical events/ms
   */
  static encode(ts: HLCTimestamp): bigint {
    return (BigInt(ts.wallTime) << 16n) | BigInt(ts.logical & 0xffff);
  }

  static decode(encoded: bigint, nodeId: string): HLCTimestamp {
    return {
      wallTime: Number(encoded >> 16n),
      logical: Number(encoded & 0xffffn),
      nodeId,
    };
  }
}

class ClockDriftError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'ClockDriftError';
  }
}

// === HLC trong Database Transaction ===

class HLCTransactionManager {
  constructor(private readonly hlc: HybridLogicalClock) {}

  async beginTransaction(): Promise<Transaction> {
    const startTs = this.hlc.now();
    return {
      id: crypto.randomUUID(),
      startTimestamp: startTs,
      readSet: new Map(),
      writeSet: new Map(),
    };
  }

  async commit(tx: Transaction): Promise<HLCTimestamp> {

    // Validate: commitTs phải > startTs (HLC guarantees this)

    }

      await this.applyWrite(key, value, commitTs);
    }

    return commitTs;
  }

    key: string,
    value: unknown,
```

### Database Replication Lag

```typescript
// Replication lag: write tới primary, read từ replica → có thể stale

class ReplicaAwareRepository {
  constructor(
    private readonly primary: DatabasePool,
    private readonly replicas: DatabasePool[],
    private readonly maxAcceptableLagMs: number = 1000,
  ) {}

  async write(query: string, params: unknown[]): Promise<QueryResult> {
    // Write LUÔN đi primary
    return this.primary.query(query, params);
  }

  async read(
    query: string,
    params: unknown[],
    options: ReadOptions = {},
  ): Promise<QueryResult> {
    if (options.requireFresh) {
      // Cần data mới nhất → đọc từ primary
      return this.primary.query(query, params);
    }

    // Chọn replica có lag thấp nhất
    const replica = await this.selectHealthyReplica();
    if (!replica) {
      // Mọi replicas đều lag quá nhiều → fallback primary
      console.warn('All replicas lagging, falling back to primary');
      return this.primary.query(query, params);
    }

    return replica.query(query, params);
  }

  private async selectHealthyReplica(): Promise<DatabasePool | null> {
    for (const replica of this.shuffled(this.replicas)) {
      const lag = await this.getReplicationLag(replica);
      if (lag <= this.maxAcceptableLagMs) {
        return replica;
      }
    }
    return null;
  }

  private async getReplicationLag(replica: DatabasePool): Promise<number> {
    // PostgreSQL: pg_last_wal_receive_lsn() vs pg_last_wal_replay_lsn()
    const result = await replica.query(`
      SELECT EXTRACT(EPOCH FROM (now() - pg_last_xact_replay_timestamp()))
        * 1000 AS lag_ms
    `);
    return result.rows[0]?.lag_ms ?? Infinity;
  }

  private shuffled<T>(arr: T[]): T[] {
    const copy = [...arr];
    for (let i = copy.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [copy[i], copy[j]] = [copy[j], copy[i]];
    }
    return copy;
  }
}

interface ReadOptions {
  requireFresh?: boolean;
}
```

## Causality Tracking trong Event-Driven Systems

### Correlation ID + Causation ID

```typescript
// Mỗi event mang hai IDs:
// - correlationId: ID của "business flow" gốc (ví dụ: orderId)
// - causationId: ID của event trực tiếp gây ra event này

interface DomainEvent {
  id: string;              // Unique event ID
  type: string;            // Event type
  aggregateId: string;     // Entity ID
  correlationId: string;   // Root cause trace
  causationId: string;     // Direct parent event
  timestamp: number;       // HLC timestamp
  payload: unknown;        // Event data
}

class EventPublisher {
  constructor(
    private readonly hlc: HybridLogicalClock,
    private readonly bus: EventBus,
  ) {}

  // Publish event gốc (không có parent)
  async publishRoot(
    type: string,
    aggregateId: string,
    payload: unknown,
  ): Promise<DomainEvent> {
    const id = crypto.randomUUID();
    const event: DomainEvent = {
      id,
      type,
      aggregateId,
      correlationId: id,  // Root event: correlationId = chính nó
      causationId: id,    // Root event: causationId = chính nó
      timestamp: HybridLogicalClock.encode(this.hlc.now()).toString() as unknown as number,
      payload,
    };

    await this.bus.publish(event);
    return event;
  }

  // Publish event phản ứng từ event khác (causal chain)
  async publishCaused(
    cause: DomainEvent,
    type: string,
    aggregateId: string,
    payload: unknown,
  ): Promise<DomainEvent> {
    const event: DomainEvent = {
      id: crypto.randomUUID(),
      type,
      aggregateId,
      correlationId: cause.correlationId,  // Giữ nguyên từ root
      causationId: cause.id,               // Parent = event gây ra
      timestamp: HybridLogicalClock.encode(this.hlc.now()).toString() as unknown as number,
      payload,
    };

    await this.bus.publish(event);
    return event;
  }
}

// === Ví dụ: Order flow với causal tracking ===
// OrderCreated (root)
//   → PaymentCharged (caused by OrderCreated)
//     → InventoryReserved (caused by PaymentCharged)
//       → ShipmentCreated (caused by InventoryReserved)
//         → NotificationSent (caused by ShipmentCreated)

// Tất cả events trên có CÙNG correlationId = OrderCreated.id
// → Dễ dàng trace toàn bộ flow trong logging/monitoring
```

### Causal Consistency trong Event Handlers

```typescript
// Đảm bảo events được xử lý theo đúng causal order

interface CausalEventHandler {
  handle(event: DomainEvent): Promise<void>;
}

class CausalOrderingMiddleware {
  private pendingEvents = new Map<string, DomainEvent[]>();
  private processedEvents = new Set<string>();

  constructor(private readonly handler: CausalEventHandler) {}

  async onEvent(event: DomainEvent): Promise<void> {
    // Root event hoặc parent đã xử lý → xử lý ngay
    if (
      event.causationId === event.id || // root event
      this.processedEvents.has(event.causationId) // parent đã xử lý
    ) {
      await this.processEvent(event);
      return;
    }

    // Parent chưa xử lý → buffer event, đợi parent
    const pending = this.pendingEvents.get(event.causationId) ?? [];
    pending.push(event);
    this.pendingEvents.set(event.causationId, pending);
  }

  private async processEvent(event: DomainEvent): Promise<void> {
    await this.handler.handle(event);
    this.processedEvents.add(event.id);

    // Xử lý các events đang đợi event này
    const waitingForThis = this.pendingEvents.get(event.id);
    if (waitingForThis) {
      this.pendingEvents.delete(event.id);
      for (const pending of waitingForThis) {
        await this.processEvent(pending);
      }
    }
  }
}
```

### Sequence Numbers cho Event Sourcing

```typescript
// Trong Event Sourcing, mỗi aggregate có sequence number riêng
// Đây là cách đáng tin cậy nhất để ordering events cho 1 entity

class EventSourcedAggregate {
  private version: number = 0;  // Sequence number
  private uncommittedEvents: VersionedEvent[] = [];

  protected apply(event: DomainEvent): void {
    this.version++;
    const versioned: VersionedEvent = {
      ...event,
      aggregateVersion: this.version,
    };
    this.uncommittedEvents.push(versioned);
    this.when(versioned);
  }

  protected abstract when(event: VersionedEvent): void;

  getUncommittedEvents(): VersionedEvent[] {
    return [...this.uncommittedEvents];
  }

  // Optimistic concurrency: chỉ append nếu version khớp
  async save(store: EventStore): Promise<void> {
    const expectedVersion = this.version - this.uncommittedEvents.length;

    try {
      await store.append(
        this.id,
        this.uncommittedEvents,
        expectedVersion, // CAS: expected version để detect concurrent writes
      );
    } catch (error) {
      if (error instanceof ConcurrencyError) {
        // Version mismatch → ai đó đã write trước
        // → Reload aggregate và retry business logic
        throw new OptimisticLockError(
          `Aggregate ${this.id} was modified concurrently`
        );
      }
      throw error;
    }

    this.uncommittedEvents = [];
  }
}

interface VersionedEvent extends DomainEvent {
  aggregateVersion: number;
}
```

## Tổng kết

| Mechanism | Detect Concurrency? | Scale | Use Case |
|-----------|---------------------|-------|----------|
| Wall Clock | No (unreliable) | Perfect | Display only |
| Lamport Clock | No | Perfect | Total ordering |
| Vector Clock | Yes | O(n) nodes | Conflict detection |
| HLC | Partial | Fixed size | Database MVCC |
| Sequence Number | N/A (single source) | Perfect | Event Sourcing |

> **Quy tac vang:** Dung wall clock de hien thi cho nguoi dung.
> Dung logical clock de ordering va causality.
> Dung HLC khi can ca hai.
> Dung sequence number khi co single authoritative source.
