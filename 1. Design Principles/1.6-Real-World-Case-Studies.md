## Case 1: Multi-tenant SaaS Billing System

**Context:** SaaS platform hỗ trợ multiple pricing models (flat, per-seat, usage-based, tiered),
multiple payment gateways, proration khi thay đổi plan, và invoice generation.

**Principles applied:** OCP, SRP, DIP, Strategy Pattern, Composition, Immutability

```typescript
// === Domain Layer (Pure business logic, zero dependencies) ===

// Value Objects — Immutable, self-validating
class Money {
  private constructor(
    readonly cents: number,
    readonly currency: Currency,
  ) {}

  static fromCents(cents: number, currency: Currency = 'USD'): Money {
    if (!Number.isInteger(cents)) throw new Error(`cents must be integer: ${cents}`);
    return new Money(cents, currency);
  }

  add(other: Money): Money {
    this.assertSameCurrency(other);
    return new Money(this.cents + other.cents, this.currency);
  }

  multiply(factor: number): Money {
    return new Money(Math.round(this.cents * factor), this.currency);
  }

  prorate(daysUsed: number, totalDays: number): Money {
    if (totalDays <= 0) throw new Error('totalDays must be positive');
    return this.multiply(daysUsed / totalDays);
  }

  private assertSameCurrency(other: Money): void {
    if (this.currency !== other.currency) {
      throw new CurrencyMismatchError(this.currency, other.currency);
    }
  }

  isZero(): boolean { return this.cents === 0; }
  isPositive(): boolean { return this.cents > 0; }
  toString(): string { return `${(this.cents / 100).toFixed(2)} ${this.currency}`; }
}

class BillingPeriod {
  constructor(
    readonly start: Date,
    readonly end: Date,
  ) {
    if (start >= end) throw new Error('start must be before end');
  }

  get totalDays(): number {
    return Math.ceil((this.end.getTime() - this.start.getTime()) / (1000 * 60 * 60 * 24));
  }

  daysRemainingFrom(date: Date): number {
    if (date > this.end) return 0;
    if (date < this.start) return this.totalDays;
    return Math.ceil((this.end.getTime() - date.getTime()) / (1000 * 60 * 60 * 24));
  }
}

// === Pricing Strategies (OCP: add new model = add new class) ===

interface PricingModel {
  readonly type: string;
  calculate(subscription: Subscription, period: BillingPeriod): LineItem[];
}

class FlatPricing implements PricingModel {
  readonly type = 'flat';

  constructor(private readonly monthlyPrice: Money) {}

  calculate(_subscription: Subscription, _period: BillingPeriod): LineItem[] {
    return [LineItem.create('Monthly subscription', this.monthlyPrice, 1)];
  }
}

class PerSeatPricing implements PricingModel {
  readonly type = 'per-seat';

  constructor(private readonly pricePerSeat: Money) {}

  calculate(subscription: Subscription, _period: BillingPeriod): LineItem[] {
    const seats = subscription.seatCount;
    return [LineItem.create(`${seats} seats × ${this.pricePerSeat}`, this.pricePerSeat, seats)];
  }
}

class UsageBasedPricing implements PricingModel {
  readonly type = 'usage';

  constructor(
    private readonly tiers: ReadonlyArray<UsageTier>,
    private readonly metricName: string,
  ) {}

  calculate(subscription: Subscription, period: BillingPeriod): LineItem[] {
    const usage = subscription.getUsage(this.metricName, period);
    const items: LineItem[] = [];
    let remaining = usage;

    for (const tier of this.tiers) {
      if (remaining <= 0) break;

      const tierUsage = tier.limit === Infinity
        ? remaining
        : Math.min(remaining, tier.limit - (tier.from ?? 0));

      if (tierUsage > 0) {
        items.push(LineItem.create(
          `${this.metricName}: ${tierUsage} units @ ${tier.pricePerUnit}`,
          tier.pricePerUnit,
          tierUsage,
        ));
        remaining -= tierUsage;
      }
    }

    return items;
  }
}

// Composite pricing (Composition pattern)
class CompositePricing implements PricingModel {
  readonly type = 'composite';

  constructor(private readonly models: ReadonlyArray<PricingModel>) {}

  calculate(subscription: Subscription, period: BillingPeriod): LineItem[] {
    return this.models.flatMap(model => model.calculate(subscription, period));
  }
}

// === Invoice Generation (SRP: only creates invoices) ===

class InvoiceGenerator {
  constructor(
    private readonly pricingRegistry: PricingRegistry,
    private readonly taxCalculator: TaxCalculator,
    private readonly discountEngine: DiscountEngine,
  ) {}

  generate(subscription: Subscription, period: BillingPeriod): Invoice {
    const pricing = this.pricingRegistry.getModel(subscription.plan);
    const lineItems = pricing.calculate(subscription, period);

    const subtotal = lineItems.reduce(
      (sum, item) => sum.add(item.total),
      Money.fromCents(0, subscription.currency),
    );

    const discounts = this.discountEngine.apply(subscription, subtotal);
    const afterDiscount = subtotal.add(discounts.totalDiscount); // discount is negative

    const tax = this.taxCalculator.calculate(afterDiscount, subscription.taxInfo);
    const total = afterDiscount.add(tax.amount);

    return Invoice.create({
      subscriptionId: subscription.id,
      period,
      lineItems,
      subtotal,
      discounts: discounts.items,
      tax,
      total,
    });
  }
}

// === Proration (Tell Don't Ask: Subscription calculates its own proration) ===

class Subscription {
  changePlan(newPlan: Plan, effectiveDate: Date): PlanChangeResult {
    const currentPeriod = this.currentBillingPeriod;
    const daysRemaining = currentPeriod.daysRemainingFrom(effectiveDate);

    // Credit for unused time on current plan
    const currentDailyRate = this.currentMonthlyPrice.multiply(1 / currentPeriod.totalDays);
    const credit = currentDailyRate.multiply(daysRemaining);

    // Charge for remaining time on new plan
    const newDailyRate = newPlan.monthlyPrice.multiply(1 / currentPeriod.totalDays);
    const charge = newDailyRate.multiply(daysRemaining);

    const netAmount = charge.add(credit.multiply(-1)); // charge - credit

    return new PlanChangeResult({
      previousPlan: this.plan,
      newPlan,
      credit,
      charge,
      netAmount,
      effectiveDate,
    });
  }
}

// === Usage ===

// Wire up (Composition Root / DI Container)
const pricingRegistry = new PricingRegistry();
pricingRegistry.register('starter', new FlatPricing(Money.fromCents(2999)));
pricingRegistry.register('team', new PerSeatPricing(Money.fromCents(1499)));
pricingRegistry.register('enterprise', new CompositePricing([
  new FlatPricing(Money.fromCents(49900)),
  new UsageBasedPricing([
    { from: 0, limit: 10000, pricePerUnit: Money.fromCents(0) },
    { from: 10000, limit: 100000, pricePerUnit: Money.fromCents(1) },
    { from: 100000, limit: Infinity, pricePerUnit: Money.fromCents(0.5) },
  ], 'api_calls'),
]));

// Adding new pricing model: create class + register. NOTHING else changes.
```

## Case 2: Event-Driven Notification System

**Context:** Multi-channel notifications (email, SMS, push, in-app, Slack) với:
- User preferences (opt-in/out per channel)
- Rate limiting (max 3 emails/hour)
- Template rendering
- Delivery tracking
- Retry with backoff

**Principles applied:** OCP, ISP, SoC, Hollywood Principle

```typescript
// === Event Types (Discriminated Union — type-safe, extensible) ===

type NotificationEvent =
  | { type: 'ORDER_CONFIRMED'; orderId: string; userId: string }
  | { type: 'PAYMENT_FAILED'; orderId: string; userId: string; reason: string }
  | { type: 'SHIPPING_UPDATE'; orderId: string; userId: string; status: ShippingStatus }
  | { type: 'ACCOUNT_SECURITY'; userId: string; action: SecurityAction; ip: string };

// === Channel Interface (ISP: minimal interface per capability) ===

interface NotificationChannel {
  readonly channelType: ChannelType;
  send(notification: RenderedNotification): Promise<DeliveryResult>;
}

interface ChannelHealthCheck {
  healthCheck(): Promise<HealthStatus>;
}

interface BatchCapable {
  sendBatch(notifications: ReadonlyArray<RenderedNotification>): Promise<BatchResult>;
}

// === Template System (SoC: rendering separate from delivery) ===

interface TemplateRenderer {
  render(event: NotificationEvent, channel: ChannelType): Promise<RenderedNotification>;
}

class HandlebarsTemplateRenderer implements TemplateRenderer {
  constructor(private readonly templateStore: TemplateStore) {}

  async render(event: NotificationEvent, channel: ChannelType): Promise<RenderedNotification> {
    const template = await this.templateStore.get(event.type, channel);
    const context = await this.buildContext(event);
    return {
      subject: template.subject ? Handlebars.compile(template.subject)(context) : undefined,
      body: Handlebars.compile(template.body)(context),
      metadata: template.metadata,
    };
  }

  private async buildContext(event: NotificationEvent): Promise<Record<string, unknown>> {
    // Enrich event data with additional context
    switch (event.type) {
      case 'ORDER_CONFIRMED':
        const order = await this.orderService.findById(event.orderId);
        return { order, user: await this.userService.findById(event.userId) };
      // ... other cases
    }
  }
}

// === Rate Limiter (SRP: only handles rate limiting logic) ===

class NotificationRateLimiter {
  constructor(private readonly redis: Redis) {}

  async canSend(userId: string, channel: ChannelType): Promise<boolean> {
    const key = `rate:notify:${userId}:${channel}`;
    const limits = RATE_LIMITS[channel];
    const count = await this.redis.incr(key);

    if (count === 1) {
      await this.redis.expire(key, limits.windowSeconds);
    }

    return count <= limits.maxPerWindow;
  }

  async getRemainingQuota(userId: string, channel: ChannelType): Promise<number> {
    const key = `rate:notify:${userId}:${channel}`;
    const count = await this.redis.get(key);
    return Math.max(0, RATE_LIMITS[channel].maxPerWindow - (Number(count) || 0));
  }
}

// === Preference Service (SRP: only handles user preferences) ===

class NotificationPreferenceService {
  constructor(private readonly repo: PreferenceRepository) {}

  async getEnabledChannels(
    userId: string,
    eventType: NotificationEvent['type'],
  ): Promise<ReadonlyArray<ChannelType>> {
    const prefs = await this.repo.findByUser(userId);

    // Security events always go to all channels — business rule
    if (eventType === 'ACCOUNT_SECURITY') {
      return ALL_CHANNELS;
    }

    return ALL_CHANNELS.filter(channel => {
      const pref = prefs.find(p => p.channel === channel && p.eventType === eventType);
      return pref?.enabled ?? DEFAULT_PREFERENCES[eventType]?.[channel] ?? true;
    });
  }
}

// === Orchestrator (Composition: wires everything together) ===

class NotificationOrchestrator {
  constructor(
    private readonly preferences: NotificationPreferenceService,
    private readonly rateLimiter: NotificationRateLimiter,
    private readonly renderer: TemplateRenderer,
    private readonly channels: ReadonlyMap<ChannelType, NotificationChannel>,
    private readonly tracker: DeliveryTracker,
    private readonly deadLetterQueue: DeadLetterQueue,
  ) {}

  async handle(event: NotificationEvent): Promise<NotificationResult> {
    const enabledChannels = await this.preferences.getEnabledChannels(
      event.userId,
      event.type,
    );

    const results: ChannelResult[] = [];

    for (const channelType of enabledChannels) {
      // Rate limit check
      const canSend = await this.rateLimiter.canSend(event.userId, channelType);
      if (!canSend) {
        results.push({ channel: channelType, status: 'rate_limited' });
        continue;
      }

      const channel = this.channels.get(channelType);
      if (!channel) {
        results.push({ channel: channelType, status: 'channel_unavailable' });
        continue;
      }

      try {
        const rendered = await this.renderer.render(event, channelType);
        const delivery = await channel.send(rendered);
        await this.tracker.record(event, channelType, delivery);
        results.push({ channel: channelType, status: 'sent', deliveryId: delivery.id });
      } catch (error) {
        await this.deadLetterQueue.push({ event, channelType, error, timestamp: new Date() });
        results.push({ channel: channelType, status: 'failed', error: String(error) });
      }
    }

    return new NotificationResult(event, results);
  }
}

// === Adding new channel: create class + register. NOTHING else changes. ===

// New: WhatsApp channel
class WhatsAppChannel implements NotificationChannel {
  readonly channelType: ChannelType = 'whatsapp';

  constructor(private readonly client: WhatsAppBusinessClient) {}

  async send(notification: RenderedNotification): Promise<DeliveryResult> {
    const response = await this.client.messages.send({
      to: notification.recipient.phone,
      type: 'template',
      template: { name: notification.metadata.templateId, body: notification.body },
    });
    return { id: response.messageId, status: 'accepted', timestamp: new Date() };
  }
}

// Register in composition root
channels.set('whatsapp', new WhatsAppChannel(whatsappClient));
// Done. Orchestrator, preferences, rate limiter, tracker all work automatically.
```

## Case 3: API Rate Limiter

**Context:** Rate limiting middleware cho API, hỗ trợ multiple algorithms,
per-user/per-IP/per-endpoint limits, distributed deployment với Redis.

**Principles applied:** Strategy, DIP, KISS, Fail Fast, Composition

```typescript
// === Core Interface (DIP: application depends on this abstraction) ===

interface RateLimiter {
  /**
   * Attempt to consume a token. Returns result immediately.
   * @returns allowed: true if request can proceed, false if rate limited
   */
  consume(key: string): Promise<RateLimitResult>;
}

interface RateLimitResult {
  readonly allowed: boolean;
  readonly limit: number;
  readonly remaining: number;
  readonly retryAfterMs: number | null;
  readonly resetAt: Date;
}

// === Algorithms (Strategy: swap without changing consumers) ===

// Fixed Window — simplest, good enough for most cases (KISS)
class FixedWindowLimiter implements RateLimiter {
  constructor(
    private readonly store: CounterStore,
    private readonly limit: number,
    private readonly windowMs: number,
  ) {}

  async consume(key: string): Promise<RateLimitResult> {
    const windowKey = `${key}:${Math.floor(Date.now() / this.windowMs)}`;
    const count = await this.store.increment(windowKey, this.windowMs);
    const resetAt = new Date(Math.ceil(Date.now() / this.windowMs) * this.windowMs);

    return {
      allowed: count <= this.limit,
      limit: this.limit,
      remaining: Math.max(0, this.limit - count),
      retryAfterMs: count > this.limit ? resetAt.getTime() - Date.now() : null,
      resetAt,
    };
  }
}

// Sliding Window Log — more accurate, higher memory
class SlidingWindowLogLimiter implements RateLimiter {
  constructor(
    private readonly store: SortedSetStore,
    private readonly limit: number,
    private readonly windowMs: number,
  ) {}

  async consume(key: string): Promise<RateLimitResult> {
    const now = Date.now();
    const windowStart = now - this.windowMs;

    // Remove entries outside window
    await this.store.removeRange(key, 0, windowStart);

    // Count entries in window
    const count = await this.store.count(key);

    if (count >= this.limit) {
      const oldestEntry = await this.store.oldest(key);
      const retryAfterMs = oldestEntry ? (oldestEntry + this.windowMs) - now : this.windowMs;
      return {
        allowed: false,
        limit: this.limit,
        remaining: 0,
        retryAfterMs,
        resetAt: new Date(now + retryAfterMs),
      };
    }

    // Add current request
    await this.store.add(key, now);
    await this.store.expire(key, this.windowMs);

    return {
      allowed: true,
      limit: this.limit,
      remaining: this.limit - count - 1,
      retryAfterMs: null,
      resetAt: new Date(now + this.windowMs),
    };
  }
}

// Token Bucket — allows bursts, smooth rate
class TokenBucketLimiter implements RateLimiter {
  constructor(
    private readonly store: TokenBucketStore,
    private readonly capacity: number,
    private readonly refillRate: number, // tokens per second
  ) {}

  async consume(key: string): Promise<RateLimitResult> {
    const bucket = await this.store.get(key);
    const now = Date.now();

    // Refill tokens based on elapsed time
    const elapsed = (now - bucket.lastRefill) / 1000;
    const newTokens = Math.min(
      this.capacity,
      bucket.tokens + elapsed * this.refillRate,
    );

    if (newTokens < 1) {
      const waitTime = (1 - newTokens) / this.refillRate * 1000;
      return {
        allowed: false,
        limit: this.capacity,
        remaining: 0,
        retryAfterMs: Math.ceil(waitTime),
        resetAt: new Date(now + waitTime),
      };
    }

    await this.store.set(key, { tokens: newTokens - 1, lastRefill: now });

    return {
      allowed: true,
      limit: this.capacity,
      remaining: Math.floor(newTokens - 1),
      retryAfterMs: null,
      resetAt: new Date(now + (this.capacity - newTokens + 1) / this.refillRate * 1000),
    };
  }
}

// === Key Extraction Strategies (Composition) ===

type KeyExtractor = (req: Request) => string;

const byIp: KeyExtractor = (req) => `ip:${req.ip}`;
const byUser: KeyExtractor = (req) => `user:${req.user?.id ?? req.ip}`;
const byEndpoint: KeyExtractor = (req) => `ep:${req.method}:${req.path}`;
const composite = (...extractors: KeyExtractor[]): KeyExtractor =>
  (req) => extractors.map(e => e(req)).join(':');

// === Middleware Factory (Composition: combine limiter + key extractor + response) ===

function createRateLimitMiddleware(config: {
  limiter: RateLimiter;
  keyExtractor: KeyExtractor;
  onLimited?: (req: Request, result: RateLimitResult) => void;
}): Middleware {
  return async (req: Request, res: Response, next: NextFunction) => {
    const key = config.keyExtractor(req);
    const result = await config.limiter.consume(key);

    // Always set rate limit headers (POLA: client can always see limits)
    res.setHeader('X-RateLimit-Limit', result.limit);
    res.setHeader('X-RateLimit-Remaining', result.remaining);
    res.setHeader('X-RateLimit-Reset', Math.ceil(result.resetAt.getTime() / 1000));

    if (!result.allowed) {
      res.setHeader('Retry-After', Math.ceil((result.retryAfterMs ?? 1000) / 1000));
      config.onLimited?.(req, result);
      res.status(429).json({
        error: 'Too Many Requests',
        retryAfterMs: result.retryAfterMs,
      });
      return;
    }

    next();
  };
}

// === Usage — compose components to match requirements ===

// Global: 100 req/min per IP
app.use(createRateLimitMiddleware({
  limiter: new FixedWindowLimiter(redisCounterStore, 100, 60_000),
  keyExtractor: byIp,
}));

// Auth endpoints: 5 req/min per IP (brute force protection)
app.use('/auth/*', createRateLimitMiddleware({
  limiter: new SlidingWindowLogLimiter(redisSortedSetStore, 5, 60_000),
  keyExtractor: byIp,
  onLimited: (req) => logger.warn('Auth rate limit hit', { ip: req.ip }),
}));

// API: 1000 req/min per user, burst allowed
app.use('/api/*', createRateLimitMiddleware({
  limiter: new TokenBucketLimiter(redisTokenBucketStore, 100, 16.67),
  keyExtractor: composite(byUser, byEndpoint),
}));
```

## Case 4: Feature Flag System

**Context:** Feature flags cho gradual rollout, A/B testing, và kill switches.
Cần: type-safe flags, percentage rollout, user targeting, runtime toggle.

**Principles applied:** KISS (start simple), Type Safety, Immutability, SoC

```typescript
// === Type-Safe Flag Definitions ===

// Flag registry — single source of truth
interface FlagDefinitions {
  'new-checkout-flow': boolean;
  'max-upload-size-mb': number;
  'pricing-tier-v2': boolean;
  'dark-mode': boolean;
  'ai-suggestions': boolean;
}

type FlagName = keyof FlagDefinitions;
type FlagValue<K extends FlagName> = FlagDefinitions[K];

// === Evaluation Context (Immutable) ===

interface EvaluationContext {
  readonly userId?: string;
  readonly email?: string;
  readonly country?: string;
  readonly plan?: string;
  readonly percentile?: number; // Pre-calculated, stable per user
  readonly custom?: Readonly<Record<string, string | number | boolean>>;
}

// === Flag Rules ===

type FlagRule<T> =
  | { type: 'static'; value: T }
  | { type: 'percentage'; percentage: number; valueIfEnabled: T; valueIfDisabled: T }
  | { type: 'allowlist'; field: keyof EvaluationContext; values: ReadonlyArray<string>; valueIfMatch: T; valueIfNoMatch: T }
  | { type: 'conditional'; conditions: ReadonlyArray<Condition>; valueIfMatch: T; valueIfNoMatch: T };

interface Condition {
  field: keyof EvaluationContext;
  operator: 'eq' | 'neq' | 'in' | 'gt' | 'lt';
  value: string | number | boolean | ReadonlyArray<string>;
}

// === Feature Flag Client (KISS: simple API surface) ===

class FeatureFlags {
  private flags: ReadonlyMap<string, FlagConfig>;

  constructor(
    private readonly store: FlagStore,
    private readonly defaults: FlagDefinitions,
  ) {
    this.flags = new Map();
  }

  // Type-safe evaluation
  async isEnabled<K extends FlagName>(
    flag: K,
    context: EvaluationContext,
  ): Promise<FlagValue<K>> {
    const config = this.flags.get(flag);
    if (!config) return this.defaults[flag] as FlagValue<K>;

    // Kill switch — always respect
    if (config.killed) return config.killedValue as FlagValue<K>;

    return this.evaluate(config.rules, context) as FlagValue<K>;
  }

  // Bulk evaluation (performance: single call for all flags)
  async evaluateAll(context: EvaluationContext): Promise<Readonly<FlagDefinitions>> {
    const result = { ...this.defaults };
    for (const [name, config] of this.flags) {
      if (name in result) {
        (result as any)[name] = config.killed
          ? config.killedValue
          : this.evaluate(config.rules, context);
      }
    }
    return result;
  }

  private evaluate<T>(rules: ReadonlyArray<FlagRule<T>>, context: EvaluationContext): T {
    for (const rule of rules) {
      switch (rule.type) {
        case 'static':
          return rule.value;

        case 'percentage':
          return (context.percentile ?? Math.random() * 100) < rule.percentage
            ? rule.valueIfEnabled
            : rule.valueIfDisabled;

        case 'allowlist': {
          const fieldValue = String(context[rule.field] ?? '');
          return (rule.values as ReadonlyArray<string>).includes(fieldValue)
            ? rule.valueIfMatch
            : rule.valueIfNoMatch;
        }

        case 'conditional': {
          const allMatch = rule.conditions.every(c => this.matchCondition(c, context));
          return allMatch ? rule.valueIfMatch : rule.valueIfNoMatch;
        }
      }
    }

    throw new Error('No rules matched'); // Fail fast
  }

  private matchCondition(condition: Condition, context: EvaluationContext): boolean {
    const value = context[condition.field];
    switch (condition.operator) {
      case 'eq': return value === condition.value;
      case 'neq': return value !== condition.value;
      case 'in': return (condition.value as ReadonlyArray<string>).includes(String(value));
      case 'gt': return Number(value) > Number(condition.value);
      case 'lt': return Number(value) < Number(condition.value);
    }
  }

  // Refresh from store (called periodically or on webhook)
  async refresh(): Promise<void> {
    this.flags = await this.store.loadAll();
  }
}

// === Usage — clean and type-safe ===

const flags = new FeatureFlags(redisStore, {
  'new-checkout-flow': false,
  'max-upload-size-mb': 10,
  'pricing-tier-v2': false,
  'dark-mode': false,
  'ai-suggestions': false,
});

// In request handler
async function handleUpload(req: Request) {
  const context: EvaluationContext = {
    userId: req.user.id,
    email: req.user.email,
    plan: req.user.plan,
    percentile: hashToPercentile(req.user.id),
  };

  const maxSize = await flags.isEnabled('max-upload-size-mb', context);
  // maxSize is typed as `number` — compiler knows!

  if (req.file.size > maxSize * 1024 * 1024) {
    throw new FileTooLargeError(maxSize);
  }

  const useNewCheckout = await flags.isEnabled('new-checkout-flow', context);
  // useNewCheckout is typed as `boolean`
}
```

## Case 5: File Processing Pipeline

**Context:** Upload file → validate → transform → store → notify.
Hỗ trợ images (resize, compress), documents (pdf extract), video (transcode).

**Principles applied:** Composition, OCP, SRP, Pipeline Pattern

```typescript
// === Pipeline Step Interface ===

interface PipelineStep<TInput, TOutput> {
  readonly name: string;
  execute(input: TInput): Promise<TOutput>;
}

// === Generic Pipeline Builder ===

class Pipeline<TInput, TOutput> {
  private constructor(
    private readonly steps: ReadonlyArray<PipelineStep<any, any>>,
    private readonly errorHandler: PipelineErrorHandler,
  ) {}

  static create<T>(errorHandler?: PipelineErrorHandler): Pipeline<T, T> {
    return new Pipeline([], errorHandler ?? defaultErrorHandler);
  }

  pipe<TNext>(step: PipelineStep<TOutput, TNext>): Pipeline<TInput, TNext> {
    return new Pipeline([...this.steps, step], this.errorHandler);
  }

  async execute(input: TInput): Promise<PipelineResult<TOutput>> {
    let current: any = input;
    const completedSteps: string[] = [];

    for (const step of this.steps) {
      try {
        current = await step.execute(current);
        completedSteps.push(step.name);
      } catch (error) {
        return {
          success: false,
          error: error as Error,
          failedStep: step.name,
          completedSteps,
        };
      }
    }

    return { success: true, output: current, completedSteps };
  }
}

// === Concrete Steps (SRP: each step does ONE thing) ===

class FileValidationStep implements PipelineStep<UploadedFile, ValidatedFile> {
  readonly name = 'validate';

  constructor(private readonly rules: FileValidationRules) {}

  async execute(file: UploadedFile): Promise<ValidatedFile> {
    if (file.size > this.rules.maxSize) {
      throw new FileTooLargeError(file.size, this.rules.maxSize);
    }

    if (!this.rules.allowedMimeTypes.includes(file.mimeType)) {
      throw new InvalidFileTypeError(file.mimeType, this.rules.allowedMimeTypes);
    }

    // Verify actual content matches declared mime type
    const detectedType = await fileType.fromBuffer(file.buffer);
    if (detectedType?.mime !== file.mimeType) {
      throw new MimeTypeMismatchError(file.mimeType, detectedType?.mime);
    }

    return { ...file, validated: true };
  }
}

class ImageResizeStep implements PipelineStep<ValidatedFile, ProcessedFile> {
  readonly name = 'resize';

  constructor(private readonly options: ResizeOptions) {}

  async execute(file: ValidatedFile): Promise<ProcessedFile> {
    const image = sharp(file.buffer);
    const metadata = await image.metadata();

    const needsResize = (metadata.width ?? 0) > this.options.maxWidth
      || (metadata.height ?? 0) > this.options.maxHeight;

    const processed = needsResize
      ? await image.resize(this.options.maxWidth, this.options.maxHeight, { fit: 'inside' }).toBuffer()
      : file.buffer;

    return {
      ...file,
      buffer: processed,
      size: processed.length,
      metadata: { width: metadata.width, height: metadata.height, format: metadata.format },
    };
  }
}

class ImageCompressionStep implements PipelineStep<ProcessedFile, ProcessedFile> {
  readonly name = 'compress';

  constructor(private readonly quality: number = 80) {}

  async execute(file: ProcessedFile): Promise<ProcessedFile> {
    const compressed = await sharp(file.buffer)
      .webp({ quality: this.quality })
      .toBuffer();

    return {
      ...file,
      buffer: compressed,
      size: compressed.length,
      mimeType: 'image/webp',
    };
  }
}

class StorageStep implements PipelineStep<ProcessedFile, StoredFile> {
  readonly name = 'store';

  constructor(private readonly storage: FileStorage) {}

  async execute(file: ProcessedFile): Promise<StoredFile> {
    const key = `uploads/${Date.now()}-${crypto.randomUUID()}.${file.extension}`;
    const url = await this.storage.upload(file.buffer, key);
    return { ...file, storageKey: key, url };
  }
}

class MetadataRecordStep implements PipelineStep<StoredFile, StoredFile> {
  readonly name = 'record-metadata';

  constructor(private readonly db: FileMetadataRepository) {}

  async execute(file: StoredFile): Promise<StoredFile> {
    await this.db.save({
      id: crypto.randomUUID(),
      originalName: file.originalName,
      storageKey: file.storageKey,
      url: file.url,
      mimeType: file.mimeType,
      size: file.size,
      metadata: file.metadata,
      uploadedAt: new Date(),
    });
    return file;
  }
}

// === Pipeline Factory (OCP: add new file type = add new pipeline) ===

class PipelineFactory {
  createImagePipeline(): Pipeline<UploadedFile, StoredFile> {
    return Pipeline.create<UploadedFile>()
      .pipe(new FileValidationStep({
        maxSize: 10 * 1024 * 1024,
        allowedMimeTypes: ['image/jpeg', 'image/png', 'image/webp'],
      }))
      .pipe(new ImageResizeStep({ maxWidth: 2048, maxHeight: 2048 }))
      .pipe(new ImageCompressionStep(85))
      .pipe(new StorageStep(this.storage))
      .pipe(new MetadataRecordStep(this.metadataRepo));
  }

  createDocumentPipeline(): Pipeline<UploadedFile, StoredFile> {
    return Pipeline.create<UploadedFile>()
      .pipe(new FileValidationStep({
        maxSize: 50 * 1024 * 1024,
        allowedMimeTypes: ['application/pdf', 'application/msword'],
      }))
      .pipe(new VirusScanStep(this.virusScanner))
      .pipe(new StorageStep(this.storage))
      .pipe(new MetadataRecordStep(this.metadataRepo))
      .pipe(new TextExtractionStep(this.textExtractor));
  }

  createAvatarPipeline(): Pipeline<UploadedFile, StoredFile> {
    return Pipeline.create<UploadedFile>()
      .pipe(new FileValidationStep({

      .pipe(new ImageResizeStep({ maxWidth: 256, maxHeight: 256 }))

      .pipe(new MetadataRecordStep(this.metadataRepo));
  }
```

### 2. Anemic Domain Model

```typescript

interface Order {
  id: string;
  status: string;
  items: Item[];
  total: number;
}

class OrderService {
  canCancel(order: Order): boolean {
    return order.status === 'pending' || order.status === 'confirmed';
  }

  cancel(order: Order): void {
    if (!this.canCancel(order)) throw new Error('Cannot cancel');
    order.status = 'cancelled'; // Mutating from outside
  }

  calculateTotal(order: Order): number {
    return order.items.reduce((sum, item) => sum + item.price * item.qty, 0);
  }
}

// ✅ Rich Domain Model: logic lives with data
class Order {
  cancel(): void {
    if (!this.canCancel) throw new CannotCancelError(this.status);
    this._status = 'cancelled';
  }

  get canCancel(): boolean {
    return this._status === 'pending' || this._status === 'confirmed';
  }

  get total(): Money {
    return this._items.reduce((sum, item) => sum.add(item.subtotal), Money.zero());
  }
}
```

### 3. Primitive Obsession

```typescript
// ❌ Primitive types cho domain concepts

  name: string,        // Any string? "X"? ""? 500 chars?
  email: string,       // Any string? "not-an-email"?

function createUser(
  name: UserName,       // Validated: 2-100 chars, no special chars
  email: EmailAddress,  // Validated: proper email format
  age: Age,             // Validated: 0-150, integer
  currency: Currency,   // Validated: ISO 4217 code
): void {}

class EmailAddress {
  private constructor(readonly value: string) {}

  static create(raw: string): EmailAddress {
    const normalized = raw.trim().toLowerCase();
    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(normalized)) {
      throw new InvalidEmailError(raw);
    }
    return new EmailAddress(normalized);
  }

  get domain(): string {
    return this.value.split('@')[1];
  }

  equals(other: EmailAddress): boolean {
    return this.value === other.value;
  }
}
```

## Decision Framework tổng hợp

### Khi thiết kế một feature mới, hỏi theo thứ tự:

```
1. YAGNI CHECK
   → Feature này cần NGAY BÂY GIỜ không?
   → Nếu không → đừng làm

2. KISS CHECK
   → Giải pháp đơn giản nhất mà ĐÚNG là gì?
   → Bắt đầu từ đó

3. SRP CHECK
   → Module/class này có bao nhiêu lý do để thay đổi?
   → Nếu > 1 → tách

4. DIP CHECK
   → Module này cần testable không? Cần swap implementation không?
   → Nếu có → define interface, inject dependency
   → Nếu không → direct dependency OK

5. OCP CHECK
   → Sẽ có thêm variant/strategy/type mới không?
   → Nếu có → design for extension (interface + strategy)
   → Nếu không chắc → viết thẳng, refactor khi cần

6. COMPOSITION CHECK
   → Đang muốn dùng inheritance?
   → True "is-a"? → OK, max 2-3 levels
   → "has-a" / "uses-a"? → Composition

7. FAIL FAST CHECK
   → Input validation ở boundary?
   → Domain invariants enforced?
   → Config validated at startup?

8. IMMUTABILITY CHECK
   → Shared state? → Make immutable
   → Value object? → Make immutable
   → Function parameter? → Don't mutate
```

### Pragmatic Principles Summary

| Principle | Khi nào quan trọng NHẤT | Khi nào bẻ cong OK |
|-----------|------------------------|---------------------|
| SRP | Team > 3 người, codebase > 10k LOC | Script nhỏ, prototype |
| OCP | Có > 2 variants, đang thêm thường xuyên | Chỉ có 1 case, chắc chắn không thêm |
| LSP | Dùng inheritance, polymorphic code | Không dùng inheritance |
| ISP | Interface > 5 methods, có clients chỉ dùng subset | Interface nhỏ (< 4 methods) |
| DIP | Cần test, cần swap, cần isolate | Simple app, no tests needed |
| DRY | Same business rule ở > 1 nơi | Code trông giống nhưng khác domain |
| KISS | LUÔN LUÔN | Khi domain inherently complex |
| YAGNI | LUÔN LUÔN | DB schema, public APIs, security |
| Composition | Default choice | True "is-a", shallow hierarchy |
| Immutability | Shared state, value objects | Local mutation, performance |
| Fail Fast | LUÔN LUÔN tại boundaries | Trong chưa viết tests |
| POLA | Public APIs, shared code | Private implementation details |
