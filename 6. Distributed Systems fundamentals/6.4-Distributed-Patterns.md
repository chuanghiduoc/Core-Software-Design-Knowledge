## Consistent Hashing

### Vấn đề

```
Bạn có N cache servers. Hash key vào server:
  server = hash(key) % N

Khi thêm/bớt server (N thay đổi):
  hash(key) % 4 ≠ hash(key) % 5 cho hầu hết keys
  → Gần như TẤT CẢ keys phải di chuyển → cache miss storm → database overload
```

### Giải pháp: Consistent Hashing

```
Thay vì modulo, hash cả key VÀ server lên một vòng tròn (ring) [0, 2^32).
Key thuộc về server gần nhất theo chiều kim đồng hồ.

Khi thêm/bớt 1 server:
  Chỉ ~1/N keys phải di chuyển (thay vì gần 100%)
```

### TypeScript Implementation

```typescript
import { createHash } from 'crypto';

interface ConsistentHashConfig {
  /** Số virtual nodes per physical node — giúp phân bổ đều hơn */
  virtualNodeCount: number;
  /** Hash function to use */
  hashFunction?: (key: string) => number;
}

class ConsistentHashRing<T> {
  private ring = new Map<number, T>();     // hash position → node
  private sortedKeys: number[] = [];        // sorted hash positions
  private readonly virtualNodeCount: number;
  private readonly hash: (key: string) => number;

  constructor(config: ConsistentHashConfig = { virtualNodeCount: 150 }) {
    this.virtualNodeCount = config.virtualNodeCount;
    this.hash = config.hashFunction ?? this.defaultHash;
  }

  /**
   * Thêm node vào ring
   * Tạo N virtual nodes để phân bổ đều
   */
  addNode(nodeId: string, node: T): void {
    for (let i = 0; i < this.virtualNodeCount; i++) {
      const virtualKey = `${nodeId}#vnode${i}`;
      const hashValue = this.hash(virtualKey);
      this.ring.set(hashValue, node);
      this.sortedKeys.push(hashValue);
    }
    this.sortedKeys.sort((a, b) => a - b);
  }

  /**
   * Xóa node khỏi ring
   */
  removeNode(nodeId: string): void {
    for (let i = 0; i < this.virtualNodeCount; i++) {
      const virtualKey = `${nodeId}#vnode${i}`;
      const hashValue = this.hash(virtualKey);
      this.ring.delete(hashValue);
    }
    this.sortedKeys = this.sortedKeys.filter(k => this.ring.has(k));
  }

  /**
   * Tìm node chịu trách nhiệm cho key
   * → Tìm vị trí tiếp theo trên ring theo chiều kim đồng hồ
   */
  getNode(key: string): T | undefined {
    if (this.sortedKeys.length === 0) return undefined;

    const hashValue = this.hash(key);

    // Binary search: tìm vị trí đầu tiên >= hashValue
    let idx = this.binarySearchCeil(hashValue);

    // Wrap around nếu vượt quá ring
    if (idx >= this.sortedKeys.length) {
      idx = 0;
    }

    return this.ring.get(this.sortedKeys[idx]);
  }

  /**
   * Lấy N nodes chịu trách nhiệm (cho replication)
   * Ví dụ: Cassandra dùng replication factor = 3
   */
  getNodes(key: string, count: number): T[] {
    if (this.sortedKeys.length === 0) return [];

    const hashValue = this.hash(key);
    let idx = this.binarySearchCeil(hashValue);
    if (idx >= this.sortedKeys.length) idx = 0;

    const result: T[] = [];
    const seen = new Set<T>(); // Tránh duplicate nodes (virtual nodes cùng physical node)

    let steps = 0;
    while (result.length < count && steps < this.sortedKeys.length) {
      const node = this.ring.get(this.sortedKeys[idx])!;
      if (!seen.has(node)) {
        seen.add(node);
        result.push(node);
      }
      idx = (idx + 1) % this.sortedKeys.length;
      steps++;
    }

    return result;
  }

  private binarySearchCeil(target: number): number {
    let lo = 0;
    let hi = this.sortedKeys.length;
    while (lo < hi) {
      const mid = (lo + hi) >>> 1;
      if (this.sortedKeys[mid] < target) {
        lo = mid + 1;
      } else {
        hi = mid;
      }
    }
    return lo;
  }

  private defaultHash(key: string): number {
    const hash = createHash('md5').update(key).digest();
    // Lấy 4 bytes đầu làm 32-bit integer
    return hash.readUInt32BE(0);
  }
}

// === Usage: Distributed Cache ===

interface CacheNode {
  host: string;
  port: number;
}

class DistributedCache {
  private ring = new ConsistentHashRing<CacheNode>({ virtualNodeCount: 150 });
  private clients = new Map<string, CacheClient>();

  addServer(id: string, node: CacheNode): void {
    this.ring.addNode(id, node);
    this.clients.set(`${node.host}:${node.port}`, new CacheClient(node));
  }

  async get(key: string): Promise<string | null> {
    const node = this.ring.getNode(key);
    if (!node) return null;

    const client = this.clients.get(`${node.host}:${node.port}`)!;
    return client.get(key);
  }

  async set(key: string, value: string, ttl?: number): Promise<void> {
    const node = this.ring.getNode(key);
    if (!node) throw new Error('No nodes available');

    const client = this.clients.get(`${node.host}:${node.port}`)!;
    await client.set(key, value, ttl);
  }

  // Khi thêm server: chỉ ~1/N keys cần di chuyển
  async addServerWithMigration(id: string, node: CacheNode): Promise<void> {
    this.addServer(id, node);
    // Migration sẽ xảy ra tự nhiên qua cache miss:
    // - Cache miss → fetch from source → write vào server MỚI
    // - Không cần bulk migration
  }
}
```

### Virtual Nodes — Tại sao cần?

```
Không có virtual nodes:
  3 servers, mỗi server 1 vị trí trên ring
  → Phân bổ rất KHÔNG đều (1 server có thể nhận 50%+ traffic)

Có virtual nodes (150 per server):
  3 servers × 150 = 450 vị trí trên ring
  → Phân bổ gần đều (~33% mỗi server)
  → Standard deviation giảm đáng kể

Rule of thumb: 100-200 virtual nodes per physical node
```

## Gossip Protocol

> Gossip (Epidemic Protocol): Mỗi node định kỳ chia sẻ thông tin với một vài nodes ngẫu nhiên.
> Thông tin "lan truyền" như virus — cuối cùng mọi node đều biết.
> Được dùng trong Cassandra, Consul, SWIM, Serf.

### Membership & Failure Detection

```typescript
interface GossipMember {
  nodeId: string;
  address: string;
  state: 'alive' | 'suspected' | 'dead';
  heartbeat: number;      // Lamport-like counter
  metadata: Record<string, string>; // Custom data (role, version, etc.)
}

class GossipProtocol {
  private members = new Map<string, GossipMember>();
  private readonly nodeId: string;
  private heartbeat = 0;
  private gossipInterval: ReturnType<typeof setInterval> | null = null;

  constructor(
    nodeId: string,
    address: string,
    private readonly config: {
      gossipIntervalMs: number;     // 1000ms — tần suất gossip
      gossipFanout: number;          // 3 — số nodes gửi mỗi round
      suspicionTimeout: number;      // 5000ms — thời gian trước khi suspected → dead
      transport: GossipTransport;
    }
  ) {
    this.nodeId = nodeId;
    // Thêm chính mình
    this.members.set(nodeId, {
      nodeId,
      address,
      state: 'alive',
      heartbeat: 0,
      metadata: {},
    });
  }

  start(): void {
    this.gossipInterval = setInterval(
      () => this.gossipRound(),
      this.config.gossipIntervalMs,
    );
  }

  stop(): void {
    if (this.gossipInterval) {
      clearInterval(this.gossipInterval);
    }
  }

  // Mỗi gossip round: chọn ngẫu nhiên N peers và gửi member list
  private async gossipRound(): Promise<void> {
    // Tăng heartbeat
    this.heartbeat++;
    const self = this.members.get(this.nodeId)!;
    self.heartbeat = this.heartbeat;

    // Chọn ngẫu nhiên fanout peers
    const peers = this.selectRandomPeers(this.config.gossipFanout);

    // Gửi member list cho mỗi peer
    const memberList = Array.from(this.members.values());

    for (const peer of peers) {
      try {
        const remoteMemberList = await this.config.transport.sendGossip(
          peer.address,
          memberList,
        );
        // Merge response
        this.mergeMemberList(remoteMemberList);
      } catch {
        // Peer unreachable → suspect it
        this.suspectMember(peer.nodeId);
      }
    }

    // Cleanup dead members
    this.checkSuspectedMembers();
  }

  // Merge member list từ peer
  private mergeMemberList(remoteMembers: GossipMember[]): void {
    for (const remote of remoteMembers) {
      const local = this.members.get(remote.nodeId);

      if (!local) {
        // Node mới — thêm vào
        this.members.set(remote.nodeId, { ...remote });
        continue;
      }

      // Heartbeat cao hơn → thông tin mới hơn
      if (remote.heartbeat > local.heartbeat) {
        local.heartbeat = remote.heartbeat;
        local.state = remote.state;
        local.metadata = { ...remote.metadata };

        // Nếu đang suspected nhưng remote nói alive → alive
        if (local.state === 'suspected' && remote.state === 'alive') {
          local.state = 'alive';
        }
      }
    }
  }

  private suspectMember(nodeId: string): void {
    const member = this.members.get(nodeId);
    if (member && member.state === 'alive') {
      member.state = 'suspected';
      // Set timer: nếu vẫn suspected sau timeout → mark dead
      setTimeout(() => {
        const m = this.members.get(nodeId);
        if (m && m.state === 'suspected') {
          m.state = 'dead';
        }
      }, this.config.suspicionTimeout);
    }
  }

  private checkSuspectedMembers(): void {
    // Xóa members đã dead quá lâu
    for (const [id, member] of this.members) {
      if (member.state === 'dead' && id !== this.nodeId) {
        this.members.delete(id);
      }
    }
  }

  private selectRandomPeers(count: number): GossipMember[] {
    const otherMembers = Array.from(this.members.values())
      .filter(m => m.nodeId !== this.nodeId && m.state !== 'dead');

    // Fisher-Yates shuffle rồi lấy count đầu tiên
    for (let i = otherMembers.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [otherMembers[i], otherMembers[j]] = [otherMembers[j], otherMembers[i]];
    }

    return otherMembers.slice(0, count);
  }

  // Public API
  getAliveMembers(): GossipMember[] {
    return Array.from(this.members.values())
      .filter(m => m.state === 'alive');
  }

  setMetadata(key: string, value: string): void {
    const self = this.members.get(this.nodeId)!;
    self.metadata[key] = value;
    // Metadata sẽ tự propagate qua gossip
  }

  // Join cluster bằng cách gossip với seed node
  async join(seedAddress: string): Promise<void> {
    const memberList = Array.from(this.members.values());
    const remoteMemberList = await this.config.transport.sendGossip(
      seedAddress,
      memberList,
    );
    this.mergeMemberList(remoteMemberList);
  }
}

interface GossipTransport {
  sendGossip(address: string, members: GossipMember[]): Promise<GossipMember[]>;
}
```

### Đặc tính Gossip Protocol

```
Ưu điểm:
  ✓ Decentralized — không có single point of failure
  ✓ Scalable — O(log N) rounds để propagate
  ✓ Fault tolerant — node crash → tự detect
  ✓ Bandwidth efficient — chỉ gửi delta

Nhược điểm:
  ✗ Eventually consistent — thông tin mất thời gian lan truyền
  ✗ Không deterministic — không biết chính xác khi nào mọi node biết
  ✗ False positives — có thể suspect node chỉ vì network lag
```

## Distributed Locking

### Redis-based Distributed Lock (Single Instance)

```typescript
import { Redis } from 'ioredis';

class RedisDistributedLock {
  constructor(
    private readonly redis: Redis,
    private readonly config: {
      lockPrefix: string;
      defaultTTL: number;       // Lock TTL in ms
      retryCount: number;        // Số lần retry
      retryDelay: number;        // Delay giữa retries (ms)
    } = {
      lockPrefix: 'lock:',
      defaultTTL: 30_000,
      retryCount: 3,
      retryDelay: 200,
    }
  ) {}

  async acquire(
    resource: string,
    ttl: number = this.config.defaultTTL,
  ): Promise<LockHandle | null> {
    const lockKey = `${this.config.lockPrefix}${resource}`;
    const lockValue = crypto.randomUUID(); // Unique value để safe release

    for (let attempt = 0; attempt < this.config.retryCount; attempt++) {
      // SET key value NX PX ttl — atomic acquire
      const acquired = await this.redis.set(
        lockKey,
        lockValue,
        'PX', ttl,
        'NX',
      );

      if (acquired === 'OK') {
        return {
          resource,
          lockKey,
          lockValue,
          acquiredAt: Date.now(),
          expiresAt: Date.now() + ttl,
          release: () => this.release(lockKey, lockValue),
          extend: (additionalMs: number) =>
            this.extend(lockKey, lockValue, additionalMs),
        };
      }

      // Lock held by someone else — wait and retry
      if (attempt < this.config.retryCount - 1) {
        await this.sleep(
          this.config.retryDelay + Math.random() * this.config.retryDelay,
        );
      }
    }

    return null; // Failed to acquire
  }

  // Safe release: chỉ release nếu value vẫn là của mình
  private async release(lockKey: string, lockValue: string): Promise<boolean> {
    const script = `
      if redis.call('GET', KEYS[1]) == ARGV[1] then
        return redis.call('DEL', KEYS[1])
      end
      return 0
    `;
    const result = await this.redis.eval(script, 1, lockKey, lockValue);
    return result === 1;
  }

  // Extend lock TTL: chỉ extend nếu vẫn giữ lock
  private async extend(
    lockKey: string,
    lockValue: string,
    additionalMs: number,
  ): Promise<boolean> {
    const script = `
      if redis.call('GET', KEYS[1]) == ARGV[1] then
        return redis.call('PEXPIRE', KEYS[1], ARGV[2])
      end
      return 0
    `;
    const result = await this.redis.eval(
      script, 1, lockKey, lockValue, additionalMs.toString(),
    );
    return result === 1;
  }

  private sleep(ms: number): Promise<void> {
    return new Promise(resolve => setTimeout(resolve, ms));
  }
}

interface LockHandle {
  resource: string;
  lockKey: string;
  lockValue: string;
  acquiredAt: number;
  expiresAt: number;
  release: () => Promise<boolean>;
  extend: (additionalMs: number) => Promise<boolean>;
}

// === Usage Pattern: Lock with auto-release ===

async function withLock<T>(
  lockService: RedisDistributedLock,
  resource: string,
  fn: () => Promise<T>,
  ttl?: number,
): Promise<T> {
  const lock = await lockService.acquire(resource, ttl);
  if (!lock) {
    throw new Error(`Failed to acquire lock on ${resource}`);
  }

  try {
    return await fn();
  } finally {
    await lock.release();
  }
}

// Example: Prevent duplicate order processing
async function processOrder(orderId: string): Promise<void> {
  const lock = new RedisDistributedLock(redis);

  await withLock(lock, `order:${orderId}`, async () => {
    const order = await db.findOrder(orderId);
    if (order.status === 'processed') return; // Already done

    await chargePayment(order);
    await reserveInventory(order);
    await db.updateOrder(orderId, { status: 'processed' });
  });
}
```

### Redlock Algorithm (Multi-Instance)

```typescript
// Redlock: distributed lock across N independent Redis instances
// → Tolerates failure of minority Redis instances

class Redlock {
  constructor(
    private readonly redisInstances: Redis[],
    private readonly config: {
      retryCount: number;
      retryDelay: number;
      driftFactor: number; // Clock drift factor (0.01 = 1%)
    } = { retryCount: 3, retryDelay: 200, driftFactor: 0.01 }
  ) {}

  async acquire(resource: string, ttl: number): Promise<RedlockHandle | null> {
    const lockValue = crypto.randomUUID();
    const quorum = Math.floor(this.redisInstances.length / 2) + 1;

    for (let attempt = 0; attempt < this.config.retryCount; attempt++) {
      const startTime = Date.now();

      // Try to acquire lock on ALL instances
      const results = await Promise.allSettled(
        this.redisInstances.map(redis =>
          redis.set(
            `lock:${resource}`, lockValue,
            'PX', ttl,
            'NX',
          )
        )
      );

      const acquiredCount = results.filter(
        r => r.status === 'fulfilled' && r.value === 'OK'
      ).length;

      const elapsed = Date.now() - startTime;
      const drift = Math.floor(ttl * this.config.driftFactor) + 2;
      const validityTime = ttl - elapsed - drift;

      if (acquiredCount >= quorum && validityTime > 0) {
        // Successfully acquired lock on majority
        return {
          resource,
          lockValue,
          validityTime,
          release: () => this.releaseAll(resource, lockValue),
        };
      }

      // Failed — release any partial locks
      await this.releaseAll(resource, lockValue);

      // Random delay before retry
      const delay = Math.random() * this.config.retryDelay;
      await new Promise(r => setTimeout(r, delay));
    }

    return null;
  }

  private async releaseAll(resource: string, lockValue: string): Promise<void> {
    const script = `
      if redis.call('GET', KEYS[1]) == ARGV[1] then
        return redis.call('DEL', KEYS[1])
      end
      return 0
    `;

    await Promise.allSettled(
      this.redisInstances.map(redis =>
        redis.eval(script, 1, `lock:${resource}`, lockValue)
      )
    );
  }
}

interface RedlockHandle {
  resource: string;
  lockValue: string;
  validityTime: number; // Remaining time lock is valid
  release: () => Promise<void>;
}
```

## Bloom Filters

> Bloom Filter: probabilistic data structure trả lời "có thể có" hoặc "chắc chắn không".
> False positives: YES. False negatives: NEVER.

### Use Cases

```
1. Spam filter:     "Email này đã bị report chưa?"
2. Cache:           "Key này CÓ THỂ trong cache không?" (tránh cache miss vô ích)
3. Database:        "Row này CÓ THỂ tồn tại không?" (tránh disk read vô ích)
4. Web crawler:     "URL này đã crawl chưa?"
5. Network:         "Packet này đã thấy chưa?" (duplicate detection)
```

### TypeScript Implementation

```typescript
import { createHash } from 'crypto';

class BloomFilter {
  private bitArray: Uint8Array;
  private readonly size: number;          // Số bits
  private readonly hashCount: number;      // Số hash functions
  private itemCount = 0;

  /**
   * @param expectedItems  Số items dự kiến
   * @param falsePositiveRate  Tỷ lệ false positive chấp nhận (0.01 = 1%)
   */
  constructor(expectedItems: number, falsePositiveRate: number = 0.01) {
    // Optimal size: m = -(n * ln(p)) / (ln(2)^2)
    this.size = Math.ceil(
      -(expectedItems * Math.log(falsePositiveRate)) / (Math.LN2 ** 2)
    );
    // Optimal hash count: k = (m/n) * ln(2)
    this.hashCount = Math.ceil((this.size / expectedItems) * Math.LN2);

    this.bitArray = new Uint8Array(Math.ceil(this.size / 8));
  }

  add(item: string): void {
    const positions = this.getHashPositions(item);
    for (const pos of positions) {
      const byteIndex = Math.floor(pos / 8);
      const bitIndex = pos % 8;
      this.bitArray[byteIndex] |= (1 << bitIndex);
    }
    this.itemCount++;
  }

  /**
   * Check if item MIGHT be in the set
   * - Returns true → item MIGHT be in set (could be false positive)
   * - Returns false → item is DEFINITELY NOT in set
   */
  mightContain(item: string): boolean {
    const positions = this.getHashPositions(item);
    for (const pos of positions) {
      const byteIndex = Math.floor(pos / 8);
      const bitIndex = pos % 8;
      if ((this.bitArray[byteIndex] & (1 << bitIndex)) === 0) {
        return false; // DEFINITELY not in set
      }
    }
    return true; // MIGHT be in set
  }

  /** Estimated false positive rate at current load */
  estimatedFalsePositiveRate(): number {
    const bitsSet = this.countBitsSet();
    const ratio = bitsSet / this.size;
    return Math.pow(ratio, this.hashCount);
  }

  /** Memory usage in bytes */
  memorySizeBytes(): number {
    return this.bitArray.byteLength;
  }

  getStats(): {
    size: number;
    hashCount: number;
    itemCount: number;
    memoryBytes: number;
    estimatedFPR: number;
  } {
    return {
      size: this.size,
      hashCount: this.hashCount,
      itemCount: this.itemCount,
      memoryBytes: this.memorySizeBytes(),
      estimatedFPR: this.estimatedFalsePositiveRate(),
    };
  }

  // Double hashing: h(i) = h1 + i * h2
  // Dùng 2 hash functions để sinh K positions
  private getHashPositions(item: string): number[] {
    const hash1 = this.murmur3Hash(item, 0);
    const hash2 = this.murmur3Hash(item, hash1);

    const positions: number[] = [];
    for (let i = 0; i < this.hashCount; i++) {
      const combinedHash = Math.abs((hash1 + i * hash2) % this.size);
      positions.push(combinedHash);
    }
    return positions;
  }

  private murmur3Hash(key: string, seed: number): number {
    // Simplified hash using crypto — in production, dùng murmurhash3
    const hash = createHash('md5')
      .update(`${seed}:${key}`)
      .digest();
    return hash.readUInt32BE(0);
  }

  private countBitsSet(): number {
    let count = 0;
    for (const byte of this.bitArray) {
      let b = byte;
      while (b) {
        count += b & 1;
        b >>= 1;
      }
    }
    return count;
  }
}

// === Usage: Database read optimization ===

class BloomFilterOptimizedDB {
  private bloom: BloomFilter;

  constructor(
    private readonly db: Database,
    expectedRows: number = 1_000_000,
  ) {
    this.bloom = new BloomFilter(expectedRows, 0.01); // 1% FPR
  }

  // Khởi tạo bloom filter từ existing data
  async initialize(): Promise<void> {
    const keys = await this.db.getAllKeys();
    for (const key of keys) {
      this.bloom.add(key);
    }
    console.log(`Bloom filter initialized: ${this.bloom.getStats().memoryBytes} bytes`);
    // 1M items, 1% FPR ≈ 1.2 MB memory — rất nhỏ!
  }

  async get(key: string): Promise<unknown | null> {
    // Bloom filter check TRƯỚC khi hit database
    if (!this.bloom.mightContain(key)) {
      return null; // CHẮC CHẮN không có → tránh DB query
    }

    // Có thể có → query DB (có thể false positive)
    return this.db.query(`SELECT * FROM data WHERE key = $1`, [key]);
  }

  async insert(key: string, value: unknown): Promise<void> {
    await this.db.insert('data', { key, value });
    this.bloom.add(key); // Cập nhật bloom filter
  }
}
```

## Sidecar Pattern & Ambassador Pattern

### Sidecar Pattern

```
Sidecar process chạy song song với application process, cung cấp
cross-cutting concerns: logging, monitoring, TLS, service discovery.

┌─────────────────────────────────┐
│           Pod / VM              │
│  ┌───────────┐  ┌────────────┐ │
│  │ Application│  │  Sidecar   │ │
│  │  (Node.js) │←→│ (Envoy)   │ │
│  └───────────┘  └────────────┘ │
│        ↕              ↕         │
│    localhost       Mesh Network │
└─────────────────────────────────┘
```

```typescript
// Sidecar pattern: Application không cần biết về infrastructure concerns

// KHÔNG có Sidecar — application phải handle hết
class MonolithicService {
  async handleRequest(req: Request): Promise<Response> {
    // Infrastructure concerns MIX với business logic
    const traceId = req.headers['x-trace-id'] ?? crypto.randomUUID();
    const startTime = Date.now();

    try {
      // mTLS verification
      await this.verifyClientCertificate(req);

      // Rate limiting
      await this.checkRateLimit(req.clientIP);

      // Circuit breaking
      if (this.circuitBreaker.isOpen()) {
        return { status: 503, body: 'Service unavailable' };
      }

      // Business logic — bị chìm trong infrastructure code
      const result = await this.businessLogic(req);

      // Metrics
      this.metrics.recordLatency(Date.now() - startTime);
      this.metrics.recordSuccess();

      return result;
    } catch (error) {
      this.metrics.recordFailure();
      this.logger.error({ traceId, error });
      throw error;
    }
  }
}

// CÓ Sidecar — application chỉ lo business logic
// Sidecar (Envoy) handle: mTLS, rate limiting, circuit breaking,
// tracing, metrics, retries, load balancing
class CleanService {

    // CHỈ business logic — Envoy sidecar xử lý phần còn lại
    const order = await this.orderRepository.findById(req.params.orderId);
    if (!order) {
      return { status: 404, body: { error: 'Order not found' } };
    }
    return { status: 200, body: order };
  }
}
```

### Ambassador Pattern

```
Ambassador: proxy giữa application và external service.
Handle: retries, circuit breaking, logging — đặc biệt cho outbound calls.

  Application → Ambassador → External Service
                (local proxy)

Khác Sidecar: Ambassador focus vào OUTBOUND connections
              Sidecar handle cả inbound VÀ outbound
```

```typescript
// Ambassador pattern: proxy outbound calls với retries, circuit breaking

class AmbassadorProxy {
  private circuitState: 'closed' | 'open' | 'half-open' = 'closed';
  private failureCount = 0;
  private lastFailureTime = 0;

  constructor(
    private readonly target: string,
    private readonly config: {
      maxRetries: number;
      retryBaseDelay: number;
      circuitBreakerThreshold: number;
      circuitBreakerResetTimeout: number;
    }
  ) {}

  async call<T>(
    path: string,
    options: RequestInit = {},
  ): Promise<T> {
    // Circuit breaker check
    if (this.circuitState === 'open') {
      if (Date.now() - this.lastFailureTime > this.config.circuitBreakerResetTimeout) {
        this.circuitState = 'half-open';
      } else {
        throw new CircuitOpenError(this.target);
      }
    }

    // Retry with exponential backoff
    let lastError: Error | null = null;
    for (let attempt = 0; attempt <= this.config.maxRetries; attempt++) {
      try {
        const response = await fetch(`${this.target}${path}`, {
          ...options,
          signal: AbortSignal.timeout(5000),
        });

        if (response.ok) {
          this.onSuccess();
          return await response.json() as T;
        }

        if (response.status >= 500) {
          throw new Error(`Server error: ${response.status}`);
        }

        // 4xx — don't retry
        throw new ClientError(response.status, await response.text());
      } catch (error) {
        lastError = error as Error;
        if (error instanceof ClientError) throw error; // Don't retry 4xx

        if (attempt < this.config.maxRetries) {
          const delay = this.config.retryBaseDelay * Math.pow(2, attempt)
            + Math.random() * 100; // Jitter
          await new Promise(r => setTimeout(r, delay));
        }
      }
    }

    this.onFailure();
    throw lastError;
  }

  private onSuccess(): void {
    this.failureCount = 0;
    this.circuitState = 'closed';
  }

  private onFailure(): void {
    this.failureCount++;
    this.lastFailureTime = Date.now();
    if (this.failureCount >= this.config.circuitBreakerThreshold) {
      this.circuitState = 'open';
    }
  }
}

class CircuitOpenError extends Error {
  constructor(target: string) {
    super(`Circuit breaker open for ${target}`);
    this.name = 'CircuitOpenError';
  }
}

class ClientError extends Error {
  constructor(public readonly statusCode: number, message: string) {
    super(message);
    this.name = 'ClientError';
  }
}
```

## Service Mesh

### Service Mesh giải quyết gì?

```
Vấn đề: Mỗi microservice cần handle:
  - Service discovery
  - Load balancing
  - mTLS (mutual TLS)
  - Retries & timeouts
  - Circuit breaking
  - Rate limiting
  - Distributed tracing
  - Metrics collection
  - Traffic routing (canary, A/B)

Nếu mỗi service tự implement → duplicated logic, inconsistent behavior

Service Mesh: Infrastructure layer handle TẤT CẢ điều trên
              Application code không cần thay đổi gì
```

### Data Plane vs Control Plane

```
Control Plane (Istiod / Linkerd):
  ├── Cấu hình routing rules
  ├── Quản lý certificates
  ├── Thu thập telemetry
  └── Push config xuống data plane

Data Plane (Envoy sidecars):
  ├── Intercept mọi network traffic (inbound + outbound)
  ├── Apply routing rules, retries, circuit breaking
  ├── Terminate/originate mTLS
  └── Report metrics, traces
```

## Backpressure & Flow Control

### Vấn đề: Producer nhanh hơn Consumer

```
Producer → Queue → Consumer

Nếu producer rate > consumer rate:
  → Queue tăng vô hạn → OOM → crash
  → Hoặc drop messages → data loss
```

### Strategies

```typescript
// Strategy 1: Bounded Buffer — Reject khi đầy
class BoundedBuffer<T> {
  private buffer: T[] = [];

  constructor(private readonly maxSize: number) {}

  push(item: T): boolean {
    if (this.buffer.length >= this.maxSize) {
      return false; // REJECT — caller phải retry hoặc drop
    }
    this.buffer.push(item);
    return true;
  }

  pop(): T | undefined {
    return this.buffer.shift();
  }

  get pressure(): number {
    return this.buffer.length / this.maxSize; // 0.0 → 1.0
  }
}

// Strategy 2: Rate Limiting — Slow down producer
class TokenBucketRateLimiter {
  private tokens: number;
  private lastRefill: number;

  constructor(
    private readonly maxTokens: number,
    private readonly refillRate: number, // tokens per second
  ) {
    this.tokens = maxTokens;
    this.lastRefill = Date.now();
  }

  tryAcquire(tokens: number = 1): boolean {
    this.refill();

    if (this.tokens >= tokens) {
      this.tokens -= tokens;
      return true;
    }

    return false; // Rate limited
  }

  private refill(): void {
    const now = Date.now();
    const elapsed = (now - this.lastRefill) / 1000;
    this.tokens = Math.min(
      this.maxTokens,
      this.tokens + elapsed * this.refillRate,
    );
    this.lastRefill = now;
  }
}

// Strategy 3: Adaptive Backpressure — Dynamic rate adjustment
class AdaptiveBackpressure {
  private windowSize = 10;
  private latencies: number[] = [];
  private currentRate: number;

  constructor(
    private readonly minRate: number,
    private readonly maxRate: number,
    private readonly targetLatencyMs: number,
  ) {
    this.currentRate = maxRate;
  }

  recordLatency(latencyMs: number): void {
    this.latencies.push(latencyMs);
    if (this.latencies.length > this.windowSize) {
      this.latencies.shift();
    }
    this.adjustRate();
  }

  private adjustRate(): void {
    if (this.latencies.length < this.windowSize) return;

    const avgLatency = this.latencies.reduce((a, b) => a + b, 0)
      / this.latencies.length;

    if (avgLatency > this.targetLatencyMs * 1.5) {
      // Latency quá cao → giảm rate 20%
      this.currentRate = Math.max(
        this.minRate,
        this.currentRate * 0.8,
      );
    } else if (avgLatency < this.targetLatencyMs * 0.5) {
      // Latency thấp → tăng rate 10%
      this.currentRate = Math.min(
        this.maxRate,
        this.currentRate * 1.1,
      );
    }
  }

  getCurrentRate(): number {
    return Math.floor(this.currentRate);
  }
}
```

## Crash Failures vs Byzantine Failures

### So sánh hai loại failure

```
Crash Failure:
  - Node ngừng hoạt động hoàn toàn
  - Không gửi message sai
  - Fail-stop: crash → im lặng
  - Dễ detect hơn (timeout)
  - Phần lớn production systems chỉ handle loại này

Byzantine Failure:
  - Node hoạt động SAI
  - Gửi message sai hoặc contradictory
  - Có thể do bug, corruption, hoặc malicious
  - Khó detect (node vẫn "alive" nhưng nói dối)
  - Cần 3f+1 nodes để tolerate f failures (đắt!)
```

### Trong thực tế

```typescript
// Crash failures — phần lớn production systems
// Handle bằng: heartbeat, timeout, quorum

class CrashFaultTolerantService {
  constructor(
    private readonly replicas: ServiceReplica[],
    private readonly quorumSize: number,
  ) {}

  async read(key: string): Promise<unknown> {
    const results = await Promise.allSettled(
      this.replicas.map(r => r.read(key))
    );

    // Quorum read: chỉ cần majority respond
    const successResults = results
      .filter((r): r is PromiseFulfilledResult<unknown> => r.status === 'fulfilled')
      .map(r => r.value);

    if (successResults.length >= this.quorumSize) {
      // Lấy giá trị mới nhất (by version/timestamp)
      return this.getLatestValue(successResults);
    }

    throw new QuorumNotReachedError('Not enough replicas responded');
  }

  private getLatestValue(results: unknown[]): unknown {
    // Sort by version và return latest
    return results[0]; // simplified
  }
}

// Byzantine failures — chỉ khi untrusted environment
// Handle bằng: majority vote, cryptographic proofs

class ByzantineFaultTolerantService {
  constructor(
    private readonly replicas: ServiceReplica[],
    // Cần 3f+1 replicas để tolerate f Byzantine nodes
    private readonly maxByzantineNodes: number,
  ) {}

  async read(key: string): Promise<unknown> {
    const results = await Promise.allSettled(
      this.replicas.map(r => r.signedRead(key)) // Signed responses
    );

    const validResults = results
      .filter((r): r is PromiseFulfilledResult<SignedResponse> =>
        r.status === 'fulfilled'
      )
      .map(r => r.value)
      .filter(r => this.verifySignature(r)); // Verify signatures

    // Cần 2f+1 nodes đồng ý cùng giá trị
    const requiredAgreement = 2 * this.maxByzantineNodes + 1;
    const consensusValue = this.findConsensus(validResults, requiredAgreement);

    if (consensusValue === null) {
      throw new ByzantineConsensusError('Could not reach Byzantine consensus');
    }

    return consensusValue;
  }

  private findConsensus(
    results: SignedResponse[],
    required: number,
  ): unknown | null {
    const counts = new Map<string, { value: unknown; count: number }>();
    for (const r of results) {
      const key = JSON.stringify(r.value);
      const entry = counts.get(key);
      if (entry) {
        entry.count++;
      } else {
        counts.set(key, { value: r.value, count: 1 });
      }
    }

    for (const entry of counts.values()) {
      if (entry.count >= required) return entry.value;
    }
    return null;
  }

  private verifySignature(response: SignedResponse): boolean {
    // Verify cryptographic signature
    return true; // simplified
  }
}

interface SignedResponse {
  value: unknown;
  signature: string;
  nodeId: string;
}
```

## Tổng kết

| Pattern | Vấn đề giải quyết | Key Trade-off |
|---------|-------------------|---------------|
| Consistent Hashing | Distribute data evenly, minimize redistribution | Virtual node count vs memory |
| Gossip Protocol | Decentralized membership & failure detection | Propagation speed vs bandwidth |
| Distributed Lock | Mutual exclusion across processes | Safety vs liveness (TTL) |
| Bloom Filter | Fast set membership test | Memory vs false positive rate |
| Sidecar | Cross-cutting concerns | Operational complexity |
| Service Mesh | Unified networking layer | Latency overhead, complexity |
| Backpressure | Prevent overload | Throughput vs reliability |
| Crash vs Byzantine | Different failure models | Cost of tolerance |

> **Nguyên tắc vàng:** Chọn pattern đơn giản nhất giải quyết được vấn đề.
> Consistent hashing trước khi custom sharding.
> Redis lock trước khi Redlock.
> Bloom filter trước khi distributed cache.
> Crash fault tolerance trước khi Byzantine.
