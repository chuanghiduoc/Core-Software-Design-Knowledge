## Entity

Entity là object có **identity** duy nhất xuyên suốt lifecycle. Hai entities bằng nhau khi cùng ID,
dù attributes khác nhau hoàn toàn.

### ❌ Bad: Entity không có identity rõ ràng

```typescript
class User {
  name: string;
  email: string;

  equals(other: User): boolean {
    // ❌ So sánh mọi field — user đổi email thì thành "user khác"?
    return this.name === other.name && this.email === other.email;
  }
}
const user = new User();
user.name = '';           // ❌ Cho phép invalid state
user.email = 'not-email'; // ❌ Không validate
```

### ✅ Good: Entity với identity, lifecycle, encapsulation

```typescript
// Base Entity
abstract class Entity<TId> {
  private _domainEvents: DomainEvent[] = [];
  constructor(protected readonly _id: TId) {}

  get id(): TId { return this._id; }
  get domainEvents(): ReadonlyArray<DomainEvent> { return [...this._domainEvents]; }

  protected addDomainEvent(event: DomainEvent): void { this._domainEvents.push(event); }
  clearDomainEvents(): DomainEvent[] {
    const events = [...this._domainEvents];
    this._domainEvents = [];
    return events;
  }

  // Equality by ID only
  equals(other: Entity<TId>): boolean {
    if (!other) return false;
    if (this === other) return true;
    return this._id === other._id;
  }
}

// Typed ID — tránh nhầm OrderId với UserId
class UserId {
  private constructor(readonly value: string) {}
  static generate(): UserId { return new UserId(crypto.randomUUID()); }
  static from(value: string): UserId {
    if (!value?.trim()) throw new InvalidUserIdError('UserId cannot be empty');
    return new UserId(value);
  }
  equals(other: UserId): boolean { return this.value === other.value; }
}

// User entity — encapsulated, validated, behavior-rich
class User extends Entity<UserId> {
  private constructor(
    id: UserId, private _email: Email, private _name: UserName,
    private _status: UserStatus, private readonly _createdAt: Date,
  ) { super(id); }

  static create(email: Email, name: UserName): User {
    const user = new User(UserId.generate(), email, name, UserStatus.Active, new Date());
    user.addDomainEvent(new UserCreated(user.id, email));
    return user;
  }

  // Reconstitution from persistence — no events emitted
  static reconstitute(props: UserProps): User {
    return new User(
      UserId.from(props.id), Email.create(props.email),
      UserName.create(props.name), props.status, props.createdAt,
    );
  }

  changeEmail(newEmail: Email): void {
    if (this._email.equals(newEmail)) return;
    const old = this._email;
    this._email = newEmail;
    this.addDomainEvent(new UserEmailChanged(this.id, old, newEmail));
  }

  deactivate(reason: DeactivationReason): void {
    if (this._status === UserStatus.Deactivated)
      throw new UserAlreadyDeactivatedError(this.id);
    this._status = UserStatus.Deactivated;
    this.addDomainEvent(new UserDeactivated(this.id, reason));
  }

  get email(): Email { return this._email; }
  get isActive(): boolean { return this._status === UserStatus.Active; }
}
```

### Khi nào dùng Entity vs Value Object

| Entity | Value Object |
|--------|-------------|
| Cần tracking qua thời gian (User, Order) | Chỉ mô tả đặc tính (Color, Money) |
| Có lifecycle (created -> active -> archived) | Không có lifecycle |
| Cần distinguish hai instances dù cùng data | Cùng data = bằng nhau |

## Value Object

Value Object **không có identity**. Equality by **all attributes**. Phải **immutable** và **self-validating**.

### ❌ Bad: Dùng primitive types cho domain concepts

```typescript
function createPayment(
  amount: number, tax: number, discount: number, // 3 numbers — dễ nhầm thứ tự!
  currency: string, email: string,
): void { /* ... */ }

createPayment(100, 8.5, 10, 'usd', 'test@mail.com');
createPayment(8.5, 100, 10, 'usd', 'test@mail.com'); // ❌ Nhầm! Compiler không báo
```

### ✅ Good: Value Objects — type-safe, self-validating, immutable

```typescript
// === Money ===
class Money {
  private constructor(readonly amount: number, readonly currency: Currency) {}

  static create(amount: number, currency: Currency): Money {
    if (!Number.isFinite(amount)) throw new InvalidMoneyError(`Invalid amount: ${amount}`);
    return new Money(Math.round(amount * 100) / 100, currency);
  }
  static zero(currency: Currency): Money { return new Money(0, currency); }

  add(other: Money): Money {
    this.assertSameCurrency(other);
    return Money.create(this.amount + other.amount, this.currency);
  }
  subtract(other: Money): Money {
    this.assertSameCurrency(other);
    return Money.create(this.amount - other.amount, this.currency);
  }
  multiply(factor: number): Money { return Money.create(this.amount * factor, this.currency); }
  isGreaterThan(other: Money): boolean {
    this.assertSameCurrency(other);
    return this.amount > other.amount;
  }
  isNegative(): boolean { return this.amount < 0; }
  equals(other: Money): boolean {
    return this.amount === other.amount && this.currency === other.currency;
  }

  private assertSameCurrency(other: Money): void {
    if (this.currency !== other.currency)
      throw new CurrencyMismatchError(`Cannot operate on ${this.currency} and ${other.currency}`);
  }
}

// === Email ===
class Email {
  private static readonly REGEX = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  private constructor(readonly value: string) {}

  static create(value: string): Email {
    const normalized = value.trim().toLowerCase();
    if (!Email.REGEX.test(normalized)) throw new InvalidEmailError(`Invalid email: ${value}`);
    return new Email(normalized);
  }
  get domain(): string { return this.value.split('@')[1]; }
  equals(other: Email): boolean { return this.value === other.value; }
}

// === Address ===
class Address {
  private constructor(
    readonly street: string, readonly city: string, readonly state: string,
    readonly postalCode: PostalCode, readonly country: CountryCode,
  ) {}

  static create(props: { street: string; city: string; state: string;
    postalCode: string; country: string }): Address {
    if (!props.street.trim()) throw new InvalidAddressError('Street is required');
    if (!props.city.trim()) throw new InvalidAddressError('City is required');
    return new Address(
      props.street.trim(), props.city.trim(), props.state.trim(),
      PostalCode.create(props.postalCode, props.country),
      CountryCode.create(props.country),
    );
  }

  // Immutable — return new instance
  withStreet(street: string): Address {
    return new Address(street, this.city, this.state, this.postalCode, this.country);
  }

  equals(other: Address): boolean {
    return this.street === other.street && this.city === other.city
      && this.state === other.state && this.postalCode.equals(other.postalCode)
      && this.country.equals(other.country);
  }
}

// === DateRange ===
class DateRange {
  private constructor(readonly start: Date, readonly end: Date) {}
  static create(start: Date, end: Date): DateRange {
    if (end <= start) throw new InvalidDateRangeError('End must be after start');
    return new DateRange(start, end);
  }
  contains(date: Date): boolean { return date >= this.start && date <= this.end; }
  overlaps(other: DateRange): boolean { return this.start < other.end && other.start < this.end; }
  get durationInDays(): number {
    return Math.ceil((this.end.getTime() - this.start.getTime()) / 86_400_000);
  }
}
```

## Aggregate

Aggregate = **cluster of entities + value objects**, treated as one unit for data changes.
Mỗi aggregate có **Aggregate Root** — entry point duy nhất.

### 5 Rules

```
1. Reference aggregates khác bằng ID, không embed
2. Một transaction = một aggregate
3. Aggregate root là entry point duy nhất
4. Aggregate enforce invariants cho toàn bộ cluster
5. Giữ aggregate nhỏ — eventual consistency giữa aggregates
```

### ❌ Bad: Aggregate quá lớn, cross-boundary

```typescript
class Order {
  customer: Customer;      // ❌ Embed cả Customer (aggregate khác)
  payment: Payment;        // ❌ Embed Payment (aggregate khác)
  items: OrderItem[];

  addItem(product: Product, quantity: number): void {
    if (product.inventory.available < quantity) { /* ... */ } // ❌ Cross-aggregate check
    product.inventory.available -= quantity;  // ❌ Modifying ANOTHER aggregate
    this.items.push(new OrderItem(product, quantity, product.price));
  }
}
```

### ✅ Good: Small aggregate, reference by ID

```typescript
class OrderItem {
  constructor(
    readonly itemId: OrderItemId,
    readonly productId: ProductId,    // Reference by ID
    private _productName: string,     // Snapshot at order time
    private _unitPrice: Money,        // Snapshot at order time
    private _quantity: Quantity,
  ) {}

  get lineTotal(): Money { return this._unitPrice.multiply(this._quantity.value); }
  changeQuantity(newQty: Quantity): void { this._quantity = newQty; }
  get productName(): string { return this._productName; }
  get unitPrice(): Money { return this._unitPrice; }
  get quantity(): Quantity { return this._quantity; }
}

class Order extends Entity<OrderId> {
  private _items: OrderItem[] = [];
  private _status: OrderStatus;
  private _customerId: CustomerId;     // Reference by ID
  private _shippingAddress: Address;   // Value Object — embedded

  static create(customerId: CustomerId, shippingAddress: Address): Order { /* ... */ }

  addItem(productId: ProductId, name: string, price: Money, qty: Quantity): void {
    this.assertDraftStatus('add items');
    if (this._items.length >= 20) throw new MaxOrderItemsExceededError(20);
    if (this._items.some(i => i.productId.equals(productId)))
      throw new DuplicateOrderItemError(productId);

    this._items.push(new OrderItem(OrderItemId.generate(), productId, name, price, qty));
  }

  place(): void {
    this.assertDraftStatus('place');
    if (this._items.length === 0) throw new EmptyOrderError();
    this._status = OrderStatus.Placed;
    this.addDomainEvent(new OrderPlaced(this.id, this._customerId, this.itemSnapshots, this.totalAmount));
  }

  confirm(paymentId: PaymentId): void {
    this.assertStatus(OrderStatus.Placed, 'confirm');
    this._status = OrderStatus.Confirmed;
    this.addDomainEvent(new OrderConfirmed(this.id, paymentId));
  }

  cancel(reason: CancellationReason): void {
    const cancellable = [OrderStatus.Draft, OrderStatus.Placed, OrderStatus.Confirmed];
    if (!cancellable.includes(this._status))
      throw new InvalidOrderStateError(this._status, 'cancel');
    this._status = OrderStatus.Cancelled;
    this.addDomainEvent(new OrderCancelled(this.id, reason));
  }

  get totalAmount(): Money {
    if (this._items.length === 0) return Money.zero(Currency.USD);
    return this._items.reduce((sum, i) => sum.add(i.lineTotal), Money.zero(this._items[0].unitPrice.currency));
  }
  get items(): ReadonlyArray<OrderItem> { return [...this._items]; }
  get status(): OrderStatus { return this._status; }

  private assertDraftStatus(action: string): void { this.assertStatus(OrderStatus.Draft, action); }
  private assertStatus(expected: OrderStatus, action: string): void {
    if (this._status !== expected) throw new InvalidOrderStateError(this._status, action);
  }
}
```

## Domain Events

Domain Events = **điều gì đó đã xảy ra** trong domain. Tên luôn ở **past tense**.

### ❌ Bad vs ✅ Good

```typescript
// ❌ Tên mơ hồ, thiếu data
class OrderUpdated {
  constructor(readonly orderId: string) {} // Consumer phải query lại — cái gì updated?
}
class OrderCreatedBad {
  constructor(readonly order: Order) {} // ❌ Chứa cả aggregate = coupling
}

// ✅ Tên cụ thể, self-contained
abstract class BaseDomainEvent implements DomainEvent {
  readonly eventId = crypto.randomUUID();
  readonly occurredAt = new Date();
  abstract readonly eventType: string;
}

class OrderPlaced extends BaseDomainEvent {
  readonly eventType = 'order.placed';
  constructor(
    readonly orderId: OrderId, readonly customerId: CustomerId,
    readonly items: ReadonlyArray<{ productId: ProductId; quantity: number; unitPrice: Money }>,
    readonly totalAmount: Money,
  ) { super(); }
}

class OrderCancelled extends BaseDomainEvent {
  readonly eventType = 'order.cancelled';
  constructor(
    readonly orderId: OrderId, readonly reason: CancellationReason,
    readonly wasConfirmed: boolean,  // ← downstream biết cần refund không
  ) { super(); }
}
```

### Dispatching

```typescript
interface DomainEventDispatcher {
  dispatch(event: DomainEvent): Promise<void>;
  dispatchAll(events: DomainEvent[]): Promise<void>;
}

// Dùng trong application service — dispatch SAU KHI save aggregate
class PlaceOrderHandler {
  constructor(
    private readonly orderRepo: OrderRepository,
    private readonly eventDispatcher: DomainEventDispatcher,
  ) {}

  async handle(command: PlaceOrderCommand): Promise<OrderId> {
    const order = Order.create(command.customerId, command.shippingAddress);
    command.items.forEach(i => order.addItem(i.productId, i.name, i.price, i.quantity));
    order.place();

    await this.orderRepo.save(order);
    await this.eventDispatcher.dispatchAll(order.clearDomainEvents()); // After persistence
    return order.id;
  }
}
```

## Domain Services

Stateless business logic mà **không thuộc về bất kỳ entity nào**.

### ❌ Bad: Logic thuộc entity nhưng bị đặt ở service

```typescript
class OrderService {
  calculateTotal(order: Order): Money { /* ... */ }  // ❌ Thuộc về Order aggregate
  canCancel(order: Order): boolean { /* ... */ }      // ❌ Thuộc về Order aggregate
}
```

### ✅ Good: Logic cần nhiều aggregates hoặc external info

```typescript
// Pricing: cần Product + Customer + Promotion rules
class OrderPricingService {
  calculateOrderTotal(
    items: ReadonlyArray<{ unitPrice: Money; quantity: Quantity }>,
    customerTier: CustomerTier,
    coupon?: Coupon,
  ): PricingResult {
    const subtotal = items.reduce(
      (sum, i) => sum.add(i.unitPrice.multiply(i.quantity.value)), Money.zero(Currency.USD));
    const tierDiscount = subtotal.multiply(customerTier === CustomerTier.Gold ? 0.1 : 0);
    const couponDiscount = coupon ? coupon.calculateDiscount(subtotal) : Money.zero(Currency.USD);
    return new PricingResult(subtotal, tierDiscount.add(couponDiscount),
      subtotal.subtract(tierDiscount).subtract(couponDiscount));
  }
}

// Transfer: logic GIỮA hai Account aggregates
class MoneyTransferService {
  transfer(from: AccountId, to: AccountId, amount: Money): TransferResult {
    if (from.equals(to)) throw new SelfTransferError('Cannot transfer to same account');
    if (amount.isNegative()) throw new InvalidTransferAmountError('Amount must be positive');
    return new TransferResult(TransferId.generate(), from, to, amount, TransferStatus.Pending);
  }
}
```

| Domain Service | Entity method |
|----------------|--------------|
| Logic cần nhiều aggregates | Logic chỉ cần data trong 1 aggregate |
| Stateless calculation | Stateful behavior |
| Cross-entity business rule | Single-entity invariant |

## Repositories

Repository = **collection-like interface** để access aggregates. Domain chỉ biết interface.

### ❌ Bad: Lộ persistence details

```typescript
class OrderRepository {
  async findById(id: string): Promise<Record<string, unknown> | null> {
    return this.db('orders').where('id', id).first(); // ❌ Raw SQL result
  }
  query(): Knex.QueryBuilder { return this.db('orders'); } // ❌ Expose query builder
}
```

### ✅ Good: Clean interface + infrastructure implementation

```typescript
// Domain layer — interface only
interface OrderRepository {
  findById(id: OrderId): Promise<Order | null>;
  findByCustomer(customerId: CustomerId): Promise<Order[]>;
  save(order: Order): Promise<void>;
  delete(id: OrderId): Promise<void>;
}

// Infrastructure layer — implementation
class PostgresOrderRepository implements OrderRepository {
  constructor(private readonly db: Knex) {}

  async findById(id: OrderId): Promise<Order | null> {
    const row = await this.db('orders').where('id', id.value).first();
    if (!row) return null;
    const items = await this.db('order_items').where('order_id', id.value);
    return this.toDomain(row, items);
  }

  async save(order: Order): Promise<void> {
    await this.db.transaction(async (trx) => {
      await trx('orders').insert(this.toRow(order)).onConflict('id').merge();
      await trx('order_items').where('order_id', order.id.value).delete();
      if (order.items.length > 0)
        await trx('order_items').insert(order.items.map(i => this.toItemRow(order.id, i)));
    });
  }

  // Mapping: DB rows <-> Domain objects
  private toDomain(row: OrderRow, items: OrderItemRow[]): Order {
    return Order.reconstitute({ /* map row fields to domain props */ });
  }
  private toRow(order: Order): OrderRow { /* map domain to DB row */ }
  private toItemRow(orderId: OrderId, item: OrderItem): OrderItemRow { /* ... */ }
}
```

## Factories

Factory đảm nhận **tạo aggregate phức tạp** — khi creation cần external services hoặc nhiều steps.

### ❌ Bad: Creation logic rải rác trong application service

```typescript
class OrderAppService {
  async createOrder(req: CreateOrderRequest): Promise<void> {
    const order = new Order();
    order.id = uuid();
    order.status = 'DRAFT';  // ❌ App service biết quá nhiều internal details
    for (const item of req.items) {
      const product = await this.productRepo.findById(item.productId);
      order.items.push(new OrderItem(/* ... */)); // ❌ Complex creation scattered
    }
  }
}
```

### ✅ Good: Factory encapsulates complexity

```typescript
class OrderFactory {
  constructor(
    private readonly productCatalog: ProductCatalogService,
  ) {}

  async createOrder(
    customerId: CustomerId, itemRequests: OrderItemRequest[], shippingAddress: Address,
  ): Promise<Order> {
    const products = await Promise.all(
      itemRequests.map(r => this.productCatalog.getProduct(r.productId))
    );
    const order = Order.create(customerId, shippingAddress);
    products.forEach((product, i) => {
      if (!product) throw new ProductNotFoundError(itemRequests[i].productId);
      order.addItem(product.id, product.name, product.currentPrice, Quantity.create(itemRequests[i].quantity));
    });
    return order;
  }
}
```

| Dùng Factory | Dùng static factory method |
|-------------|--------------------------|
| Creation cần external services (API, DB) | Creation chỉ dùng input data |
| Nhiều steps, complex validation | Simple — vài parameters |

## Specification Pattern

Composable, reusable business rules dưới dạng objects.

### Implementation

```typescript
interface Specification<T> {
  isSatisfiedBy(candidate: T): boolean;
  and(other: Specification<T>): Specification<T>;
  or(other: Specification<T>): Specification<T>;
  not(): Specification<T>;
}

abstract class CompositeSpecification<T> implements Specification<T> {
  abstract isSatisfiedBy(candidate: T): boolean;
  and(other: Specification<T>): Specification<T> { return new AndSpec(this, other); }
  or(other: Specification<T>): Specification<T> { return new OrSpec(this, other); }
  not(): Specification<T> { return new NotSpec(this); }
}

class AndSpec<T> extends CompositeSpecification<T> {
  constructor(private left: Specification<T>, private right: Specification<T>) { super(); }
  isSatisfiedBy(c: T): boolean { return this.left.isSatisfiedBy(c) && this.right.isSatisfiedBy(c); }
}
class OrSpec<T> extends CompositeSpecification<T> {
  constructor(private left: Specification<T>, private right: Specification<T>) { super(); }
  isSatisfiedBy(c: T): boolean { return this.left.isSatisfiedBy(c) || this.right.isSatisfiedBy(c); }
}
class NotSpec<T> extends CompositeSpecification<T> {
  constructor(private spec: Specification<T>) { super(); }
  isSatisfiedBy(c: T): boolean { return !this.spec.isSatisfiedBy(c); }
}
```

### ❌ Bad: Rules hardcoded trong if/else

```typescript
canFulfill(order: Order): boolean {
  if (order.status !== 'CONFIRMED') return false;
  if (order.totalAmount.amount > 10000 && !order.isApproved) return false;
  if (order.items.some(i => i.isBackordered)) return false;
  // ❌ Không reusable, khó test từng rule riêng, duplicate ở canShip()
}
```

### ✅ Good: Composable Specifications

```typescript
class OrderIsConfirmed extends CompositeSpecification<Order> {
  isSatisfiedBy(order: Order): boolean { return order.status === OrderStatus.Confirmed; }
}
class OrderBelowThreshold extends CompositeSpecification<Order> {
  constructor(private threshold: Money) { super(); }
  isSatisfiedBy(order: Order): boolean { return !order.totalAmount.isGreaterThan(this.threshold); }
}
class NoBackorderedItems extends CompositeSpecification<Order> {
  isSatisfiedBy(order: Order): boolean { return !order.items.some(i => i.isBackordered); }
}
class ShippingToAllowedCountry extends CompositeSpecification<Order> {
  constructor(private sanctioned: Set<string>) { super(); }
  isSatisfiedBy(order: Order): boolean { return !this.sanctioned.has(order.shippingAddress.country.value); }
}

// Compose
class OrderFulfillmentPolicy {
  private readonly spec: Specification<Order>;
  constructor() {
    this.spec = new OrderIsConfirmed()
      .and(new OrderBelowThreshold(Money.create(10000, Currency.USD)).or(new OrderIsApproved()))
      .and(new NoBackorderedItems())
      .and(new ShippingToAllowedCountry(new Set(['KP', 'IR', 'SY'])));
  }
  canFulfill(order: Order): boolean { return this.spec.isSatisfiedBy(order); }
}
// ✅ Mỗi spec test riêng, reusable, compose dynamically
```

| Dùng Specification | Không cần |
|-------------------|-----------|
| Complex rules, nhiều conditions | 1-2 simple conditions |
| Rules reuse ở nhiều nơi | Rule chỉ dùng 1 lần |
| Rules thay đổi thường xuyên | Static, đơn giản |

## Full Example: Order Aggregate

Tổng hợp tất cả tactical patterns — complete lifecycle.

```typescript
// === Value Objects ===
class OrderId {
  private constructor(readonly value: string) {}
  static generate(): OrderId { return new OrderId(crypto.randomUUID()); }
  static from(v: string): OrderId { if (!v) throw new Error('Empty'); return new OrderId(v); }
}

class Quantity {
  private constructor(readonly value: number) {}
  static create(v: number): Quantity {
    if (!Number.isInteger(v) || v < 1) throw new InvalidQuantityError(`Invalid: ${v}`);
    if (v > 999) throw new InvalidQuantityError(`Max 999: ${v}`);
    return new Quantity(v);
  }
}

// === Domain Events ===
class OrderPlaced extends BaseDomainEvent {
  readonly eventType = 'order.placed';
  constructor(
    readonly orderId: OrderId, readonly customerId: CustomerId,
    readonly items: ReadonlyArray<OrderItemSnapshot>, readonly totalAmount: Money,
    readonly shippingAddress: Address,
  ) { super(); }
}

class OrderCancelled extends BaseDomainEvent {
  readonly eventType = 'order.cancelled';
  constructor(
    readonly orderId: OrderId, readonly reason: CancellationReason,
    readonly wasConfirmed: boolean,
  ) { super(); }
}

// === Aggregate Root ===
class Order extends Entity<OrderId> {
  private _items: OrderItem[] = [];
  private _status: OrderStatus;
  private _customerId: CustomerId;
  private _shippingAddress: Address;
  private _discountAmount: Money;
  private _placedAt: Date | null = null;

  private constructor(id: OrderId, customerId: CustomerId, shippingAddress: Address) {
    super(id);
    this._customerId = customerId;
    this._shippingAddress = shippingAddress;
    this._status = OrderStatus.Draft;
    this._discountAmount = Money.zero(Currency.USD);
  }

  static create(customerId: CustomerId, shippingAddress: Address): Order {
    return new Order(OrderId.generate(), customerId, shippingAddress);
  }

  // --- Commands ---
  addItem(productId: ProductId, name: string, price: Money, qty: Quantity): void {
    this.assertStatus(OrderStatus.Draft, 'add items');
    if (this._items.length >= 50) throw new MaxOrderItemsExceededError(50);
    if (this._items.some(i => i.productId.equals(productId)))
      throw new DuplicateOrderItemError(productId);
    this._items.push(new OrderItem(OrderItemId.generate(), productId, name, price, qty));
  }

  removeItem(productId: ProductId): void {
    this.assertStatus(OrderStatus.Draft, 'remove items');
    const idx = this._items.findIndex(i => i.productId.equals(productId));
    if (idx === -1) throw new OrderItemNotFoundError(productId);
    this._items.splice(idx, 1);
  }

  place(): void {
    this.assertStatus(OrderStatus.Draft, 'place');
    if (this._items.length === 0) throw new EmptyOrderError();
    this._status = OrderStatus.Placed;
    this._placedAt = new Date();
    this.addDomainEvent(new OrderPlaced(
      this.id, this._customerId, this.itemSnapshots, this.totalAmount, this._shippingAddress));
  }

  confirm(paymentId: PaymentId): void {
    this.assertStatus(OrderStatus.Placed, 'confirm');
    this._status = OrderStatus.Confirmed;
    this.addDomainEvent(new OrderConfirmed(this.id, paymentId));
  }

  ship(tracking: TrackingNumber): void {
    this.assertStatus(OrderStatus.Confirmed, 'ship');
    this._status = OrderStatus.Shipped;
    this.addDomainEvent(new OrderShipped(this.id, tracking));
  }

  deliver(): void {
    this.assertStatus(OrderStatus.Shipped, 'deliver');
    this._status = OrderStatus.Delivered;
  }

  cancel(reason: CancellationReason): void {
    const ok = [OrderStatus.Draft, OrderStatus.Placed, OrderStatus.Confirmed];
    if (!ok.includes(this._status)) throw new InvalidOrderStateError(this._status, 'cancel');
    const wasConfirmed = this._status === OrderStatus.Confirmed;
    this._status = OrderStatus.Cancelled;
    this.addDomainEvent(new OrderCancelled(this.id, reason, wasConfirmed));
  }

  // --- Queries ---
  get subtotal(): Money {
    if (!this._items.length) return Money.zero(Currency.USD);
    return this._items.reduce((s, i) => s.add(i.lineTotal), Money.zero(this._items[0].unitPrice.currency));
  }
  get totalAmount(): Money { return this.subtotal.subtract(this._discountAmount); }
  get status(): OrderStatus { return this._status; }
  get items(): ReadonlyArray<OrderItem> { return [...this._items]; }
  get isCancellable(): boolean {
    return [OrderStatus.Draft, OrderStatus.Placed, OrderStatus.Confirmed].includes(this._status);
  }

  private assertStatus(expected: OrderStatus, action: string): void {
    if (this._status !== expected) throw new InvalidOrderStateError(this._status, action);
  }
  private get itemSnapshots() {
    return this._items.map(i => ({
      productId: i.productId, productName: i.productName,
      quantity: i.quantity.value, unitPrice: i.unitPrice,
    }));
  }
}

/*  State Machine:
    Draft --place()--> Placed --confirm()--> Confirmed --ship()--> Shipped --deliver()--> Delivered
      |                  |                      |
      +--cancel()--------+------cancel()---------+--> Cancelled
*/
```

## Tổng kết

```
┌─────────────┬──────────────────────────────────────────────────┐
│ Pattern     │ Mục đích                                         │
├─────────────┼──────────────────────────────────────────────────┤
│ Entity      │ Object có identity, tracked qua lifecycle        │
│ Value Object│ Immutable, equality by value, self-validating    │
│ Aggregate   │ Consistency boundary, 1 txn = 1 aggregate       │
│ Domain Event│ Thông báo điều đã xảy ra (past tense)           │
│ Domain Svc  │ Stateless logic không thuộc entity nào           │
│ Repository  │ Collection-like access to aggregates             │
│ Factory     │ Complex aggregate creation                       │
│ Specification│ Composable, reusable business rules             │
└─────────────┴──────────────────────────────────────────────────┘
```

> **Rule of thumb**: Entity chỉ có getters/setters mà không có behavior?
> Đó là Anemic Domain Model — không phải DDD.
