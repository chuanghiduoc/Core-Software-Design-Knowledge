## What is Consensus and Why It's Hard

### Định nghĩa chính thức

Consensus protocol phải đảm bảo 3 thuộc tính:

```
1. Agreement:    Mọi non-faulty nodes đồng ý cùng một giá trị
2. Validity:     Giá trị được đồng ý phải được đề xuất bởi ít nhất 1 node
3. Termination:  Mọi non-faulty nodes cuối cùng phải quyết định
                 (FLP nói: property này không thể guarantee 100% trong async system)
```

### Tại sao consensus khó?

```
Scenario: 5 nodes cần đồng ý ai là leader

Bước 1: Node A gửi "Tôi muốn là leader" tới tất cả
Bước 2: Node B cũng gửi "Tôi muốn là leader" (đồng thời!)
Bước 3: Network partition chia 5 nodes thành [A, B, C] và [D, E]

→ Node C nhận message từ cả A và B — chọn ai?
→ Node D, E chỉ nhận message từ... không ai? Hay chỉ B?
→ Nếu cả A và B đều nghĩ mình là leader → SPLIT BRAIN

Consensus protocol giải quyết chính xác vấn đề này.
```

### Ứng dụng của consensus

| Use Case | Cần consensus để... |
|----------|-------------------|
| Leader election | Chọn DUY NHẤT 1 leader |
| Atomic broadcast | Mọi nodes nhận messages theo CÙNG thứ tự |
| Distributed lock | Chỉ 1 process giữ lock tại 1 thời điểm |
| State machine replication | Mọi replicas có cùng state |
| Configuration management | Mọi nodes thấy cùng config |

## Raft Algorithm

> "In search of an understandable consensus algorithm"
> — Diego Ongaro & John Ousterhout, 2014

Raft được thiết kế để **dễ hiểu** hơn Paxos. Nó chia consensus thành 3 sub-problems:

### 1. Leader Election

```
3 trạng thái của mỗi node:
  - Follower:  Passive, chỉ phản hồi requests
  - Candidate: Đang tranh cử leader
  - Leader:    Xử lý mọi client requests

Concept "Term": Mỗi term là một "nhiệm kỳ" có tối đa 1 leader
```

```typescript
// Raft Node States
type RaftState = 'follower' | 'candidate' | 'leader';

interface RaftNode {
  id: string;
  state: RaftState;
  currentTerm: number;      // Term hiện tại
  votedFor: string | null;  // Đã vote cho ai trong term này
  log: LogEntry[];           // Replicated log
  commitIndex: number;       // Index cao nhất đã committed
  lastApplied: number;       // Index cao nhất đã applied to state machine
}

interface LogEntry {
  term: number;       // Term khi entry được tạo
  index: number;      // Vị trí trong log
  command: unknown;   // State machine command
}

// Leader Election Flow
class RaftElection {
  private electionTimeout: ReturnType<typeof setTimeout> | null = null;
  private heartbeatInterval: ReturnType<typeof setInterval> | null = null;

  constructor(
    private node: RaftNode,
    private peers: RaftPeer[],
    private readonly config: {
      electionTimeoutMin: number;  // 150ms
      electionTimeoutMax: number;  // 300ms
      heartbeatInterval: number;   // 50ms
    }
  ) {}

  // Khi follower không nhận heartbeat trong election timeout
  startElection(): void {
    // 1. Chuyển sang candidate
    this.node.state = 'candidate';

    // 2. Tăng term
    this.node.currentTerm++;

    // 3. Vote cho chính mình
    this.node.votedFor = this.node.id;
    let votesReceived = 1; // vote cho mình

    const majority = Math.floor(this.peers.length / 2) + 1;

    // 4. Request vote từ mọi peers
    for (const peer of this.peers) {
      this.requestVote(peer).then(response => {
        if (response.term > this.node.currentTerm) {
          // Peer có term cao hơn → step down
          this.stepDown(response.term);
          return;
        }

        if (response.voteGranted) {
          votesReceived++;
          if (votesReceived >= majority && this.node.state === 'candidate') {
            this.becomeLeader();
          }
        }
      }).catch(() => {
        // Peer unreachable — ignore, continue election
      });
    }

    // 5. Reset election timeout (random để tránh split vote)
    this.resetElectionTimeout();
  }

  private async requestVote(peer: RaftPeer): Promise<VoteResponse> {
    const lastLog = this.node.log[this.node.log.length - 1];
    return peer.requestVote({
      term: this.node.currentTerm,
      candidateId: this.node.id,
      lastLogIndex: lastLog?.index ?? 0,
      lastLogTerm: lastLog?.term ?? 0,
    });
  }

  // Vote handler: quyết định có grant vote không
  handleVoteRequest(request: VoteRequest): VoteResponse {
    // Rule 1: Reject nếu term thấp hơn
    if (request.term < this.node.currentTerm) {
      return { term: this.node.currentTerm, voteGranted: false };
    }

    // Rule 2: Nếu term cao hơn → step down và xem xét vote
    if (request.term > this.node.currentTerm) {
      this.stepDown(request.term);
    }

    // Rule 3: Chỉ vote nếu chưa vote cho ai khác trong term này
    //         VÀ candidate's log ít nhất "up-to-date" bằng mình
    const canVote =
      (this.node.votedFor === null || this.node.votedFor === request.candidateId)
      && this.isLogUpToDate(request.lastLogIndex, request.lastLogTerm);

    if (canVote) {
      this.node.votedFor = request.candidateId;
      this.resetElectionTimeout(); // Reset timeout khi grant vote
      return { term: this.node.currentTerm, voteGranted: true };
    }

    return { term: this.node.currentTerm, voteGranted: false };
  }

  private isLogUpToDate(lastLogIndex: number, lastLogTerm: number): boolean {
    const myLastLog = this.node.log[this.node.log.length - 1];
    const myLastTerm = myLastLog?.term ?? 0;
    const myLastIndex = myLastLog?.index ?? 0;

    // Candidate's log phải "up-to-date": term cao hơn,
    // hoặc cùng term nhưng index dài hơn hoặc bằng
    if (lastLogTerm !== myLastTerm) return lastLogTerm > myLastTerm;
    return lastLogIndex >= myLastIndex;
  }

  private becomeLeader(): void {
    this.node.state = 'leader';
    // Gửi heartbeat ngay lập tức
    this.sendHeartbeats();
    // Bắt đầu heartbeat interval
    this.heartbeatInterval = setInterval(
      () => this.sendHeartbeats(),
      this.config.heartbeatInterval
    );
  }

  private sendHeartbeats(): void {
    for (const peer of this.peers) {
      peer.appendEntries({
        term: this.node.currentTerm,
        leaderId: this.node.id,
        entries: [], // Heartbeat = empty entries
        prevLogIndex: 0, // simplified
        prevLogTerm: 0,
        leaderCommit: this.node.commitIndex,
      }).catch(() => {
        // Peer unreachable — will retry next heartbeat
      });
    }
  }

  private stepDown(newTerm: number): void {
    this.node.state = 'follower';
    this.node.currentTerm = newTerm;
    this.node.votedFor = null;
    if (this.heartbeatInterval) {
      clearInterval(this.heartbeatInterval);
      this.heartbeatInterval = null;
    }
    this.resetElectionTimeout();
  }

  private resetElectionTimeout(): void {
    if (this.electionTimeout) clearTimeout(this.electionTimeout);
    // Random timeout để giảm split vote
    const timeout = this.config.electionTimeoutMin +
      Math.random() * (this.config.electionTimeoutMax - this.config.electionTimeoutMin);
    this.electionTimeout = setTimeout(() => this.startElection(), timeout);
  }
}

interface VoteRequest {
  term: number;
  candidateId: string;
  lastLogIndex: number;
  lastLogTerm: number;
}

interface VoteResponse {
  term: number;
  voteGranted: boolean;
}

interface AppendEntriesRequest {
  term: number;
  leaderId: string;
  entries: LogEntry[];
  prevLogIndex: number;
  prevLogTerm: number;
  leaderCommit: number;
}
```

### 2. Log Replication

```
Client → Leader → Replicate to followers → Commit when majority ACK

Timeline:
  1. Client gửi command tới Leader
  2. Leader append command vào log (uncommitted)
  3. Leader gửi AppendEntries RPC tới followers
  4. Followers append vào log, gửi ACK
  5. Khi majority ACK → Leader commit → apply to state machine
  6. Leader thông báo commit cho followers
  7. Followers apply committed entries to state machine
```

```typescript
// Log Replication (simplified)
class RaftLogReplication {
  // Leader: nhận command từ client
  async proposeCommand(command: unknown): Promise<boolean> {
    if (this.node.state !== 'leader') {
      throw new NotLeaderError('Not the leader');
    }

    // 1. Append to local log
    const entry: LogEntry = {
      term: this.node.currentTerm,
      index: this.node.log.length,
      command,
    };
    this.node.log.push(entry);

    // 2. Replicate to followers
    let ackCount = 1; // Leader counts as 1
    const majority = Math.floor(this.peers.length / 2) + 1;

    const results = await Promise.allSettled(
      this.peers.map(peer =>
        peer.appendEntries({
          term: this.node.currentTerm,
          leaderId: this.node.id,
          entries: [entry],
          prevLogIndex: entry.index - 1,
          prevLogTerm: this.node.log[entry.index - 1]?.term ?? 0,
          leaderCommit: this.node.commitIndex,
        })
      )
    );

    for (const result of results) {
      if (result.status === 'fulfilled' && result.value.success) {
        ackCount++;
      }
    }

    // 3. Commit if majority
    if (ackCount >= majority) {
      this.node.commitIndex = entry.index;
      this.applyToStateMachine(entry);
      return true;
    }

    return false;
  }

  // Follower: nhận AppendEntries từ leader
  handleAppendEntries(request: AppendEntriesRequest): AppendEntriesResponse {
    // Reject nếu term thấp hơn
    if (request.term < this.node.currentTerm) {
      return { term: this.node.currentTerm, success: false };
    }

    // Term cao hơn → acknowledge new leader
    if (request.term > this.node.currentTerm) {
      this.node.currentTerm = request.term;
      this.node.state = 'follower';
    }

    // Log consistency check
    if (request.prevLogIndex > 0) {
      const prevEntry = this.node.log[request.prevLogIndex];
      if (!prevEntry || prevEntry.term !== request.prevLogTerm) {
        // Log inconsistent → leader sẽ retry với earlier entries
        return { term: this.node.currentTerm, success: false };
      }
    }

    // Append new entries
    for (const entry of request.entries) {
      // Xóa conflicting entries nếu có
      if (this.node.log[entry.index]?.term !== entry.term) {
        this.node.log.length = entry.index; // Truncate
      }
      this.node.log[entry.index] = entry;
    }

    // Update commit index
    if (request.leaderCommit > this.node.commitIndex) {
      const lastNewIndex = request.entries.length > 0
        ? request.entries[request.entries.length - 1].index
        : this.node.commitIndex;
      this.node.commitIndex = Math.min(request.leaderCommit, lastNewIndex);
    }

    return { term: this.node.currentTerm, success: true };
  }

  private applyToStateMachine(entry: LogEntry): void {
    // Apply command to application state
  }
}

interface AppendEntriesResponse {
  term: number;
  success: boolean;
}
```

### 3. Safety Properties

```
Election Safety:   Tối đa 1 leader per term
Leader Append-Only: Leader không bao giờ overwrite/delete log entries
Log Matching:      Nếu 2 logs có entry cùng index và term → tất cả
                   entries trước đó cũng giống nhau
Leader Completeness: Entry đã committed → có mặt trong log
                     của mọi future leaders
State Machine Safety: Mọi nodes apply cùng entries theo cùng thứ tự
```

## Paxos — Simplified

> "The Part-Time Parliament" — Leslie Lamport, 1989 (published 1998)
> Nổi tiếng là khó hiểu. Raft ra đời chính vì Paxos quá phức tạp.

### 3 vai trò trong Paxos

```
Proposer:   Đề xuất giá trị (thường là client hoặc leader)
Acceptor:   Chấp nhận/từ chối proposals (thường là server nodes)
Learner:    Học giá trị đã được chấp nhận (thường cũng là server nodes)

Trong thực tế, 1 node thường đóng cả 3 vai trò.
```

### Basic Paxos — 2 Phase Protocol

```
Phase 1: PREPARE
  Proposer chọn proposal number n
  Proposer → Acceptors: "Prepare(n)" — "Tôi muốn propose với số n"
  Acceptor kiểm tra:
    - Nếu n > mọi proposal number đã thấy → Promise không chấp nhận
      proposal nào có number < n
    - Trả về proposal đã accepted trước đó (nếu có)

Phase 2: ACCEPT
  Nếu Proposer nhận được Promise từ majority:
    Proposer → Acceptors: "Accept(n, value)"
    - value = giá trị từ highest-numbered accepted proposal
      hoặc proposer's own value nếu không ai đã accept
    Acceptor: chấp nhận nếu chưa promise cho proposal number cao hơn

Giá trị được chọn khi majority Acceptors accept cùng proposal.
```

```typescript
// Simplified Paxos implementation

interface Proposal {
  number: number;    // Unique, monotonically increasing
  value: unknown;    // Proposed value
}

interface PrepareResponse {
  promised: boolean;
  acceptedProposal: Proposal | null; // Previously accepted proposal
}

interface AcceptResponse {
  accepted: boolean;
}

class PaxosProposer {
  private proposalCounter = 0;

  constructor(
    private readonly nodeId: number,
    private readonly totalNodes: number,
    private readonly acceptors: PaxosAcceptor[],
  ) {}

  async propose(value: unknown): Promise<{ decided: boolean; value: unknown }> {
    const majority = Math.floor(this.acceptors.length / 2) + 1;

    // Generate unique proposal number
    // Format: counter * totalNodes + nodeId (ensures uniqueness)
    this.proposalCounter++;
    const proposalNumber = this.proposalCounter * this.totalNodes + this.nodeId;

    // Phase 1: Prepare
    const prepareResults = await Promise.allSettled(
      this.acceptors.map(a => a.prepare(proposalNumber))
    );

    const promises: PrepareResponse[] = [];
    for (const r of prepareResults) {
      if (r.status === 'fulfilled' && r.value.promised) {
        promises.push(r.value);
      }
    }

    if (promises.length < majority) {
      return { decided: false, value: null }; // Không đủ promises
    }

    // Chọn value: dùng value từ highest-numbered accepted proposal
    let valueToPropose = value;
    let highestAccepted: Proposal | null = null;
    for (const p of promises) {
      if (p.acceptedProposal) {
        if (!highestAccepted || p.acceptedProposal.number > highestAccepted.number) {
          highestAccepted = p.acceptedProposal;
        }
      }
    }
    if (highestAccepted) {
      valueToPropose = highestAccepted.value; // PHẢI dùng giá trị đã accepted
    }

    // Phase 2: Accept
    const acceptResults = await Promise.allSettled(
      this.acceptors.map(a =>
        a.accept({ number: proposalNumber, value: valueToPropose })
      )
    );

    const acceptCount = acceptResults.filter(
      r => r.status === 'fulfilled' && r.value.accepted
    ).length;

    if (acceptCount >= majority) {
      return { decided: true, value: valueToPropose };
    }

    return { decided: false, value: null }; // Bị preempted, retry
  }
}

class PaxosAcceptor {
  private highestPromised: number = 0;      // Highest prepared number
  private acceptedProposal: Proposal | null = null;

  prepare(proposalNumber: number): PrepareResponse {
    if (proposalNumber > this.highestPromised) {
      this.highestPromised = proposalNumber;
      return {
        promised: true,
        acceptedProposal: this.acceptedProposal,
      };
    }
    return { promised: false, acceptedProposal: null };
  }

  accept(proposal: Proposal): AcceptResponse {
    if (proposal.number >= this.highestPromised) {
      this.highestPromised = proposal.number;
      this.acceptedProposal = proposal;
      return { accepted: true };
    }
    return { accepted: false };
  }
}
```

## Leader Election Patterns

### Pattern 1: Leader Election bằng Database

```typescript
// Sử dụng database row-level locking cho leader election
// Đơn giản nhất, phù hợp khi đã có database

class DatabaseLeaderElection {
  private isLeader = false;
  private heartbeatTimer: ReturnType<typeof setInterval> | null = null;

  constructor(
    private readonly db: DatabasePool,
    private readonly nodeId: string,
    private readonly leaseDuration: number = 30_000,  // 30s lease
    private readonly heartbeatInterval: number = 10_000, // 10s heartbeat
  ) {}

  async start(): Promise<void> {
    // Đảm bảo table exists
    await this.db.query(`
      CREATE TABLE IF NOT EXISTS leader_election (
        resource_name VARCHAR(255) PRIMARY KEY,
        leader_id VARCHAR(255) NOT NULL,
        lease_expires_at TIMESTAMP NOT NULL,
        elected_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
      )
    `);

    // Thử trở thành leader
    await this.tryAcquireLeadership();

    // Định kỳ renew hoặc thử acquire
    this.heartbeatTimer = setInterval(
      () => this.tryAcquireLeadership(),
      this.heartbeatInterval,
    );
  }

  private async tryAcquireLeadership(): Promise<void> {
    const now = new Date();
    const leaseExpires = new Date(now.getTime() + this.leaseDuration);

    try {
      // Atomic operation: INSERT nếu chưa có, hoặc UPDATE nếu lease hết hạn
      const result = await this.db.query(`
        INSERT INTO leader_election (resource_name, leader_id, lease_expires_at)
        VALUES ('main-leader', $1, $2)
        ON CONFLICT (resource_name) DO UPDATE
        SET leader_id = $1,
            lease_expires_at = $2,
            elected_at = CURRENT_TIMESTAMP
        WHERE leader_election.leader_id = $1           -- Renew own lease
           OR leader_election.lease_expires_at < $3     -- Or expired lease
        RETURNING leader_id
      `, [this.nodeId, leaseExpires, now]);

      const wasLeader = this.isLeader;
      this.isLeader = result.rows.length > 0
        && result.rows[0].leader_id === this.nodeId;

      if (this.isLeader && !wasLeader) {
        console.log(`Node ${this.nodeId}: Became leader`);
        this.onBecomeLeader();
      } else if (!this.isLeader && wasLeader) {
        console.log(`Node ${this.nodeId}: Lost leadership`);
        this.onLoseLeadership();
      }
    } catch (error) {
      console.error('Leadership election error:', error);
      if (this.isLeader) {
        this.isLeader = false;
        this.onLoseLeadership();
      }
    }
  }

  getIsLeader(): boolean {
    return this.isLeader;
  }

  async stop(): Promise<void> {
    if (this.heartbeatTimer) {
      clearInterval(this.heartbeatTimer);
    }
    // Voluntarily release leadership
    if (this.isLeader) {
      await this.db.query(
        `DELETE FROM leader_election
         WHERE resource_name = 'main-leader' AND leader_id = $1`,
        [this.nodeId]
      );
    }
  }

  private onBecomeLeader(): void {
    // Override: bắt đầu leader-only tasks
  }

  private onLoseLeadership(): void {
    // Override: dừng leader-only tasks
  }
}
```

### Pattern 2: Leader Election bằng ZooKeeper (Ephemeral Nodes)

```typescript
// ZooKeeper pattern: Ephemeral Sequential Nodes
// Node tạo ephemeral znode → khi node crash, znode tự xóa → trigger re-election

class ZookeeperLeaderElection {
  private myPath: string | null = null;

  constructor(
    private readonly zk: ZookeeperClient,
    private readonly electionPath: string,
    private readonly nodeId: string,
  ) {}

  async participate(): Promise<void> {
    // 1. Tạo ephemeral sequential znode
    // /election/candidate-0000000001
    this.myPath = await this.zk.create(
      `${this.electionPath}/candidate-`,
      this.nodeId,
      { ephemeral: true, sequential: true }
    );

    await this.checkLeadership();
  }

  private async checkLeadership(): Promise<void> {
    // 2. Lấy danh sách tất cả candidates
    const children = await this.zk.getChildren(this.electionPath);
    children.sort(); // Sorted by sequence number

    const myNode = this.myPath!.split('/').pop()!;
    const myIndex = children.indexOf(myNode);

    if (myIndex === 0) {
      // Tôi có sequence number nhỏ nhất → Tôi là leader
      console.log(`${this.nodeId}: I am the leader`);
      this.onBecomeLeader();
    } else {
      // Watch node ngay trước tôi (không watch leader trực tiếp)
      // → Tránh "herd effect" (thundering herd khi leader crash)
      const predecessor = children[myIndex - 1];
      console.log(`${this.nodeId}: Watching ${predecessor}`);

      await this.zk.watch(
        `${this.electionPath}/${predecessor}`,
        async (event) => {
          if (event.type === 'deleted') {
            // Predecessor gone → check lại
            await this.checkLeadership();
          }
        }
      );
    }
  }

  private onBecomeLeader(): void {
    // Start leader duties
  }
}
```

## Split-Brain Problem

### Vấn đề

```
Split-brain: 2 nodes ĐỀU NGHĨ mình là leader

Scenario:
  1. Leader A active, Follower B passive
  2. Network partition giữa A và B
  3. B không thấy A → timeout → B tự promote thành leader
  4. A vẫn hoạt động → 2 leaders!

Hậu quả:
  - Cả A và B đều accept writes → data divergence
  - Clients gửi tới A thấy data khác clients gửi tới B
  - Khi partition heal → conflicting data, có thể mất data
```

### Giải pháp: Quorum

```typescript
// Quorum = majority vote → tối đa 1 partition có majority

// Cluster 5 nodes: quorum = 3
// Partition [A, B, C] và [D, E]
// [A, B, C] có majority → có thể elect leader
// [D, E] KHÔNG có majority → KHÔNG thể elect leader
// → Chỉ có 1 leader!

class QuorumChecker {
  constructor(private readonly clusterSize: number) {}

  get quorumSize(): number {
    return Math.floor(this.clusterSize / 2) + 1;
  }

  hasQuorum(reachableNodes: number): boolean {
    return reachableNodes >= this.quorumSize;
  }

  // Tại sao cluster size nên lẻ?
  // 3 nodes: quorum=2, tolerate 1 failure
  // 4 nodes: quorum=3, tolerate 1 failure  ← cùng tolerance, tốn thêm node!
  // 5 nodes: quorum=3, tolerate 2 failures
  // 6 nodes: quorum=4, tolerate 2 failures ← cùng tolerance, tốn thêm node!
  static recommendedClusterSize(targetFailureTolerance: number): number {
    return 2 * targetFailureTolerance + 1;
  }
}
```

## Fencing Tokens

> Fencing token đảm bảo stale leader không thể ghi data sau khi đã mất leadership.
> — Martin Kleppmann, "Designing Data-Intensive Applications"

### Vấn đề: Process Pause

```
Scenario:
  1. Client A acquire lock → fencing token = 34
  2. Client A bị GC pause 30 giây
  3. Lock hết hạn
  4. Client B acquire lock → fencing token = 35
  5. Client B ghi data với token 35
  6. Client A tỉnh dậy, nghĩ vẫn giữ lock
  7. Client A ghi data với token 34 → OVERWRITE data của B!

Nếu không có fencing token → data corruption
```

### Giải pháp

```typescript
// Fencing token: monotonically increasing number
// Storage layer REJECT writes với token cũ hơn token đã thấy

class FencingTokenLockService {
  private tokenCounter = 0;

  async acquireLock(resource: string, ttl: number): Promise<FencedLock> {
    const token = ++this.tokenCounter; // Monotonically increasing

    const acquired = await this.tryLock(resource, ttl);
    if (!acquired) {
      throw new LockNotAcquiredError(resource);
    }

    return {
      resource,
      fencingToken: token,
      expiresAt: Date.now() + ttl,
    };
  }

  private async tryLock(resource: string, ttl: number): Promise<boolean> {
    // Implementation: Redis SET NX PX, etc.
    return true;
  }
}

interface FencedLock {
  resource: string;
  fencingToken: number;
  expiresAt: number;
}

// Storage layer: validate fencing token
class FencedStorageProxy {
  // Track highest token seen per resource
  private highestTokenSeen = new Map<string, number>();

  constructor(private readonly storage: StorageBackend) {}

  async write(
    resource: string,
    data: unknown,
    fencingToken: number,
  ): Promise<void> {
    const currentHighest = this.highestTokenSeen.get(resource) ?? 0;

    if (fencingToken < currentHighest) {
      // REJECT: stale token từ old leader
      throw new StaleFencingTokenError(
        `Token ${fencingToken} < highest seen ${currentHighest} for ${resource}`
      );
    }

    // Accept: update highest token và write
    this.highestTokenSeen.set(resource, fencingToken);
    await this.storage.write(resource, data);
  }
}

class StaleFencingTokenError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'StaleFencingTokenError';
  }
}

// === Complete flow ===
async function safeLeaderWrite(
  lockService: FencingTokenLockService,
  storage: FencedStorageProxy,
): Promise<void> {
  // 1. Acquire lock với fencing token
  const lock = await lockService.acquireLock('order-processing', 30_000);

  try {
    // 2. Do work...
    const result = await processOrders();

    // 3. Write with fencing token
    // Nếu lock đã expired và ai đó lấy lock mới (token cao hơn)
    // → storage sẽ reject write này → SAFE!
    await storage.write('order-results', result, lock.fencingToken);
  } finally {
    // Release lock
  }
}
```

## TypeScript Implementation: Leader Election với Redis

```typescript
import { Redis } from 'ioredis';
import { EventEmitter } from 'events';

interface LeaderElectionConfig {
  /** Tên resource cần elect leader */
  resourceName: string;
  /** Thời gian giữ lease (ms) */
  leaseDurationMs: number;
  /** Tần suất renew lease (ms) — nên < leaseDuration / 3 */
  renewIntervalMs: number;
  /** Node identifier */
  nodeId: string;
}

type LeadershipEvent = 'became-leader' | 'lost-leadership' | 'error';

class RedisLeaderElection extends EventEmitter {
  private redis: Redis;
  private config: LeaderElectionConfig;
  private isLeader = false;
  private renewTimer: ReturnType<typeof setInterval> | null = null;
  private running = false;
  private fencingToken = 0;

  constructor(redis: Redis, config: LeaderElectionConfig) {
    super();
    this.redis = redis;
    this.config = config;
  }

  async start(): Promise<void> {
    this.running = true;

    // Lua script: atomic acquire or renew
    await this.registerScripts();

    // Initial attempt
    await this.attemptLeadership();

    // Periodic renewal / acquisition
    this.renewTimer = setInterval(
      () => this.attemptLeadership(),
      this.config.renewIntervalMs,
    );
  }

  async stop(): Promise<void> {
    this.running = false;

    if (this.renewTimer) {
      clearInterval(this.renewTimer);
      this.renewTimer = null;
    }

    // Release leadership nếu đang là leader
    if (this.isLeader) {
      await this.releaseLock();
    }
  }

  getIsLeader(): boolean {
    return this.isLeader;
  }

  getFencingToken(): number {
    return this.fencingToken;
  }

  private async attemptLeadership(): Promise<void> {
    if (!this.running) return;

    try {
      // Lua script đảm bảo atomicity
      // SET key nodeId NX PX ttl — chỉ set nếu key chưa tồn tại
      // Hoặc renew nếu value = nodeId hiện tại
      const result = await this.redis.eval(
        `
        local key = KEYS[1]
        local nodeId = ARGV[1]
        local ttl = tonumber(ARGV[2])

        local current = redis.call('GET', key)

        if current == false then
          -- Key không tồn tại → acquire
          redis.call('SET', key, nodeId, 'PX', ttl)
          local token = redis.call('INCR', key .. ':token')
          return {1, token}
        elseif current == nodeId then
          -- Đã là leader → renew lease
          redis.call('PEXPIRE', key, ttl)
          local token = redis.call('GET', key .. ':token')
          return {1, tonumber(token)}
        else
          -- Ai đó khác là leader
          return {0, 0}
        end
        `,
        1, // number of keys
        this.lockKey(),
        this.config.nodeId,
        this.config.leaseDurationMs.toString(),
      ) as [number, number];

      const [acquired, token] = result;
      const wasLeader = this.isLeader;
      this.isLeader = acquired === 1;

      if (this.isLeader) {
        this.fencingToken = token;
      }

      if (this.isLeader && !wasLeader) {
        this.emit('became-leader', { nodeId: this.config.nodeId, fencingToken: token });
      } else if (!this.isLeader && wasLeader) {
        this.emit('lost-leadership', { nodeId: this.config.nodeId });
      }
    } catch (error) {
      // Redis connection error
      if (this.isLeader) {
        this.isLeader = false;
        this.emit('lost-leadership', {
          nodeId: this.config.nodeId,
          reason: 'redis_error',
        });
      }
      this.emit('error', error);
    }
  }

  private async releaseLock(): Promise<void> {
    // Chỉ release nếu value vẫn là nodeId của mình (tránh release lock người khác)
    await this.redis.eval(
      `
      local key = KEYS[1]
      local nodeId = ARGV[1]
      if redis.call('GET', key) == nodeId then
        return redis.call('DEL', key)
      end
      return 0
      `,
      1,
      this.lockKey(),
      this.config.nodeId,
    );
    this.isLeader = false;
  }

  private lockKey(): string {
    return `leader:${this.config.resourceName}`;
  }

  private async registerScripts(): Promise<void> {
    // Ensure fencing token key exists
    await this.redis.setnx(
      `${this.lockKey()}:token`,
      '0'
    );
  }
}
```
