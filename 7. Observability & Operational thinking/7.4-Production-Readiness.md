## Capacity Planning & Load Testing

### Capacity Planning Framework

```
Capacity Planning trả lời: "Hệ thống hiện tại chịu được bao nhiêu traffic?"

Bước 1: Xác định bottleneck dimensions
  → CPU, Memory, Network, Disk I/O, DB connections, External API rate limits

Bước 2: Đo capacity hiện tại
  → Load test để tìm breaking point cho mỗi dimension

Bước 3: Dự đoán traffic tương lai
  → Dựa trên business growth, marketing campaigns, seasonal patterns

Bước 4: Plan for headroom
  → Luôn có ít nhất 50% headroom (dùng 50% capacity = plan scale)
  → Luôn có khả năng survive mất 1 node/AZ
```

## Graceful Startup & Shutdown

### Tại sao cần Graceful Lifecycle?

```
STARTUP — Nếu service nhận traffic trước khi sẵn sàng:
  → Database connection chưa established → errors
  → Cache chưa warm → tất cả requests đều miss cache → storm DB
  → Dependencies chưa healthy → cascading failures

SHUTDOWN — Nếu service bị kill ngay lập tức:
  → In-flight requests bị drop → users thấy errors
  → Database transactions uncommitted → data inconsistency
  → WebSocket connections bị đứt đột ngột
  → Background jobs bị interrupt giữa chừng
```

### Implementation

```typescript
import { createServer, Server, IncomingMessage, ServerResponse } from 'node:http';
import { once } from 'node:events';

// ===== Graceful Lifecycle Manager =====

type ShutdownHook = () => Promise<void>;

class LifecycleManager {
  private shutdownHooks: Array<{ name: string; hook: ShutdownHook; order: number }> = [];
  private isShuttingDown = false;
  private startupComplete = false;

  // === STARTUP ===

  async startup(steps: Array<{ name: string; fn: () => Promise<void> }>): Promise<void> {
    console.log('[lifecycle] Starting application...');

    for (const step of steps) {
      const start = performance.now();
      try {
        await step.fn();
        const duration = Math.round(performance.now() - start);
        console.log(`[lifecycle] ✓ ${step.name} (${duration}ms)`);
      } catch (error) {
        console.error(`[lifecycle] ✗ ${step.name} failed:`, error);
        throw error; // Abort startup
      }
    }

    this.startupComplete = true;
    console.log('[lifecycle] Application started successfully');
  }

  isReady(): boolean {
    return this.startupComplete && !this.isShuttingDown;
  }

  // === SHUTDOWN ===

  onShutdown(name: string, hook: ShutdownHook, order: number = 100): void {
    this.shutdownHooks.push({ name, hook, order });
  }

  async shutdown(signal: string): Promise<void> {
    if (this.isShuttingDown) {
      console.log('[lifecycle] Shutdown already in progress, ignoring duplicate signal');
      return;
    }

    this.isShuttingDown = true;
    console.log(`[lifecycle] Received ${signal}, starting graceful shutdown...`);

    // Sort hooks by order (lower = earlier)
    const sorted = [...this.shutdownHooks].sort((a, b) => a.order - b.order);

    for (const { name, hook } of sorted) {
      const start = performance.now();
      try {
        await Promise.race([
          hook(),
          new Promise((_, reject) =>
            setTimeout(() => reject(new Error('timeout')), 10000)
          ),
        ]);
        const duration = Math.round(performance.now() - start);
        console.log(`[lifecycle] ✓ ${name} shut down (${duration}ms)`);
      } catch (error) {
        console.error(`[lifecycle] ✗ ${name} shutdown failed:`, error);
        // Continue shutting down other hooks
      }
    }

    console.log('[lifecycle] Graceful shutdown complete');
  }

  // === SIGNAL HANDLING ===

  registerSignalHandlers(): void {
    const signals: NodeJS.Signals[] = ['SIGTERM', 'SIGINT'];

    for (const signal of signals) {
      process.on(signal, async () => {
        await this.shutdown(signal);
        process.exit(0);
      });
    }

    // Handle uncaught errors
    process.on('uncaughtException', async (error) => {
      console.error('[lifecycle] Uncaught exception:', error);
      await this.shutdown('uncaughtException');
      process.exit(1);
    });

    process.on('unhandledRejection', async (reason) => {
      console.error('[lifecycle] Unhandled rejection:', reason);
      await this.shutdown('unhandledRejection');
      process.exit(1);
    });
  }
}

// ===== Usage: Graceful HTTP Server =====

async function main(): Promise<void> {
  const lifecycle = new LifecycleManager();
  lifecycle.registerSignalHandlers();

  // Dependencies
  let dbPool: any;
  let redisClient: any;
  let server: Server;

  // --- STARTUP ---
  await lifecycle.startup([
    {
      name: 'Database connection',
      fn: async () => {
        dbPool = await createDbPool({
          host: process.env.DB_HOST,
          maxConnections: 20,
        });
        // Verify connection
        await dbPool.query('SELECT 1');
      },
    },
    {
      name: 'Redis connection',
      fn: async () => {
        redisClient = await createRedisClient({
          url: process.env.REDIS_URL,
        });
        await redisClient.ping();
      },
    },
    {
      name: 'Cache warm-up',
      fn: async () => {
        // Pre-load frequently accessed data
        await warmUpProductCache(dbPool, redisClient);
      },
    },
    {
      name: 'HTTP server',
      fn: async () => {
        const app = createApp(dbPool, redisClient, lifecycle);
        server = createServer(app);
        server.listen(Number(process.env.PORT) ?? 3000);
        await once(server, 'listening');
        console.log(`[lifecycle] HTTP server listening on port ${(server.address() as any).port}`);
      },
    },
  ]);

  // --- SHUTDOWN HOOKS (order matters!) ---

  // 1. Stop accepting new requests (order: 10)
  lifecycle.onShutdown('Stop accepting requests', async () => {
    server.close(); // Stop new connections
  }, 10);

  // 2. Wait for in-flight requests to complete (order: 20)
  lifecycle.onShutdown('Drain in-flight requests', async () => {
    await new Promise<void>((resolve) => {
      // server.close() callback fires when all connections are closed
      server.on('close', resolve);
      // Force close after timeout
      setTimeout(() => {
        console.warn('[lifecycle] Force closing remaining connections');
        resolve();
      }, 15000);
    });
  }, 20);

  // 3. Close Redis (order: 80)
  lifecycle.onShutdown('Redis disconnect', async () => {
    await redisClient.quit();
  }, 80);

  // 4. Close database last (order: 90)
  lifecycle.onShutdown('Database disconnect', async () => {
    await dbPool.end();
  }, 90);
}

main().catch((error) => {
  console.error('[lifecycle] Failed to start:', error);
  process.exit(1);
});
```

## Feature Flags

### Tại sao cần Feature Flags?

```
Deploy ≠ Release

Deploy: đưa code lên production
Release: bật feature cho users

Feature flags tách biệt deploy khỏi release:
  → Deploy code mới nhưng chưa bật feature
  → Bật dần cho 1% → 10% → 50% → 100% users
  → Nếu có vấn đề → tắt feature NGAY mà không cần rollback deployment
  → A/B testing: 50% users thấy feature A, 50% thấy feature B
```

### Implementation

```typescript
// ===== Feature Flag Service =====

interface FeatureFlag {
  name: string;
  enabled: boolean;
  rolloutPercentage: number;  // 0-100
  targetUsers?: string[];     // Specific users
  targetTenants?: string[];   // Specific tenants
  metadata?: Record<string, string>;
}

interface FeatureFlagContext {
  userId?: string;
  tenantId?: string;
  environment?: string;
  userAttributes?: Record<string, string>;
}

class FeatureFlagService {
  private flags: Map<string, FeatureFlag> = new Map();
  private refreshInterval: NodeJS.Timeout | null = null;

  constructor(
    private readonly configSource: FeatureFlagSource,
    private readonly logger: any,
  ) {}

  async initialize(): Promise<void> {
    await this.refresh();
    // Refresh flags mỗi 30 giây
    this.refreshInterval = setInterval(() => this.refresh(), 30000);
  }

  isEnabled(flagName: string, context: FeatureFlagContext = {}): boolean {
    const flag = this.flags.get(flagName);

    // Flag không tồn tại → disabled
    if (!flag) return false;

    // Flag disabled globally
    if (!flag.enabled) return false;

    // Check targeted users
    if (flag.targetUsers?.length && context.userId) {
      if (flag.targetUsers.includes(context.userId)) return true;
    }

    // Check targeted tenants
    if (flag.targetTenants?.length && context.tenantId) {
      if (flag.targetTenants.includes(context.tenantId)) return true;
    }

    // Percentage rollout
    if (flag.rolloutPercentage >= 100) return true;
    if (flag.rolloutPercentage <= 0) return false;

    // Deterministic: cùng user luôn thấy cùng kết quả
    const hash = this.hashString(`${flagName}:${context.userId ?? 'anonymous'}`);
    const bucket = hash % 100;
    return bucket < flag.rolloutPercentage;
  }

  private hashString(str: string): number {
    let hash = 0;
    for (let i = 0; i < str.length; i++) {
      const char = str.charCodeAt(i);
      hash = ((hash << 5) - hash) + char;
      hash = hash & hash; // Convert to 32bit integer
    }
    return Math.abs(hash);
  }

  private async refresh(): Promise<void> {
    try {
      const flags = await this.configSource.fetchFlags();
      this.flags = new Map(flags.map(f => [f.name, f]));
    } catch (error) {
      this.logger.error('Failed to refresh feature flags', error);
      // Keep using existing flags
    }
  }

  async close(): Promise<void> {
    if (this.refreshInterval) {
      clearInterval(this.refreshInterval);
    }
  }
}

// ===== Usage trong business logic =====

class CheckoutService {
  constructor(
    private readonly featureFlags: FeatureFlagService,
    private readonly logger: any,
  ) {}

  async processCheckout(userId: string, cart: Cart): Promise<Order> {
    const context: FeatureFlagContext = { userId };

    // New payment flow — rollout dần
    if (this.featureFlags.isEnabled('new-payment-flow', context)) {
      this.logger.info('Using new payment flow', { userId });
      return this.processWithNewPaymentFlow(cart);
    }

    return this.processWithLegacyPaymentFlow(cart);
  }

  async calculateDiscount(userId: string, cart: Cart): Promise<number> {
    // A/B test: new discount algorithm
    if (this.featureFlags.isEnabled('discount-algorithm-v2', { userId })) {
      return this.calculateDiscountV2(cart);
    }
    return this.calculateDiscountV1(cart);
  }
}

// Feature flag lifecycle:
// 1. Create flag (disabled) → deploy code guarded by flag
// 2. Enable for internal team → test in production
// 3. Rollout 5% → monitor error rate, latency
// 4. Rollout 25% → 50% → 100%
// 5. Remove flag from code (clean up) → deploy
//
// Quan trọng: CLEAN UP flags sau khi rollout 100%!
// Tech debt: old flags tích tụ → code khó đọc, khó maintain
```

## Canary & Progressive Rollouts

```
Canary Deployment: deploy version mới cho 1-5% traffic trước.
Nếu metrics ổn → tăng dần. Nếu có vấn đề → rollback chỉ 5% bị ảnh hưởng.

Progressive Rollout Steps:
  1. Deploy canary (5% traffic)
  2. Wait 5 phút, check error rate + latency
  3. Promote to 25%
  4. Wait 10 phút, check metrics
  5. Promote to 50%
  6. Wait 15 phút, check metrics
  7. Promote to 100%

Automatic Rollback khi:
  → Error rate canary > 2x baseline
  → P99 latency canary > 1.5x baseline
  → Health check fails

Tools: Argo Rollouts, Flagger, AWS CodeDeploy, Istio
```

## Database Migration Safety

### Safe Migration Practices

```
Nguyên tắc vàng: Migration PHẢI backward compatible.

Tại sao? Vì trong deployment:
  Old code version VÀ new code version chạy đồng thời.
  Nếu migration break old code → downtime.

Safe pattern: Expand & Contract
  Phase 1 (Expand): Thêm column/table mới, KHÔNG xóa cũ
  Phase 2: Deploy code hỗ trợ CẢ hai schema
  Phase 3 (Contract): Migrate data, xóa cũ (sau khi 100% code mới)
```

```typescript
// ===== Safe Migration Examples =====

// ❌ DANGEROUS: Rename column in 1 step
// → Old code tìm "email", new code tìm "email_address" → CRASH
// ALTER TABLE users RENAME COLUMN email TO email_address;

// ✅ SAFE: 3-step migration

// Step 1: Add new column (backward compatible)
const migration001 = {
  up: `ALTER TABLE users ADD COLUMN email_address VARCHAR(255);`,
  down: `ALTER TABLE users DROP COLUMN email_address;`,
};

// Step 2: Deploy code that writes to BOTH columns, reads from new
// (code change, not migration)

// Step 3: Backfill data
const migration002 = {
  up: `UPDATE users SET email_address = email WHERE email_address IS NULL;`,
  down: `-- no-op`,
};

// Step 4: Drop old column (AFTER old code is fully gone)
const migration003 = {
  up: `ALTER TABLE users DROP COLUMN email;`,
  down: `ALTER TABLE users ADD COLUMN email VARCHAR(255);`,
};

// ===== Migration Safety Checklist =====
// □ Migration có backward compatible không?
// □ Migration có rollback script không?
// □ Migration đã test trên copy of production data chưa?
// □ Estimated execution time? (lớn hơn 1 phút → cần online migration)
// □ Có lock table không? (ALTER TABLE trên table lớn → lock → downtime)
// □ Có cần index mới không? (CREATE INDEX CONCURRENTLY)
```

## Dependency Management & Supply Chain Security

```
Supply chain attack: Attacker compromises một dependency
→ Mọi app dùng dependency đó bị compromise

Ví dụ thực tế:
  - event-stream (2018): Malicious code steal Bitcoin wallets
  - ua-parser-js (2021): Cryptominer injected
  - colors/faker (2022): Author sabotaged own packages

Biện pháp phòng ngừa:
  1. Lock dependencies (package-lock.json / yarn.lock)
  2. npm audit trong CI pipeline
  3. Dependabot / Renovate cho automated updates
  4. Review dependency changelogs trước khi update
  5. Minimize dependencies (every dep is a risk)
  6. Private registry / proxy (Verdaccio, Artifactory)
  7. Pin exact versions (không dùng ^ hoặc ~)
  8. SBOM (Software Bill of Materials) cho compliance
```

## Performance Profiling in Production

### Node.js Specific: Event Loop Monitoring

```typescript
import { monitorEventLoopDelay } from 'node:perf_hooks';

// ===== Event Loop Monitoring =====
// Event loop lag = thời gian một callback phải CHỜ trước khi được execute
// Nếu lag cao → có blocking operation trên main thread

class EventLoopMonitor {
  private histogram = monitorEventLoopDelay({ resolution: 20 });
  private interval: NodeJS.Timeout | null = null;

  start(reportIntervalMs: number = 10000): void {
    this.histogram.enable();

    this.interval = setInterval(() => {
      const stats = {
        min: this.histogram.min / 1e6,       // ns → ms
        max: this.histogram.max / 1e6,
        mean: this.histogram.mean / 1e6,
        p50: this.histogram.percentile(50) / 1e6,
        p99: this.histogram.percentile(99) / 1e6,
        stddev: this.histogram.stddev / 1e6,
      };

      // Alert nếu p99 > 100ms
      if (stats.p99 > 100) {
        console.warn('[event-loop] High lag detected', stats);
      }

      // Report as metrics
      eventLoopLagGauge.set({ percentile: 'p50' }, stats.p50);
      eventLoopLagGauge.set({ percentile: 'p99' }, stats.p99);
      eventLoopLagGauge.set({ percentile: 'max' }, stats.max);

      // Reset cho window tiếp theo
      this.histogram.reset();
    }, reportIntervalMs);
  }

  stop(): void {
    this.histogram.disable();
    if (this.interval) clearInterval(this.interval);
  }
}
```

### Heap Snapshots

```typescript
import v8 from 'node:v8';
import fs from 'node:fs';
import path from 'node:path';

// ===== On-Demand Heap Snapshot =====
// Dùng khi suspect memory leak — KHÔNG dùng routine vì:
// - Freeze process trong lúc snapshot
// - File size = heap size (có thể hàng GB)

function takeHeapSnapshot(outputDir: string): string {
  const timestamp = new Date().toISOString().replace(/[:.]/g, '-');
  const filename = `heapdump-${process.pid}-${timestamp}.heapsnapshot`;
  const filepath = path.join(outputDir, filename);

  console.log(`[profiling] Taking heap snapshot: ${filepath}`);

  const snapshotStream = v8.writeHeapSnapshot(filepath);
  console.log(`[profiling] Heap snapshot written: ${snapshotStream}`);

  return filepath;
}

// Endpoint để trigger heap snapshot khi cần debug
// QUAN TRỌNG: Protect endpoint này! Chỉ internal access.
function registerProfilingEndpoints(app: any): void {
  app.post('/debug/heap-snapshot', async (req: any, res: any) => {
    // Auth check - chỉ cho phép internal calls
    if (req.headers['x-internal-token'] !== process.env.DEBUG_TOKEN) {
      return res.status(403).json({ error: 'Forbidden' });
    }

    try {
      const filepath = takeHeapSnapshot('/tmp/heapdumps');
      res.json({ filepath, message: 'Heap snapshot created' });
    } catch (error) {
      res.status(500).json({ error: (error as Error).message });
    }
  });
}
```

## Memory Leak Detection in Node.js

### Common Causes

```
Top 5 nguyên nhân memory leak trong Node.js:

1. GLOBAL CACHES KHÔNG CÓ EVICTION
   const cache = new Map();  // Grows forever!
   → Fix: dùng LRU cache với max size

2. EVENT LISTENER KHÔNG ĐƯỢC REMOVE
   emitter.on('data', handler);  // Thêm mỗi request nhưng không bao giờ remove
   → Fix: removeListener hoặc dùng once()

3. CLOSURES GIỮ REFERENCE
   function process(bigData) {
     return () => bigData.id;  // Closure giữ toàn bộ bigData, không chỉ id
   }
   → Fix: extract cần thiết trước khi tạo closure

4. TIMER KHÔNG ĐƯỢC CLEAR
   setInterval(() => {...}, 1000);  // Chạy mãi mãi
   → Fix: clearInterval khi không cần

5. STREAM KHÔNG ĐƯỢC CLOSE
   const stream = fs.createReadStream(path);
   // Nếu error xảy ra trước khi stream finish → leak
   → Fix: luôn handle error events, dùng pipeline()
```

### Detection Strategy

```typescript
// ===== Memory Monitoring =====

class MemoryMonitor {
  private samples: Array<{ timestamp: number; heapUsed: number }> = [];
  private interval: NodeJS.Timeout | null = null;
  private readonly maxSamples = 360;  // 30 phút với interval 5s

  start(intervalMs: number = 5000): void {
    this.interval = setInterval(() => {
      const mem = process.memoryUsage();
      this.samples.push({
        timestamp: Date.now(),
        heapUsed: mem.heapUsed,
      });

      // Keep only recent samples
      if (this.samples.length > this.maxSamples) {
        this.samples.shift();
      }

      // Check for leak pattern
      this.detectLeak();

      // Report metrics
      memoryGauge.set({ type: 'heapUsed' }, mem.heapUsed);
      memoryGauge.set({ type: 'heapTotal' }, mem.heapTotal);
      memoryGauge.set({ type: 'rss' }, mem.rss);
      memoryGauge.set({ type: 'external' }, mem.external);
    }, intervalMs);
  }

  private detectLeak(): void {
    if (this.samples.length < 60) return; // Cần ít nhất 5 phút data

    // So sánh trung bình 5 phút đầu với 5 phút cuối
    const firstWindow = this.samples.slice(0, 60);
    const lastWindow = this.samples.slice(-60);

    const avgFirst = firstWindow.reduce((s, x) => s + x.heapUsed, 0) / firstWindow.length;
    const avgLast = lastWindow.reduce((s, x) => s + x.heapUsed, 0) / lastWindow.length;

    const growthPercent = ((avgLast - avgFirst) / avgFirst) * 100;

    // Nếu memory tăng > 20% trong 30 phút → có thể leak
    if (growthPercent > 20) {
      console.warn('[memory] Potential memory leak detected', {
        growthPercent: growthPercent.toFixed(1),
        heapUsedStart: Math.round(avgFirst / 1024 / 1024) + 'MB',
        heapUsedCurrent: Math.round(avgLast / 1024 / 1024) + 'MB',
      });

      memoryLeakCounter.inc();
    }
  }

  stop(): void {
    if (this.interval) clearInterval(this.interval);
  }
}

const memoryGauge = new client.Gauge({
  name: 'nodejs_memory_bytes',
  help: 'Node.js memory usage',
  labelNames: ['type'] as const,
});

const memoryLeakCounter = new client.Counter({
  name: 'nodejs_memory_leak_detections_total',
  help: 'Number of potential memory leak detections',
});

// Pro tip: Soak test (load test chạy 2+ giờ) là cách tốt nhất
// để phát hiện memory leak trước khi production.
```

```typescript
// ===== production-server.ts =====
// Template cho production-ready Express server với tất cả best practices

import express, { Request, Response, NextFunction } from 'express';
import { createServer, Server } from 'node:http';
import { once } from 'node:events';
import { randomUUID } from 'node:crypto';
import client from 'prom-client';

// ===== Configuration =====

interface AppConfig {
  port: number;
  serviceName: string;
  version: string;
  environment: string;
  shutdownTimeoutMs: number;
  dbUrl: string;
  redisUrl: string;
}

function loadConfig(): AppConfig {
  const required = (key: string): string => {
    const value = process.env[key];
    if (!value) throw new Error(`Missing required env var: ${key}`);
    return value;
  };

  return {
    port: Number(process.env.PORT) || 3000,
    serviceName: process.env.SERVICE_NAME ?? 'my-service',
    version: process.env.APP_VERSION ?? '0.0.0',
    environment: process.env.NODE_ENV ?? 'development',
    shutdownTimeoutMs: Number(process.env.SHUTDOWN_TIMEOUT_MS) || 30000,
    dbUrl: required('DATABASE_URL'),
    redisUrl: process.env.REDIS_URL ?? 'redis://localhost:6379',
  };
}

// ===== Application Factory =====

function createApp(config: AppConfig): express.Express {
  const app = express();

  // --- Trust proxy (nếu behind load balancer) ---
  app.set('trust proxy', 1);

  // --- Body parsing ---
  app.use(express.json({ limit: '1mb' }));

  // --- Request ID ---
  app.use((req: Request, res: Response, next: NextFunction) => {
    const requestId = (req.headers['x-request-id'] as string) ?? randomUUID();
    (req as any).requestId = requestId;
    res.setHeader('X-Request-Id', requestId);
    next();
  });

  // --- Metrics middleware ---
  const httpDuration = new client.Histogram({
    name: 'http_request_duration_seconds',
    help: 'HTTP request duration',
    labelNames: ['method', 'route', 'status_code'] as const,
    buckets: [0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1, 2.5, 5, 10],
  });

  const httpTotal = new client.Counter({
    name: 'http_requests_total',
    help: 'Total HTTP requests',
    labelNames: ['method', 'route', 'status_code'] as const,
  });

  app.use((req: Request, res: Response, next: NextFunction) => {
    const end = httpDuration.startTimer();
    res.on('finish', () => {
      const labels = {
        method: req.method,
        route: req.route?.path ?? req.path,
        status_code: String(res.statusCode),
      };
      end(labels);
      httpTotal.inc(labels);
    });
    next();
  });

  // --- Health checks ---
  app.get('/health/live', (_req, res) => {
    res.json({ status: 'alive' });
  });

  app.get('/health/ready', (_req, res) => {
    // TODO: check dependencies
    res.json({ status: 'ready', version: config.version });
  });

  // --- Metrics endpoint ---
  app.get('/metrics', async (_req, res) => {
    res.set('Content-Type', client.register.contentType);
    res.end(await client.register.metrics());
  });

  // --- Business routes ---
  app.get('/api/v1/health', (_req, res) => {
    res.json({ service: config.serviceName, version: config.version });
  });

  // --- 404 handler ---
  app.use((_req: Request, res: Response) => {
    res.status(404).json({ error: 'Not Found' });
  });

  // --- Error handler ---
  app.use((err: Error, req: Request, res: Response, _next: NextFunction) => {
    console.error('[error]', {
      requestId: (req as any).requestId,
      method: req.method,
      path: req.path,
      error: err.message,
      stack: config.environment === 'production' ? undefined : err.stack,
    });

    const statusCode = (err as any).statusCode ?? 500;
    res.status(statusCode).json({
      error: statusCode === 500 ? 'Internal Server Error' : err.message,
      requestId: (req as any).requestId,
    });
  });

  return app;
}

// ===== Main =====

async function main(): Promise<void> {
  const config = loadConfig();

  console.log(`[startup] Starting ${config.serviceName} v${config.version}`);
  console.log(`[startup] Environment: ${config.environment}`);

  // Default metrics (CPU, memory, event loop, GC)
  client.collectDefaultMetrics({
    prefix: `${config.serviceName.replace(/-/g, '_')}_`,
  });

  const app = createApp(config);
  const server = createServer(app);

  // Start server
  server.listen(config.port);
  await once(server, 'listening');
  console.log(`[startup] Server listening on port ${config.port}`);

  // Graceful shutdown
  let isShuttingDown = false;

  async function shutdown(signal: string): Promise<void> {
    if (isShuttingDown) return;
    isShuttingDown = true;

    console.log(`[shutdown] Received ${signal}, shutting down gracefully...`);

    // 1. Stop accepting new connections
    server.close();

    // 2. Wait for in-flight requests
    const shutdownTimer = setTimeout(() => {
      console.error('[shutdown] Timeout reached, forcing exit');
      process.exit(1);
    }, config.shutdownTimeoutMs);

    try {
      await new Promise<void>((resolve) => {
        server.on('close', resolve);
      });

      // 3. Close other resources
      // await dbPool.end();
      // await redisClient.quit();

      clearTimeout(shutdownTimer);
      console.log('[shutdown] Graceful shutdown complete');
      process.exit(0);
    } catch (error) {
      console.error('[shutdown] Error during shutdown:', error);
      clearTimeout(shutdownTimer);
      process.exit(1);
    }
  }

  process.on('SIGTERM', () => shutdown('SIGTERM'));
  process.on('SIGINT', () => shutdown('SIGINT'));

  process.on('uncaughtException', (error) => {
    console.error('[fatal] Uncaught exception:', error);
    shutdown('uncaughtException');
  });

  process.on('unhandledRejection', (reason) => {
    console.error('[fatal] Unhandled rejection:', reason);
    shutdown('unhandledRejection');
  });
}

main().catch((error) => {
  console.error('[fatal] Failed to start:', error);
  process.exit(1);
});
```

### Tổng kết Production Readiness

```
Production readiness không phải checklist làm 1 lần rồi quên.
Nó là MINDSET và CULTURE:

1. THINK ABOUT FAILURE
   → Mọi dependency đều có thể fail
   → Mọi deployment đều có thể break
   → Mọi assumption đều có thể sai

2. MEASURE EVERYTHING
   → Không đo được thì không biết có vấn đề
   → Không biết có vấn đề thì không fix được
   → Không fix được thì users suffer

3. AUTOMATE RELIABILITY
   → Health checks tự động
   → Rollback tự động
   → Scaling tự động
   → Alert tự động

4. LEARN FROM INCIDENTS
   → Mỗi incident là cơ hội cải thiện
   → Postmortem → action items → prevent recurrence
   → Share learnings → whole org gets better

5. BALANCE SPEED AND SAFETY
   → Feature flags cho safe rollouts
   → Canary deployments
   → Error budgets cho phép innovation
   → Ship nhanh nhưng có safety net
```
