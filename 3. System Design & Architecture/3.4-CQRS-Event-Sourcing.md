## CQRS

### Bản chất

Tách **write model** (commands) và **read model** (queries) thành 2 models riêng biệt, có thể có storage riêng, optimize riêng.

```
Traditional CRUD:
  Client → [API] → [Service] → [Single DB] → [Same tables for read & write]

CQRS:
  Client → [Command API] → [Command Handler] → [Write DB (normalized)]
                                                      │
                                                      ▼ (sync/async)
  Client → [Query API]  → [Query Handler]  → [Read DB (denormalized, optimized)]
```

### Tại sao tách?

| Write Model | Read Model |
|-------------|-----------|
| Normalized (3NF) | Denormalized (flat, pre-joined) |
| Consistency (ACID) | Availability (eventually consistent OK) |
| Complex validation | Simple lookups |
| Low throughput | High throughput |
| Entity-oriented | View-oriented |
| PostgreSQL | Redis, Elasticsearch, materialized views |

### Implementation trong TypeScript

```typescript
// === WRITE SIDE (Commands) ===

// Command
class TransferMoneyCommand {
  constructor(
    readonly fromAccountId: string,
    readonly toAccountId: string,
    readonly amount: Money,
    readonly description: string,
  ) {
    if (amount.isNegativeOrZero()) throw new ValidationError('Amount must be positive');
    if (fromAccountId === toAccountId) throw new ValidationError('Cannot transfer to same account');
  }
}

// Command Handler — focuses on business rules, writes to normalized DB
class TransferMoneyHandler {
  constructor(
    private readonly accountRepo: AccountRepository,
    private readonly eventPublisher: EventPublisher,
  ) {}

  async execute(command: TransferMoneyCommand): Promise<string> {
    const fromAccount = await this.accountRepo.findById(command.fromAccountId);
    const toAccount = await this.accountRepo.findById(command.toAccountId);

    if (!fromAccount || !toAccount) throw new AccountNotFoundError();

    // Domain logic
    fromAccount.debit(command.amount, command.description);
    toAccount.credit(command.amount, command.description);

    // Persist write model (normalized)
    await this.accountRepo.saveAll([fromAccount, toAccount]);

    // Publish events → triggers read model update
    const transferId = crypto.randomUUID();
    await this.eventPublisher.publish(new MoneyTransferredEvent(
      transferId,
      command.fromAccountId,
      command.toAccountId,
      command.amount,
      command.description,
    ));

    return transferId;
  }
}

// === READ SIDE (Queries) ===

// Query
class GetAccountDashboardQuery {
  constructor(
    readonly accountId: string,
    readonly transactionLimit: number = 20,
  ) {}
}

// Read Model — denormalized, optimized for reads
interface AccountDashboardView {
  accountId: string;
  ownerName: string;
  balance: number;
  currency: string;
  recentTransactions: ReadonlyArray<{
    id: string;
    date: string;
    description: string;
    amount: number;
    type: 'credit' | 'debit';
    counterpartyName: string;
    runningBalance: number;
  }>;
  monthlySpending: number;
  monthlyIncome: number;
}

// Query Handler — simple lookup, no business logic
class GetAccountDashboardHandler {
  constructor(private readonly readDb: Knex) {}

  async execute(query: GetAccountDashboardQuery): Promise<AccountDashboardView | null> {
    // Single query on denormalized view — FAST
    const dashboard = await this.readDb('account_dashboard_view')
      .where('account_id', query.accountId)
      .first();

    if (!dashboard) return null;

    const transactions = await this.readDb('transaction_view')
      .where('account_id', query.accountId)
      .orderBy('date', 'desc')
      .limit(query.transactionLimit);

    return {
      accountId: dashboard.account_id,
      ownerName: dashboard.owner_name,
      balance: dashboard.balance,
      currency: dashboard.currency,
      recentTransactions: transactions,
      monthlySpending: dashboard.monthly_spending,
      monthlyIncome: dashboard.monthly_income,
    };
  }
}

// === Read Model Updater (Projection) ===
// Listens to events, updates denormalized read model

class AccountDashboardProjection {
  constructor(private readonly readDb: Knex) {}

  async handleMoneyTransferred(event: MoneyTransferredEvent): Promise<void> {
    await this.readDb.transaction(async (trx) => {
      // Update sender dashboard
      await trx('account_dashboard_view')
        .where('account_id', event.fromAccountId)
        .decrement('balance', event.amount.cents)
        .increment('monthly_spending', event.amount.cents);

      // Update receiver dashboard
      await trx('account_dashboard_view')
        .where('account_id', event.toAccountId)
        .increment('balance', event.amount.cents)
        .increment('monthly_income', event.amount.cents);

      // Add to transaction view (both sides)
      await trx('transaction_view').insert([
        {
          id: crypto.randomUUID(),
          account_id: event.fromAccountId,
          date: event.occurredAt,
          description: event.description,
          amount: -event.amount.cents,
          type: 'debit',
          counterparty_name: await this.getAccountName(trx, event.toAccountId),
        },
        {
          id: crypto.randomUUID(),
          account_id: event.toAccountId,
          date: event.occurredAt,
          description: event.description,
          amount: event.amount.cents,
          type: 'credit',
          counterparty_name: await this.getAccountName(trx, event.fromAccountId),
        },
      ]);
    });
  }

  private async getAccountName(trx: Knex.Transaction, accountId: string): Promise<string> {
    const account = await trx('account_dashboard_view').where('account_id', accountId).first();
    return account?.owner_name ?? 'Unknown';
  }
}
```

## Event Sourcing

### Bản chất

Thay vì store **current state**, store **sequence of events** đã xảy ra. Current state = replay tất cả events.

```
Traditional:
  Account { id: "acc_1", balance: 500, status: "active" }
  → Chỉ biết state HIỆN TẠI. Không biết LÀM SAO đến đây.

Event Sourcing:
  Event 1: AccountOpened { id: "acc_1", initialBalance: 1000 }
  Event 2: MoneyWithdrawn { id: "acc_1", amount: 200, reason: "ATM" }
  Event 3: MoneyDeposited { id: "acc_1", amount: 500, source: "salary" }
  Event 4: MoneyWithdrawn { id: "acc_1", amount: 800, reason: "rent" }
  → Current balance: 1000 - 200 + 500 - 800 = 500
  → Biết TOÀN BỘ lịch sử, có thể audit, replay, time-travel
```

### Event Store Implementation

```typescript
// Event Store — append-only log of events

interface StoredEvent {
  readonly eventId: string;
  readonly aggregateId: string;
  readonly aggregateType: string;
  readonly eventType: string;
  readonly data: unknown;
  readonly metadata: EventMetadata;
  readonly version: number;           // Per-aggregate version (optimistic concurrency)
  readonly globalPosition: number;    // Global ordering
  readonly occurredAt: Date;
}

interface EventMetadata {
  readonly correlationId: string;
  readonly causationId?: string;
  readonly userId?: string;
}

class PostgresEventStore {
  constructor(private readonly db: Knex) {}

  // Append events with optimistic concurrency
  async append(
    aggregateId: string,
    aggregateType: string,
    events: ReadonlyArray<DomainEvent>,
    expectedVersion: number,
  ): Promise<void> {
    await this.db.transaction(async (trx) => {
      // Check current version (optimistic concurrency control)
      const result = await trx('event_store')
        .where('aggregate_id', aggregateId)
        .max('version as max_version')
        .first();

      const currentVersion = result?.max_version ?? 0;

      if (currentVersion !== expectedVersion) {
        throw new ConcurrencyError(
          `Expected version ${expectedVersion}, but current is ${currentVersion}`
        );
      }

      // Append events
      const rows = events.map((event, index) => ({
        event_id: event.eventId,
        aggregate_id: aggregateId,
        aggregate_type: aggregateType,
        event_type: event.eventType,
        data: JSON.stringify(event),
        metadata: JSON.stringify(event.metadata ?? {}),
        version: expectedVersion + index + 1,
        occurred_at: event.occurredAt,
      }));

      await trx('event_store').insert(rows);
    });
  }

  // Load all events for an aggregate
  async loadEvents(aggregateId: string): Promise<ReadonlyArray<StoredEvent>> {
    return this.db('event_store')
      .where('aggregate_id', aggregateId)
      .orderBy('version', 'asc');
  }

  // Load events from a specific version (for snapshots)
  async loadEventsFromVersion(
    aggregateId: string,
    fromVersion: number,
  ): Promise<ReadonlyArray<StoredEvent>> {
    return this.db('event_store')
      .where('aggregate_id', aggregateId)
      .where('version', '>', fromVersion)
      .orderBy('version', 'asc');
  }

  // Stream all events (for projections)
  async loadAllEvents(fromPosition: number, batchSize: number): Promise<ReadonlyArray<StoredEvent>> {
    return this.db('event_store')
      .where('global_position', '>', fromPosition)
      .orderBy('global_position', 'asc')
      .limit(batchSize);
  }
}

// SQL Schema
// CREATE TABLE event_store (
//   global_position BIGSERIAL PRIMARY KEY,
//   event_id UUID UNIQUE NOT NULL,
//   aggregate_id UUID NOT NULL,
//   aggregate_type VARCHAR(100) NOT NULL,
//   event_type VARCHAR(100) NOT NULL,
//   data JSONB NOT NULL,
//   metadata JSONB DEFAULT '{}',
//   version INTEGER NOT NULL,
//   occurred_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
//   UNIQUE(aggregate_id, version)  -- Optimistic concurrency
// );
// CREATE INDEX idx_event_store_aggregate ON event_store(aggregate_id, version);
```

### Event-Sourced Aggregate

```typescript
// Account aggregate — state rebuilt from events

type AccountEvent =
  | { type: 'AccountOpened'; ownerId: string; initialBalance: number; currency: string }
  | { type: 'MoneyDeposited'; amount: number; source: string; reference: string }
  | { type: 'MoneyWithdrawn'; amount: number; reason: string; reference: string }
  | { type: 'AccountSuspended'; reason: string }
  | { type: 'AccountClosed'; reason: string };

class Account {
  private _id: string;
  private _ownerId: string;
  private _balance: number;
  private _currency: string;
  private _status: 'active' | 'suspended' | 'closed';
  private _version: number;
  private _pendingEvents: AccountEvent[] = [];

  private constructor() {
    this._id = '';
    this._ownerId = '';
    this._balance = 0;
    this._currency = 'USD';
    this._status = 'active';
    this._version = 0;
  }

  // Create new account (generates event)
  static open(id: string, ownerId: string, initialBalance: number, currency: string): Account {
    const account = new Account();
    account.apply({
      type: 'AccountOpened',
      ownerId,
      initialBalance,
      currency,
    });
    account._id = id;
    return account;
  }

  // Rebuild from event history
  static fromHistory(id: string, events: ReadonlyArray<AccountEvent>): Account {
    const account = new Account();
    account._id = id;
    for (const event of events) {
      account.applyEvent(event);
      account._version++;
    }
    return account;
  }

  get id(): string { return this._id; }
  get balance(): number { return this._balance; }
  get status(): string { return this._status; }
  get version(): number { return this._version; }
  get pendingEvents(): ReadonlyArray<AccountEvent> { return this._pendingEvents; }

  deposit(amount: number, source: string): void {
    if (this._status !== 'active') throw new Error('Account not active');
    if (amount <= 0) throw new Error('Amount must be positive');

    this.apply({
      type: 'MoneyDeposited',
      amount,
      source,
      reference: crypto.randomUUID(),
    });
  }

  withdraw(amount: number, reason: string): void {
    if (this._status !== 'active') throw new Error('Account not active');
    if (amount <= 0) throw new Error('Amount must be positive');
    if (this._balance < amount) throw new Error('Insufficient funds');

    this.apply({
      type: 'MoneyWithdrawn',
      amount,
      reason,
      reference: crypto.randomUUID(),
    });
  }

  suspend(reason: string): void {
    if (this._status !== 'active') throw new Error('Can only suspend active accounts');
    this.apply({ type: 'AccountSuspended', reason });
  }

  // Apply event: update state + record as pending
  private apply(event: AccountEvent): void {
    this.applyEvent(event);
    this._pendingEvents.push(event);
  }

  // Pure state mutation from event — no business rules here
  private applyEvent(event: AccountEvent): void {
    switch (event.type) {
      case 'AccountOpened':
        this._ownerId = event.ownerId;
        this._balance = event.initialBalance;
        this._currency = event.currency;
        this._status = 'active';
        break;
      case 'MoneyDeposited':
        this._balance += event.amount;
        break;
      case 'MoneyWithdrawn':
        this._balance -= event.amount;
        break;
      case 'AccountSuspended':
        this._status = 'suspended';
        break;
      case 'AccountClosed':
        this._status = 'closed';
        break;
    }
  }

  clearPendingEvents(): void {
    this._pendingEvents = [];
  }
}

// Repository cho Event-Sourced Aggregate
class EventSourcedAccountRepository {
  constructor(private readonly eventStore: PostgresEventStore) {}

  async findById(id: string): Promise<Account | null> {
    const storedEvents = await this.eventStore.loadEvents(id);
    if (storedEvents.length === 0) return null;

    const events = storedEvents.map(se => se.data as AccountEvent);
    return Account.fromHistory(id, events);
  }

  async save(account: Account): Promise<void> {
    const pendingEvents = account.pendingEvents;
    if (pendingEvents.length === 0) return;

    const domainEvents = pendingEvents.map(event => ({
      eventId: crypto.randomUUID(),
      eventType: event.type,
      occurredAt: new Date(),
      metadata: {},
      ...event,
    }));

    await this.eventStore.append(
      account.id,
      'Account',
      domainEvents as any,
      account.version,
    );

    account.clearPendingEvents();
  }
}
```

### Snapshots — Performance optimization

```typescript
// Aggregate với 10,000 events → replay lâu
// Snapshot: save current state periodically, replay chỉ events sau snapshot

class SnapshotStore {
  constructor(private readonly db: Knex) {}

  async saveSnapshot(aggregateId: string, version: number, state: unknown): Promise<void> {
    await this.db('snapshots')
      .insert({
        aggregate_id: aggregateId,
        version,
        state: JSON.stringify(state),
        created_at: new Date(),
      })
      .onConflict('aggregate_id')
      .merge();
  }

  async loadSnapshot(aggregateId: string): Promise<{ version: number; state: unknown } | null> {
    const snapshot = await this.db('snapshots')
      .where('aggregate_id', aggregateId)
      .first();
    return snapshot ? { version: snapshot.version, state: JSON.parse(snapshot.state) } : null;
  }
}

// Repository with snapshot support
class SnapshotAccountRepository {
  private readonly snapshotFrequency = 100; // Snapshot every 100 events

  constructor(
    private readonly eventStore: PostgresEventStore,
    private readonly snapshotStore: SnapshotStore,
  ) {}

  async findById(id: string): Promise<Account | null> {
    // Try loading from snapshot first
    const snapshot = await this.snapshotStore.loadSnapshot(id);

    let events: StoredEvent[];
    if (snapshot) {
      // Only load events AFTER snapshot
      events = await this.eventStore.loadEventsFromVersion(id, snapshot.version) as StoredEvent[];
      if (events.length === 0 && snapshot) {
        return Account.fromSnapshot(id, snapshot.state, snapshot.version);
      }
    } else {
      events = await this.eventStore.loadEvents(id) as StoredEvent[];
    }

    if (events.length === 0 && !snapshot) return null;

    const account = snapshot
      ? Account.fromSnapshotAndEvents(id, snapshot.state, snapshot.version, events.map(e => e.data as AccountEvent))
      : Account.fromHistory(id, events.map(e => e.data as AccountEvent));

    return account;
  }

  async save(account: Account): Promise<void> {
    await this.eventStore.append(
      account.id, 'Account',
      account.pendingEvents as any,
      account.version,
    );

    // Create snapshot periodically
    const newVersion = account.version + account.pendingEvents.length;
    if (newVersion % this.snapshotFrequency === 0) {
      await this.snapshotStore.saveSnapshot(account.id, newVersion, account.toSnapshot());
    }

    account.clearPendingEvents();
  }
}
```

## CQRS + Event Sourcing kết hợp

```
Write Side:                          Read Side:
Command → Handler → Aggregate        Event Store → Projection → Read DB → Query Handler
              │                             │
              ▼                             ▼
         Event Store ─── events ──► Projection Worker
         (source of truth)          (builds read models)

Write: event-sourced aggregates
Read: denormalized projections rebuilt from events
```

## Khi nào dùng / Khi nào KHÔNG

### CQRS

| ✅ Dùng khi | ❌ Quá mức khi |
|------------|---------------|
| Read/write ratio rất lệch (100:1) | Simple CRUD app |
| Read model cần khác write model structurally | Read/write model giống nhau |
| Cần optimize read performance riêng | Đủ nhanh với 1 model |
| Complex query requirements (search, aggregation) | Basic queries |

### Event Sourcing

| ✅ Dùng khi | ❌ Quá mức khi |
|------------|---------------|
| Audit trail bắt buộc (finance, healthcare) | Không cần lịch sử |
| Cần time-travel / temporal queries | Current state đủ |
| Complex domain with many state transitions | Simple CRUD |
| Debugging production issues cần replay | Standard logging đủ |
| Event-driven architecture sẵn | Request-response architecture |

### Cả hai?

> **CQRS without Event Sourcing** = tách read/write model, cùng DB, materialized views. **Rất thực tế, dùng được cho phần lớn apps phức tạp.**
>
> **Event Sourcing without CQRS** = lưu events nhưng query trực tiếp event store. **Ít thực tế vì query event store rất chậm.**
>
> **CQRS + Event Sourcing** = full combo. **Chỉ dùng cho domains thực sự cần (finance, booking, inventory).** Thêm significant complexity.
